# 2331 - 精英

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 10,953 百萬台幣
**企業價值:** 3,757 百萬台幣

精英電腦 (2331，[[Elitegroup Computer Systems]]，ECS) 成立於 1987 年，總部位於台北，為全球主機板及迷你電腦知名設計製造商，以自有品牌 LIVA 迷你電腦系列在全球工控與商用 PC 市場建立定位。2025 年全年合併營收 201.1 億元，年增 15%；2026 年首季累計營收年增 40.75%，顯示復甦動能強勁；毛利率維持在 10-11% 區間，營業利益受高費用拖累而偏低。旗下產品在印度市場連續兩年獲評「最受歡迎迷你電腦品牌」，並贏得「最佳迷你電腦品牌」殊榮，顯示在新興市場的品牌滲透成效。

**營收結構方面**，主機板（含 [[Intel]] 及 [[AMD]] 平台桌機主機板）佔整體營收最大比重，約 45%；LIVA 迷你電腦系列（商用、工業及數位看板應用）佔約 25%；商用及教育筆電與 [[Chromebook]] 佔約 15%；工業電腦 (IPC) 主機板及嵌入式解決方案佔約 10%；衛星模組及其他新興方案佔約 5%。地理分布以歐洲為最大市場，亞洲及美洲次之。

**核心技術與競爭優勢方面**，精英電腦深耕 [[Intel]] 與 [[AMD]] 雙平台主機板長達 35 年以上，具備快速導入新一代 CPU 的研發能力。LIVA 迷你電腦採模組化設計，支援 Intel Core Ultra 及 [[AMD]] Ryzen 處理器，廣泛應用於數位看板、工業自動化 AOI、自助服務亭等場景。2025 年於 Embedded World 亮相工業級嵌入式解決方案；CES 2026 發表次世代主機板與 AI 商務筆電，驗證產品線持續更新能力。在 [[Chromebook]] 方面，透過 [[Google]] 生態系進入教育市場，提供低成本商用筆電方案。立方衛星 (CubeSat) 模組為新興布局，切入低軌衛星[[低軌衛星]]應用。

**成長動能方面**，AI PC 換機潮為主機板及筆電帶來替換需求；LIVA 迷你電腦持續擴大在數位零售與工業邊緣運算的應用場景；工業電腦 (IPC) 隨自動化與 AI 邊緣推論需求上升而穩定成長；[[5G]]、AIoT 相關工業應用推動 IPC 主機板需求。2026 年累計營收大幅成長亦顯示新品週期已帶動出貨量回升。

主要風險：主機板市場整體規模趨於停滯，受到整合式 NUC 及迷你主機競爭壓縮；毛利率長期偏低，對原材料與 CPU 漲價敏感；小型公司規模相對[[華碩]]、[[技嘉]]仍有明顯差距，品牌影響力受限；整體 PC 市場波動與消費信心直接影響主機板銷售。

## 供應鏈位置
**上游 (晶片組與電子元件):**
- **CPU/晶片組:** [[Intel]] — 桌機/筆電 CPU 及晶片組平台 (Core Ultra、第 13/14 代 Core)
- **CPU/晶片組:** [[AMD]] — Ryzen 桌機及筆電 CPU 平台
- **GPU:** [[NVIDIA]]、[[AMD]] — 顯示卡繪圖晶片
- **記憶體:** [[Samsung]]、[[SK 海力士]] — DDR5 DRAM 模組
- **PCB:** 多層 PCB 電路板製造商
- **電源管理:** 電源管理 IC 及電壓調節器供應商

**中游 (主機板與迷你電腦設計製造):**
- **主機板:** **精英** ([[Intel]]/[[AMD]] 平台桌機主機板，涵蓋入門至高端)
- **LIVA 迷你電腦:** **精英** (Q 系列、Z 系列、One 系列、M 系列工業級、X 系列數位看板)
- **IPC 主機板:** **精英** (工業電腦嵌入式主機板)
- **商用筆電/Chromebook:** **精英** (教育及企業商用機型)

**下游 (通路商與企業終端客戶):**
- **全球 IT 通路:** 歐洲、亞洲、美洲 IT 產品經銷通路商 — 主機板及迷你電腦
- **教育市場:** [[Google]] Chromebook 生態系 — 教育及商用筆電
- **工業客戶:** 工業自動化及嵌入式系統整合商 — IPC 主機板
- **零售數位看板:** 智慧零售及自助服務亭業者 — LIVA X 系列多螢幕解決方案
