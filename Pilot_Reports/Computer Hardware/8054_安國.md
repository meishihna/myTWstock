# 8054 - 安國

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 8,113 百萬台幣
**企業價值:** 8,540 百萬台幣

安國科技 (Alcor Micro) 為台灣 IC 設計公司，為 [[神盾]] (Egis Technology，6923) 集團旗下子公司，傳統核心為 USB 卡片讀取控制器及 HUB IC，近年轉型推進 ASIC 自研設計業務。2024 年底完成合併 StarRiver（星河），整合 Arm CPU 設計能力，並於 2025 年 OCP Summit 展示搭載 Arm CSS V3 架構的 Mobius100 伺服器 CPU 平台，標誌公司向高階伺服器處理器市場轉型。集團同時持有 [[神盾]] 指紋感測 IC 技術生態系的協同優勢。

**營收結構方面**，依產品別：傳統 USB HUB 及卡片讀取控制器佔現有主力營收（約 70%），ASIC 設計服務及新興 Arm CPU 設計業務比重逐步提升（約 20%），其他約 10%。依地區：以外銷為主，亞太地區（中國、台灣）電腦周邊及消費電子市場為主要客戶群。

**核心技術與競爭優勢方面**，安國完成 StarRiver 合併後獲得 Arm 架構伺服器 CPU 設計能力，Mobius100 採用 [[Arm]] CSS V3 高效能計算（HPC）IP 架構，定位為資料中心 [[AI 伺服器]] 及雲端 CPU 市場。[[神盾]] 母公司提供生態系協同支援及資金資源；公司在 USB 3.x/USB4 控制器領域有多年深厚積累，形成基本護城河。

**成長動能方面**，Mobius100 [[Arm]] CSS V3 伺服器 CPU 平台若成功商業化，可切入資料中心及 AI 伺服器的 CPU 多元化趨勢（[[Intel]] 替代方案需求）；[[神盾]] 集團的財務支援及客戶資源有助新平台導入；ASIC 設計服務受惠晶片客製化需求增長。

主要風險：伺服器 CPU 市場競爭激烈（[[Intel]]、[[AMD]]、[[Ampere Computing]] 等）、Mobius100 商業化進程不確定、USB 控制器傳統業務萎縮壓力、母公司 [[神盾]] 集團整合風險。

## 供應鏈位置
**上游 (IP 授權與晶圓代工):**
- **CPU 架構 IP:** [[Arm]] — Arm CSS V3 高效能 CPU 架構授權
- **晶圓代工:** [[台積電]] — ASIC/CPU IC 晶圓製造
- **記憶體:** [[Micron]]、[[三星電子]] — 系統記憶體

**中游:**
- **ASIC/CPU 設計:** **安國** (Mobius100 [[Arm]] CSS V3 伺服器 CPU 設計；USB 控制器 IC)
- **母公司協同:** **[[神盾]]** (指紋感測 IC 設計能力及集團資源支援)

**下游 (終端應用):**
- **電腦周邊:** 電腦 OEM/ODM 廠 — USB HUB 及卡片讀取控制器
- **資料中心（潛在）:** 雲端服務商及 AI 資料中心 — Mobius100 伺服器 CPU（開發中）
