# 3706 - 神達

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 116,131 百萬台幣
**企業價值:** 120,992 百萬台幣

神達電腦 (MiTAC Holdings) 為台灣多角化科技控股公司，旗下業務涵蓋 GPS 衛星導航（Mio、Navman 品牌）、IT 伺服器與基礎建設（MiTAC-Hewlett Packard IT）及車用電子，以「個人導航設備品牌+IT 基礎建設服務」雙核心策略布局全球市場。2024 年合併營收約新台幣 200 億元，GPS 事業仍佔最大比重但持續萎縮，IT 伺服器及雲端服務事業快速成長。

**營收結構方面**，依業務別：GPS 個人導航設備（Mio/Navman 品牌）佔約 35%，IT 伺服器及 MiTAC IT 企業服務佔約 40%，車用電子及 [[ADAS]] 系統佔約 15%，其他（雲端/IoT）佔約 10%。依地區：歐洲（GPS 主要市場）約 35%，北美約 25%，亞太約 40%。

**核心技術與競爭優勢方面**，神達在 GPS 導航設備具備多年地圖整合及即時交通資訊演算法積累，Mio 品牌在歐洲車用 GPS 市場具備穩固市佔；MiTAC IT 在台灣企業 IT 服務市場深耕，提供伺服器、儲存及雲端整合方案；車用電子業務進入 [[ADAS]] 後裝市場，可提供車道偏離警示（LDWS）及前向碰撞預警（FCWS）系統，通過車規認證具競爭壁壘。

**成長動能方面**，企業 IT 數位轉型推動伺服器及雲端基礎建設採購，MiTAC IT 受惠台灣企業 IT 升級需求；車用 [[ADAS]] 後裝市場持續成長，後裝行車記錄器整合 AI 事件偵測功能；Mio 品牌切入行車記錄器（Dashcam）高成長市場，補償 GPS 市場萎縮；[[低軌衛星]] 導航未來可能強化 GPS 精度，帶動換代需求。

主要風險：GPS 個人導航設備市場長期萎縮（智慧型手機地圖應用取代）、IT 服務市場競爭激烈、車用電子業務規模尚小、多角化業務整合效益有限。

## 供應鏈位置
**上游 (定位晶片與電子元件):**
- **GNSS 晶片:** [[Qualcomm]] (GNSS SoC)、[[聯發科]] (MT3333) — GPS/GNSS 定位晶片
- **地圖資料:** [[TomTom]]、[[HERE Technologies]] — 地圖授權
- **伺服器元件:** [[Intel]] Xeon、[[AMD]] EPYC — MiTAC IT 伺服器 CPU

**中游:**
- **GPS 導航設備:** **神達** (Mio、Navman 品牌個人導航設備設計製造)
- **IT 伺服器/服務:** **神達** (MiTAC IT 企業伺服器及雲端服務)
- **車用電子:** **神達** (後裝 [[ADAS]] 及行車記錄器)

**下游 (終端應用):**
- **消費者/車主:** 歐洲車主 — Mio/Navman 車用 GPS 導航
- **企業/政府:** 台灣企業及政府機構 — MiTAC IT 伺服器及雲端服務
- **車用後裝:** 汽車後裝配件通路商 — ADAS 行車記錄器
