# 6599_普達系統

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 877 百萬台幣
**企業價值:** 594 百萬台幣

普達系統股份有限公司 (6599，Poindus Systems) 是一家深耕零售與餐旅業端點銷售解決方案的專業製造商，主要產品涵蓋全整合型 [[POS]] 終端機 (All-in-One POS Terminal)、工業電腦觸控顯示器 ([[IPC]] Display) 及自助服務終端機 (Self-Service Kiosk)。公司以設計端到端 [[POS]] 硬體解決方案見長，提供 OEM/ODM 服務，服務對象包含全球零售連鎖、餐飲集團及加油站等垂直行業，產品銷售遍及北美、歐洲及亞太等地。2024 年營收達 11.7 億元台幣，年成長近七成，主要受惠於北美零售客戶大單入帳。

**營收結構方面**，[[POS]] 系統及零售終端硬體為最主要收入來源，約佔七成；[[IPC]] 顯示器及工業觸控顯示器約佔二成；自助服務 Kiosk 及零組件服務佔餘約一成。地理分布上，北美市場約佔半數，歐洲約佔兩成，亞太及其他佔三成。

**核心技術與競爭優勢方面**，普達系統擁有將 [[POS]] 終端所需的電腦主機、顯示器、讀卡機與印表機整合為單一機身的設計能力，具備行業專用高溫、濺水防護等強固特性，通過 PCI-PTS 支付安全認證，滿足金融支付合規要求。長期深耕零售與餐旅特定行業使公司累積豐富的行業定制化能力，形成高轉換成本的黏性客戶關係。

**成長動能方面**，北美零售業 [[POS]] 系統升級週期帶動大型連鎖客戶汰換舊機需求；自助服務 Kiosk 滲透率提升，餐飲業加速採用觸控點餐機；歐美零售商在後疫情時代積極進行數位轉型，帶動新一輪 [[POS]] 硬體建置投資；加油站及便利商店等特殊垂直市場的客制化需求持續成長。

主要風險：客戶集中度偏高，少數北美大客戶訂單波動對營收影響顯著；[[POS]] 硬體市場呈現強週期性，大型連鎖客戶採購集中在升級週期，訂單能見度不穩定；競爭對手如 [[Posiflex]] 及中國廠商提供低價產品形成壓力；全球半導體元件供應鏈波動影響交期。

## 供應鏈位置
**上游 (核心元件):**
- **處理器:** [[Intel]] — 嵌入式 Atom/Core/Celeron 系列 CPU
- **觸控面板:** 工業級觸控顯示面板供應商
- **支付周邊:** 條碼讀取器、磁條讀卡機、[[NFC]] 模組及熱感印表機供應商
- **電路板:** 工業級 [[PCB]] 製造商

**中游 (POS 硬體設計製造):**
- **AIO POS 終端:** **普達系統** (All-in-One POS 終端機 OEM/ODM)
- **IPC 顯示器:** **普達系統** (工業觸控顯示器設計製造)
- **Kiosk:** **普達系統** (自助服務終端機設計製造)

**下游 (垂直行業客戶):**
- **零售連鎖:** 歐美大型零售連鎖超市及便利商店
- **餐飲集團:** 連鎖餐廳與速食業者 — 觸控點餐機
- **加油站:** 加油站 POS 系統整合商
- **旅館飯店:** 旅館餐旅業管理系統整合商

## 主要客戶及供應商
### 主要客戶
- **零售連鎖:** 北美大型零售連鎖客戶 — All-in-One POS 終端機 OEM
- **餐飲集團:** 歐美連鎖餐廳及速食品牌系統整合商 — 觸控點餐機
- **加油站:** 歐美加油站 POS 解決方案整合商
- **旅館飯店:** 酒店業管理系統廠商 — IPC 觸控顯示器

### 主要供應商
- **處理器:** [[Intel]] — 嵌入式 CPU 平台
- **顯示模組:** 工業級 LCD/觸控顯示面板供應商
- **支付模組:** [[NFC]] 感應讀卡機及條碼讀取模組供應商
- **PCB:** 工業級印刷電路板廠商
- **機殼:** 精密金屬/塑膠機殼供應商
