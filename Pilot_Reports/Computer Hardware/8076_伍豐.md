# 8076 - 伍豐

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 7,481 百萬台幣
**企業價值:** 8,318 百萬台幣

伍豐科技 (FEC) 為台灣 POS 系統及自助服務設備製造商，以自有品牌銷售商用 [[POS 系統]]、彩票投注終端及自助服務 Kiosk，在台灣擁有重要的政府授權彩票投注終端業務（[[台灣彩券]]）。2024 年外銷佔比高，歐洲及美洲合計貢獻 51%，中國/亞洲 35%，台灣本地 14%，以全球多元市場分散客戶集中風險。

**營收結構方面**，依應用別：[[POS 系統]] 及商用收銀設備佔約 50%，彩票/博彩投注終端佔約 30%，自助服務 Kiosk 佔約 20%。依地區：歐洲及美洲合計約 51%，中國/亞洲約 35%，台灣約 14%。

**核心技術與競爭優勢方面**，伍豐在彩票/博彩投注終端具備政府合規認證及長期維護合約，台灣本地 [[台灣彩券]] 的授權合約形成穩定收入基礎。POS 產品以耐用性及成本效益見長，切入歐洲中小型零售業市場。自有品牌銷售全球多個國家，具備全球通路布建能力，多元地區配置降低景氣集中風險。

**成長動能方面**，歐洲零售業 POS 更新換代需求穩健；博彩市場自助服務化趨勢驅動投注終端升級；中國零售業數位化及無人零售持續推進；亞太新興市場自助服務需求成長；台灣彩券投注終端合約續約與擴展帶動本地業務。

主要風險：彩票/博彩業務受政府政策監管影響大、POS 市場競爭激烈、[[台灣彩券]] 單一客戶集中風險、地緣政治影響中國業務。

## 供應鏈位置
**上游 (電子元件):**
- **處理器:** [[Intel]]、[[AMD]] — POS/Kiosk 嵌入式 CPU
- **觸控面板:** 觸控螢幕模組廠商
- **熱感應列印元件:** 熱感應列印機頭供應商

**中游:**
- **POS 系統:** **伍豐** (商用 [[POS 系統]] 品牌設計製造)
- **彩票/博彩終端:** **伍豐** (博彩投注終端、自助服務機)

**下游 (終端應用):**
- **零售業:** 歐洲及亞太連鎖零售業者 — [[POS 系統]] 設備
- **博彩/彩票:** [[台灣彩券]]、海外博彩機構 — 投注終端
- **政府/公共服務:** 政府機構 — 自助服務 Kiosk

## 主要客戶及供應商
### 主要客戶
- **彩票/博彩:** [[台灣彩券]] — 台灣授權彩票投注終端
- **零售業:** 歐洲及亞太連鎖零售業者 — [[POS 系統]] 設備
- **政府/公共:** 亞太政府機構 — 自助服務 Kiosk

### 主要供應商
- **嵌入式處理器:** [[Intel]] — POS 嵌入式 CPU
- **觸控螢幕:** 觸控面板模組廠商
