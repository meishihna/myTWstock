# 6928_攸泰科技

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 4,713 百萬台幣
**企業價值:** 3,219 百萬台幣

攸泰科技 (RuggON) 為[[大眾控]]（3701，大眾電腦集團）旗下子公司，成立於 2011 年，以自有品牌 RuggON 銷售強固型行動電腦，核心產品為高規格全強固平板電腦（Fully Rugged Tablet）及手持電腦，主攻艦船海事、航空地勤、國防軍事及工業野外作業等對設備耐用性要求極高的垂直市場。公司與[[台灣太空中心]]（TASA）及[[工研院]]（ITRI）合作，積極布局 [[LEO]] 低軌衛星通訊整合應用。

**營收結構方面**，依應用別：海事艦船強固型電腦佔約 35%，航空地勤強固型裝置佔約 25%，國防軍用設備佔約 25%，工業/其他佔約 15%。依地區：北美及歐洲（海事/國防採購市場）約 60%，亞太約 40%。

**核心技術與競爭優勢方面**，RuggON 強固型電腦具備 MIL-STD-810H、IP67 防水防塵及 MIL-STD-461 電磁兼容認證，符合艦船及國防裝備採購規格。與[[台灣太空中心]]合作探索 [[LEO]] 衛星通訊整合應用，在台灣廠商中具領先地位。[[大眾控]]（USI）集團光纖模組及無線通訊技術資源可為 RuggON 產品提供衛星通訊模組整合支援。國防採購週期長、轉換成本高，形成穩定客戶關係。

**成長動能方面**，全球海事數位化（船隊管理、港口自動化）帶動艦船強固型電腦採購增長；[[LEO]] 低軌衛星通訊部署（如 [[SpaceX Starlink]]）帶動海事/航空終端設備整合需求；各國國防預算增加推動軍規強固型電腦換代；台灣國防自主政策帶動本土強固型設備採購；航空地勤電子飛行手冊（EFB）數位化帶動強固型平板採購。

主要風險：公司規模小、國防採購週期長且不確定性高、[[LEO]] 衛星通訊整合尚在早期、海事市場景氣與全球貿易量連動、[[大眾控]]集團策略調整對攸泰資源分配的影響。

## 供應鏈位置
**上游 (強固型電腦核心元件):**
- **處理器:** [[Intel]] — 工業級 Core i/Atom 處理器
- **通訊模組:** [[Qualcomm]] — LTE/5G 行動通訊模組
- **衛星通訊:** [[LEO]] 衛星通訊晶片及模組廠商
- **顯示面板:** 軍規寬溫 LCD 面板供應商

**中游:**
- **強固型行動電腦:** **攸泰科技** (RuggON 品牌強固型平板/手持電腦設計製造)

**下游 (終端應用):**
- **海事艦船:** 海軍艦艇、商船船隊 — RuggON 強固型艦載電腦
- **航空地勤:** 航空公司地勤、機坪作業 — RuggON 強固型平板
- **國防軍事:** 各國軍隊野戰指揮 — 軍規強固型電腦

## 主要客戶及供應商
### 主要客戶
- **海事/海軍:** 歐美艦艇及商船船隊客戶 — RuggON 艦載強固型電腦
- **航空公司:** 國際航空公司地勤部門 — RuggON 地勤強固型平板
- **國防機構:** 歐美亞太各國軍方採購 — 軍規強固型電腦

### 主要供應商
- **工業處理器:** [[Intel]] — 工業級嵌入式 CPU
- **通訊模組:** [[Qualcomm]] — LTE/5G 行動通訊模組
