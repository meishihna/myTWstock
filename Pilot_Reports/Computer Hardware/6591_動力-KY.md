# 6591_動力-KY

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 1,822 百萬台幣
**企業價值:** 1,418 百萬台幣

動力-KY 為精密散熱風扇製造商，核心產品為顯示卡（VGA/GPU）冷卻風扇，同時生產個人電腦機殼風扇、工業用風扇及伺服器散熱模組，主要服務 AIB（顯示卡加工廠）及主機板 OEM 廠商。VGA 風扇貢獻約 87% 營收，是全球 GPU AIB 廠的主要散熱方案供應商之一，已通過 [[NVIDIA]] Referral Service Provider (RSP) 認證。為降低地緣政治風險及提升交期靈活性，公司宣布在泰國設立新廠，預計 2026 年 Q3 開始量產。

**營收結構方面**，依產品別：VGA（顯示卡）散熱風扇佔約 87%，PC 機殼風扇佔約 6%，工業用風扇佔約 4%，網通/AI 伺服器散熱佔約 3%。依地區：出口為主，客戶主要集中於中國（AIB 廠）及台灣（AIB/主機板廠）。

**核心技術與競爭優勢方面**，動力-KY 具備精密無刷直流馬達設計及風扇葉片氣動力學最佳化能力，通過 [[NVIDIA]] RSP 認證可供應 RTX 系列 GPU 的 AIB 散熱解決方案，客戶認證壁壘高。在中國及台灣均設有製造基地，可彈性因應客戶交期需求；泰國新廠有助分散地緣政治風險並滿足北美客戶的非中國製造需求。

**成長動能方面**，AI 推論端 GPU 需求爆發使 RTX 及 [[NVIDIA]] 新一代顯示卡出貨持續攀升，帶動 VGA 風扇訂單成長；伺服器及網通設備對靜音高效散熱需求增加，公司積極開拓 [[AI 伺服器]] 機箱及 GPU 加速卡散熱模組市場；泰國新廠量產後可回應北美「去中化」供應鏈需求，有望切入新客戶。

主要風險：VGA 風扇業務高度集中、AI PC 及遊戲 GPU 景氣波動影響 AIB 廠採購、泰國新廠產能爬坡風險、競爭對手削價。

## 供應鏈位置
**上游 (馬達與機構件):**
- **磁性材料:** 永久磁鐵、矽鋼片供應商
- **風扇葉片/機殼:** 塑料射出及金屬壓鑄件供應商
- **軸承:** 流體動力軸承 (FDB)、滾珠軸承廠商

**中游:**
- **VGA 散熱風扇:** **動力-KY** ([[NVIDIA]] RSP 認證，AIB 用 GPU 散熱風扇製造)
- **工業/PC 風扇:** **動力-KY** (機殼風扇、工業用風扇)

**下游 (終端應用):**
- **AIB（顯示卡廠）:** [[技嘉]]、[[微星]]、[[華碩]]、[[撼訊科技]] — RTX GPU AIB 散熱採購
- **主機板廠:** [[技嘉]]、[[微星]] — PC 機殼風扇
- **AI 伺服器:** [[NVIDIA]] 生態系 GPU 伺服器廠 — 伺服器散熱模組

## 主要客戶及供應商
### 主要客戶
- **顯示卡 AIB:** [[技嘉]]、[[微星]]、[[華碩]]、[[撼訊科技]] — GPU 散熱風扇
- **主機板/PC OEM:** 台灣主機板廠 — PC 機殼風扇

### 主要供應商
- **磁性材料:** 永久磁鐵廠、矽鋼片廠
- **軸承:** 流體動力軸承 (FDB) 廠商
- **塑料機構件:** 風扇葉片射出成型廠
