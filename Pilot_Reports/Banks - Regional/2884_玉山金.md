# 2884 - [[玉山金]]

## 業務簡介
**板塊:** Financial Services
**產業:** Banks - Regional
**市值:** 627,440 百萬台幣
**企業價值:** N/A

玉山金融控股（2884）成立於 2002 年，為台灣最具品牌溢價與數位創新的民營金控，核心子公司[[玉山銀行]]全台設有約 140 家分行。其他子公司包括[[玉山證券]]及[[玉山投信]]（2025 年收購[[保德信投信]]後更名整合）。[[玉山銀行]]信用卡發卡量及消費力道位居全台前段班，與[[Visa]]及[[Mastercard]]深度合作，多次獲《亞洲貨幣》台灣最佳本土銀行。國際佈局積極，涵蓋新加坡、越南、日本、柬埔寨等地，服務台商及東南亞在地客群。2025 年集團稅後淨利約 220 億元，EPS 達 2.1 元以上。

**營收結構方面**，依子公司（2025 年）：[[玉山銀行]]銀行業務佔集團淨利約 80%（消費金融、財富管理及企業金融），[[玉山證券]]約 10%，[[玉山投信]]約 10%。依地區：台灣約 85%，海外（東南亞、日本、北美）約 15%。信用卡手續費及財富管理為非利息收入主力。

**核心技術與競爭優勢方面**，[[玉山銀行]]以「科技+溫度」品牌定位建立高客戶忠誠度；信用卡業務（[[Visa]]/[[Mastercard]]聯名）在消費金融具深度競爭力；東南亞布局（越南、柬埔寨）切入高成長市場；[[玉山投信]]收購[[保德信投信]]後資產管理規模顯著擴大；API 開放銀行及數位金融技術領先業界。

**成長動能方面**，東南亞據點（越南、柬埔寨）受惠當地經濟高速成長帶動存放款規模擴大；信用卡消費量隨台灣消費市場成長，財富管理費收持續提升；[[玉山投信]]整合[[保德信投信]]後基金管理規模倍增；開放銀行 API 帶動 Fintech 生態系合作；企業金融受惠台灣製造業供應鏈資本支出擴張。

主要風險：民營金控受市場化競爭（[[中信金]]、[[富邦金]]）影響較大；壽險業務相對較輕，利率風險較低但成長動能也較弱；東南亞分行面臨當地政治及匯率風險；投信業務在市場下行時資產管理規模縮減；數位銀行競爭者持續增加。

## 供應鏈位置
**上游 (資金來源):**
- **存款:** 全台 140 家分行企業及個人存款
- **資本市場:** 金融債券及同業資金
- **同業資金:** [[中央銀行]]

**中游:**
- **[[玉山金融控股]]** (金控管理)
- **[[玉山銀行]]** (消費金融、企業金融、財富管理)
- **[[玉山證券]]** (證券經紀)
- **[[玉山投信]]** (資產管理，含整合後[[保德信投信]])

**下游 (服務對象):**
- **消費金融:** 信用卡（[[Visa]]/[[Mastercard]]）、個人信貸
- **企業金融:** 台灣企業聯貸、台商海外融資
- **財富管理:** 高資產客群及投信基金投資人

## 主要客戶及供應商
### 主要客戶
- **消費金融:** 台灣消費者（信用卡[[Visa]]/[[Mastercard]]聯名，消費力道全台前段班）
- **企業金融:** 台灣大中型企業聯貸及台商東南亞融資
- **財富管理:** 高資產族群及[[玉山投信]]基金投資人

### 主要供應商
- **國際支付:** [[Visa]]、[[Mastercard]] — 信用卡網絡
- **金流基礎設施:** [[財金資訊]] — 跨行交易基礎設施
- **整合資產管理:** [[保德信投信]] — 被收購整合，擴大 AUM
