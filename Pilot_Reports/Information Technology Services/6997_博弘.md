# 6997_博弘

## 業務簡介
**板塊:** Technology
**產業:** Information Technology Services
**市值:** 1,591 百萬台幣
**企業價值:** 699 百萬台幣

博弘雲端科技 (6997，Nextlink Technology) 成立於 2014 年，為[[遠傳電信]]旗下之多雲託管服務商 (Cloud MSP)，隸屬[[遠東集團]]，是台灣少數同時持有 [[AWS]]、[[Google]] Cloud（GCP）、[[Microsoft]] Azure 與[[阿里雲]]四大公有雲最高級合作夥伴認證的系統服務商，且為台灣第一家獲得 [[AWS]] MSP 認證的業者，並榮獲 [[AWS]] 台灣年度最佳諮詢合作夥伴（2024）。公司服務逾 2,500 家企業客戶，客戶留存率高達 93.2%，2025 年合併營收 44.5 億元（年增 11.2%），稅後純益 1.13 億元。

**營收結構方面**，雲端代理服務（[[AWS]]/GCP/Azure 容量轉售加上託管維運）佔 2025 年營收約 93%，專業顧問服務（雲端架構、遷移、資安顧問）佔約 4%，其餘為其他項目。目前 [[AWS]] 為最大雲端平台，GCP 服務透過子公司宏庭科技運營，Azure 為第三大平台，[[阿里雲]]覆蓋大中華區。約 20% 的客戶使用客製化託管服務（高毛利），其餘為標準授權轉售。地理上以台灣為核心市場，2026 年第一季完成越南 Renova Cloud 70% 股權收購，東南亞業務從 2026 年第二季起併入合併報表，正式開啟海外擴張。

**核心技術與競爭優勢方面**，博弘雲端是台灣唯一同時持有四大主流公有雲（[[AWS]]、GCP、Azure、[[阿里雲]]）頂級認證的中立型 MSP，進入壁壘高，企業多雲治理需求使其具備他廠難以複製的差異化定位。公司自主研發 AICOM 雲端優化管理平台，提供跨雲成本監控、AI 工作負載優化與 24/7 代管監控，協助客戶降低多雲架構的管理複雜度。依託[[遠傳電信]]母公司的企業銷售通路與品牌公信力，可觸及原本難以直接接觸的金融控股與大型製造業客群。

**成長動能方面**，企業 AI 採用浪潮推動雲端算力消費快速成長，博弘雲端作為中立型 MSP 可跨平台協助客戶部署 [[AI]] 推論與訓練工作負載，受惠於 [[AWS]]、GCP、Azure 三大平台的 AI 服務擴展。越南 Renova Cloud 的併購為東南亞市場佈局提供即戰力，越南雲端市場年複合成長率預計達 19.12%（2025–2029）。[[遠傳電信]]企業客戶通路的聯賣效應持續放大，金融控股、遊戲及高科技製造為主要成長客群。

主要風險：雲端代理業務毛利率僅約 10%，2025 年淨利反較 2024 年下滑 8.3%（儘管營收成長 11.2%），顯示成本壓力上升；營收幾乎完全依賴 [[AWS]]、GCP、[[Microsoft]] Azure 三大超大規模雲端業者的定價政策與佣金結構；越南 Renova Cloud 跨境併購存在整合風險；電信公司自有雲端子公司（[[中華電信]]雲端）及大型系統整合商（[[宏碁資訊]]等）形成直接競爭；[[阿里雲]]業務受地緣政治影響存在不確定性。

## 供應鏈位置
**上游 (全球公有雲原廠):**
- **核心夥伴:** [[AWS]] ([[Amazon]] Web Services) — 台灣 Premier Tier 頂級合作夥伴，最大雲端平台
- **雲端平台:** [[Google]] Cloud (GCP) — Premier 合作夥伴，透過子公司宏庭科技運營
- **雲端平台:** [[Microsoft]] (Azure) — 頂級合作夥伴
- **雲端平台:** [[阿里雲]] (Alibaba Cloud) — 大中華區 Premium 合作夥伴

**中游 (雲端託管與加值服務):**
- **MSP:** **博弘雲端** (多雲架構諮詢、雲端搬遷託管、AICOM 雲端優化管理平台、[[AI]] 工作負載管理、24/7 代管監控)
- **海外子公司:** Renova Cloud（越南，2026 Q1 完成 70% 股權收購）— [[AI]] 專業雲端 MSP，深耕越南金融業

**下游 (終端客戶):**
- **高科技製造:** 半導體與電子製造業 — 雲端基礎設施
- **金融:** 金融控股與銀行 — 高規格多雲代管與[[資安]]
- **遊戲/媒體:** 手機遊戲與媒體娛樂業 — 彈性算力需求
- **零售/電商:** 電商與零售業 — 雲端基礎設施
- **中大型企業:** 逾 2,500 家各類企業 — 多雲代管服務

## 主要客戶及供應商
### 主要客戶
- **高科技製造:** 半導體與電子製造業 — 多雲架構建置與 [[AI]] 工作負載管理
- **金融:** 金融控股與銀行機構 — 高規格雲端代管與資安防護（高成長客群）
- **遊戲/媒體:** 手機遊戲發行商、媒體娛樂業 — 全球彈性算力部署
- **零售/電商:** 電商與零售業者 — 雲端基礎設施
- **策略通路:** [[遠傳電信]] — 母公司兼聯賣通路，協助觸及企業客戶

### 主要供應商
- **核心夥伴:** [[AWS]] — 台灣 Premier Tier + MSP 頂級合作夥伴，台灣年度最佳諮詢合作夥伴（2024）
- **雲端平台:** [[Google]] Cloud (GCP) — Premier 合作夥伴（透過子公司宏庭科技）
- **雲端平台:** [[Microsoft]] (Azure) — 頂級合作夥伴
- **雲端平台:** [[阿里雲]] (Alibaba Cloud) — 大中華區 Premium 合作夥伴
- **母集團:** [[遠傳電信]] / [[遠東集團]] — 策略股東、企業銷售通路與電信資源
