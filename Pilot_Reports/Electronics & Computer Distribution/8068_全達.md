# 8068 - 全達

## 業務簡介
**板塊:** Technology
**產業:** Electronics & Computer Distribution
**市值:** 1,365 百萬台幣
**企業價值:** 1,746 百萬台幣

全達國際 (8068，[[Chander Electronics]]) 隸屬於[[威盛電子]]（VIA Technologies）集團，成立於 1997 年，以亞太區半導體 IC 零組件及軟體代理為核心業務，並跨足電動車充電設備新事業。公司第二大股東為遊戲開發商[[大宇資]]（持股約 17%），另持有第三方支付平台[[藍新科技]]約 32% 股權，後者為非核心但具財務價值之轉投資資產。年營收規模約 8–9 億元，屬中小型上櫃通路商。

**營收結構方面**，2024 年特定應用 IC 代理佔約 68%，軟體代理（[[Microsoft]] Windows IoT、Azure IoT Edge、Microsoft 365）佔約 28%，其他（電動車充電、陶瓷材料等）佔約 3–4%。地理分佈以外銷為主（約 62%），主要為中國大陸消費電子製造商；台灣內銷約 38%。代理 IC 以[[星宸科技]]（SigmaStar）多媒體與影像 SoC 為主，下游客戶集中於中國 TV OEM 與 IP 攝影機廠商；另代理 [[Intelligo]] 邊緣 AI 推論晶片與[[威盛電子]] VIA Pixetto AI 視覺感測器模組。

**核心技術與競爭優勢方面**，全達在[[威盛電子]]集團生態系中扮演亞太通路角色，掌握集團 IC 產品於台灣及中國市場的分銷管道；[[Microsoft]] 嵌入式 Windows IoT 授權代理為較具差異化的利基業務，服務物聯網設備製造商；子公司[[藍新科技]]（第三方支付）雖非本業，但按權益法認列之投資收益長期挹注母公司淨利，彌補 IC 通路代理毛利率過低（4–8%）造成的營業虧損。新事業方面，達拉電能子公司推出 E-HERO 自主移動式電動車充電機器人，為台灣首座移動充電機器人，搭配 DARA GO App 提供按需充電服務，具先行者話題性。

**成長動能方面**，E-HERO 充電機器人進入商業化初期，目標在 3 年內於全台部署 600 台，以老舊社區、商業大樓、旅館等無法安裝固定充電樁的場景為切入口，並規劃向東南亞與中東市場輸出；[[Intelligo]] 邊緣 AI 推論晶片及 VIA Pixetto AI 視覺模組跟隨工業自動化與智慧製造需求有望帶動 IC 代理業務增量；[[藍新科技]]隨台灣第三方支付交易量持續成長，權益法收益可望穩健提升。

主要風險：IC 代理毛利率長期僅 4–8%，固定費用結構導致持續性營業虧損，依賴非本業之[[藍新科技]]投資收益支撐帳面獲利，本業獲利能力薄弱；[[星宸科技]] SoC 下游客戶高度集中於中國消費電子廠商，受地緣政治與關稅風險衝擊；E-HERO 充電機器人仍處早期商業化，部署進度與盈利時程不確定；IC 通路競爭激烈，面對[[大聯大]]、[[文曄]]等大型通路商的規模壓制。

## 供應鏈位置
**上游（IC 設計與軟體原廠）：**
- **多媒體/影像 SoC:** [[星宸科技]] (SigmaStar) — LCD-TV、IP 攝影機、IoT 晶片
- **邊緣 AI 晶片:** [[Intelligo]] — 邊緣 AI 推論處理器
- **AI 視覺模組:** [[威盛電子]] VIA Pixetto — AI 視覺感測器
- **嵌入式軟體:** [[Microsoft]] — Windows IoT、Azure IoT Edge 授權
- **充電設備零件:** 電池模組與電力電子元件供應商 — E-HERO 核心零件

**中游（代理通路與系統整合）：**
- **全達國際** (IC 與軟體代理行銷；E-HERO 充電機器人商業化)
- **達拉電能** (子公司，E-HERO 移動式充電機器人運營)

**下游（終端應用）：**
- **消費電子製造:** 中國 TV OEM 與 IP 攝影機製造商 — [[星宸科技]] SoC
- **物聯網裝置:** 台灣 IoT 設備製造商 — [[Microsoft]] Windows IoT 授權
- **電動車充電:** 商業停車場、老舊社區、旅館 — E-HERO 按需充電服務

## 主要客戶及供應商
### 主要客戶
- **中國消費電子製造:** 中國 TV OEM 廠與 IP 攝影機製造商 — [[星宸科技]] SoC 晶片
- **IoT 設備製造:** 台灣物聯網裝置製造商 — [[Microsoft]] Windows IoT 嵌入式授權
- **工業/教育應用:** 工業自動化整合商與教育機構 — [[Intelligo]] 邊緣 AI、VIA Pixetto 模組
- **電動車充電場域:** 商業停車場、住宅社區、旅館 — 達拉電能 E-HERO 充電服務

### 主要供應商
- **影像 SoC:** [[星宸科技]] (SigmaStar) — 多媒體 SoC 主力代理品牌
- **AI 晶片:** [[Intelligo]]、[[威盛電子]] — 邊緣 AI 推論晶片與 AI 視覺模組
- **嵌入式軟體:** [[Microsoft]] — Windows IoT、Azure IoT Edge 授權代理
- **財務性投資:** [[藍新科技]] (持股約 32%) — 第三方支付，按權益法認列收益
