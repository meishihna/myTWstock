# 3687 - 歐買尬

## 業務簡介
**板塊:** Communication Services
**產業:** Electronic Gaming & Multimedia
**市值:** 2,291 百萬台幣
**企業價值:** 3,209 百萬台幣

茂為歐買尬數位科技 (3687，MacroWell OMG) 為台灣數位娛樂與金融科技集團，已成功從早期線上遊戲營運商轉型為橫跨第三方支付、電子支付與遊戲平台的數位雲端企業。核心三大支柱為：旗下子公司 [[綠界科技]] (6763) 占合併營收逾九成，是台灣第三方支付龍頭；旗下歐付寶為台灣首批取得電子支付執照的業者，深耕跨境支付與微小商家服務；OMG 遊戲派對平台則負責代理營運多款線上遊戲與手遊，搭配 FunPoint 虛寶交易平台提供遊戲數位金流服務。集團亦持有 [[精誠資訊]] 旗下精誠金融之股權作為財務性投資。

**營收結構方面**，第三方支付（[[綠界科技]]）佔合併營收約 93%，遊戲及其他業務佔約 7%。地理分布以台灣市場為主，[[綠界科技]] 服務逾數十萬中小型電商賣家，歐付寶專注台灣本地實體微小商家及跨境支付。2025 年合併營收 18.28 億元，年增 6.1%，受惠綠界科技處分轉投資精誠金融之業外收益，稅後淨利大增。

**核心技術與競爭優勢方面**，[[綠界科技]] 整合信用卡、[[Visa]]、[[Mastercard]] 信用卡收單、銀行轉帳、超商代碼、虛擬帳號等多元金流通道，具備高黏著性的電商賣家生態系，競爭對手包括 [[藍新科技]]、[[LINE Pay]]，但 [[綠界科技]] 在中小型電商市場市佔率領先。歐付寶鎖定微小商家及跨境支付場景，與 [[綠界科技]] 形成互補。FunPoint 平台則以遊戲虛寶交易媒合為差異化，提供履約保證機制。集團轉投資財務槓桿讓母公司每股盈餘彈性顯著。

**成長動能方面**，[[綠界科技]] 受益於台灣電商市場滲透率持續提升，中小企業數位轉型加速；歐付寶跨境支付需求因台灣企業海外電商布局而成長；FunPoint 虛寶交易平台拓展遊戲 B2B 金流服務市場；[[綠界科技]] 獨立上櫃後市值持續提升，帶動母公司投資收益。此外，AI 手遊《Luna：AI月神之遠征》自研產品嘗試為遊戲業務注入新動能。

主要風險：[[綠界科技]] 在合併報表中佔比過高，子公司估值波動對母公司影響顯著；電子支付市場競爭激烈，[[LINE Pay]]、[[街口支付]]、[[全支付]] 等強敵持續搶市；遊戲業務規模持續萎縮，整體遊戲品牌影響力式微；法規風險方面，金管會對電子支付及第三方支付之監管趨嚴，可能提高合規成本。

## 供應鏈位置
**上游（原料與關鍵元件）：**
- **金融基礎設施:** [[Visa]]、[[Mastercard]] 信用卡收單網絡、銀行清算系統
- **遊戲內容:** 國內外遊戲開發商 — IP 授權與遊戲代理
- **雲端基礎設施:** 伺服器代管與雲端服務供應商

**中游（公司定位）：**
- **第三方支付:** [[綠界科技]] (6763)（台灣第三方支付龍頭，中小電商金流服務）
- **電子支付:** 歐付寶（跨境支付與電子錢包）
- **遊戲平台:** **歐買尬**（OMG 遊戲派對平台、FunPoint 虛寶交易平台）

**下游（終端應用）：**
- **電商賣家:** 中小型電商賣家 — 使用 [[綠界科技]] 金流收款
- **實體商家:** 微小店家 — 使用歐付寶行動支付
- **遊戲消費者:** 線上遊戲與手遊玩家 — OMG 平台服務
- **直播電商:** 直播賣貨業者 — FunPoint 金流整合

## 主要客戶及供應商
### 主要客戶
- **電商平台:** 中小型電商賣家、網路服務平台 — 使用 [[綠界科技]] 第三方支付金流
- **實體零售:** 微小店家、自雇業者 — 使用歐付寶電子支付工具
- **遊戲消費者:** 線上遊戲與手遊玩家 — OMG 遊戲派對平台
- **遊戲業者:** 遊戲虛寶買賣雙方 — FunPoint 虛寶交易平台媒合

### 主要供應商
- **金融清算:** [[Visa]]、[[Mastercard]] 信用卡收單機構 — 金流清算基礎設施
- **遊戲內容:** 國內外遊戲開發商 — IP 授權與遊戲代理協議
- **轉投資關係:** [[綠界科技]] (6763) — 最重要子公司，貢獻合併營收逾九成
- **財務投資:** [[精誠資訊]] 旗下精誠金融 — 轉投資財務性持股
