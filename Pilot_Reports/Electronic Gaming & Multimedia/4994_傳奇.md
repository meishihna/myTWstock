# 4994 - 傳奇

## 業務簡介
**板塊:** Communication Services
**產業:** Electronic Gaming & Multimedia
**市值:** 5,510 百萬台幣
**企業價值:** 4,501 百萬台幣

傳奇網路遊戲 (4994，X-Legend Entertainment) 為台灣知名遊戲研發與發行商，以日系動漫畫風之 MMORPG 聞名，旗下代表作品包含《精靈樂章》(Grand Fantasia)、《幻想神域》(Aura Kingdom)、《晴空物語》等，深受日本、台灣及全球玩家喜愛。公司採「自研自營」與「授權海外」並行策略，2016 年起積極拓展 Global Server 直營業務，並收回先前授權予 [[Aeria Games]] 的歐美市場，轉為直接面對全球玩家，提升自主獲利空間。

**營收結構方面**，遊戲收入佔總營收約 98%，權利金授權收入佔約 2%。地理分布上，日本市場佔全年營收約 42%，台灣市場佔約 39%，其他地區佔約 19%。2024 年全年營收 15.84 億元，毛利率 65.9%；2025 年受新遊戲《晴空物語》PC 版認列天數較少及《幻想神域》PC 版延期上線影響，全年營收下滑至 11.85 億元，但長線遊戲生命週期管理仍為核心優勢。

**核心技術與競爭優勢方面**，傳奇網路具備自主遊戲 IP 研發能力，以日系輕鬆可愛美術風格深耕全球 MMORPG 細分市場，形成差異化競品壁壘。遊戲引擎採用 [[Unity]]，雲端基礎設施利用 [[iKala]] 與 [[Google Cloud]]，控制研發成本。IP 轉手遊化策略成功延長既有 IP 生命週期，同一世界觀多平台發行提升玩家黏著度。自營 Global Server 相比授權模式毛利率更高，可直接掌握玩家數據與付費行為。

**成長動能方面**，2026 年規劃推出輕量化 MORPG 新作與《Pew Pew Slime Lite》台港版，拓展新玩家族群；持續深耕日本市場，四款全球版 PC 遊戲（《聖境傳說》、《星界神話》、《精靈樂章》、《晴空物語》）穩定貢獻收入；手遊版本強化日本市場投放，以精準廣告策略控制獲客成本；長線策略聚焦「延長遊戲生命週期」，降低新遊戲失敗風險，穩定基本盤。

主要風險：遊戲生命週期有限，核心 IP 老化速度加快；新遊戲開發進度延誤對短期營收造成衝擊（如《幻想神域》PC 版已有延期前例）；日本市場高度依賴 [[Apple]] App Store 及 [[Google]] Play 平台抽成（約 30%），壓縮手遊毛利；遊戲市場競爭激烈，大型開發商如 [[miHoYo]]、[[Nexon]] 等持續搶占 MMORPG 玩家份額。

## 供應鏈位置
**上游（原料與關鍵元件）：**
- **遊戲引擎:** [[Unity]] — 遊戲開發引擎工具
- **雲端服務:** [[iKala]]、[[Google Cloud]] — 伺服器與雲端基礎設施
- **廣告投放:** [[Google]] Ads、[[Meta]] — 玩家獲取行銷渠道
- **外部 IP:** 少數外部 IP 合作授權方

**中游（公司定位）：**
- **自研發行:** **傳奇網路** (X-Legend)（MMORPG 與手遊自主研發、台灣與全球直營）
- **海外授權:** 部分遊戲授權予海外代理商 — 權利金收入

**下游（終端應用）：**
- **行動平台:** [[Apple]] App Store、[[Google]] Play — 手遊上架通路（平台抽成約 30%）
- **PC 平台:** [[Steam]] — PC 遊戲發行通路
- **全球玩家:** 日本（42%）、台灣（39%）、其他地區（19%）之 MMORPG 與手遊玩家

## 主要客戶及供應商
### 主要客戶
- **B2C 直營玩家:** 全球遊戲玩家 — 遊戲內付費為主要收入（日本佔 42%、台灣佔 39%）
- **B2B 授權代理:** 海外遊戲代理運營商 — 授權金與分潤收入（佔比約 2%）

### 主要供應商
- **平台通路:** [[Apple]]、[[Google]]、[[Steam]] — 遊戲上架、平台服務費（約 30% 抽成）
- **廣告行銷:** [[Google]] Ads、[[Meta]] — 玩家獲取廣告投放
- **遊戲引擎:** [[Unity]] — 開發工具授權
- **雲端服務:** [[iKala]]、[[Google Cloud]] — 遊戲伺服器基礎設施
