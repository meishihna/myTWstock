# 8048 - 德勝

## 業務簡介
**板塊:** Technology
**產業:** Communication Equipment
**市值:** 3,097 百萬台幣
**企業價值:** 2,259 百萬台幣

德勝科技（8048，[[Ruby Tech]]）為台灣深耕網路通訊設備逾四十年之專業 OEM/ODM 製造商，1982 年創立，總部位於台北市，以品牌名稱 Rubytech 行銷全球，具備超過 230 種現行乙太網路 [[PoE]] 交換機型號，為全球規模最大之乙太網路 PoE 交換器 OEM/ODM 廠之一。核心業務高度集中於光纖區域網路及乙太網路交換設備研發製造，主要產品線涵蓋 [[PoE]] 乙太網路交換器（管理型、非管理型，1G 至 100G 全速率）、工業級交換器（車規、工業、戶外運營商規格）、光纖媒體轉換器、[[GEPON]] OLT/ONU 光纖到府設備及 L3 Host Stacking 100G 高速網路交換器，並跨入整合衛星數據機、防火牆與路由器功能之 Server Switch 產品（已實際部署於船舶及無人機場域）。2025 年全年營收 10.11 億元，毛利率升至 34.67%，全年 EPS 2.67 元（年增 68%），法說會（2025 年 12 月 18 日）揭示訂單能見度延伸至次季，NDAA 合規認證已成功開啟美國政府採購市場。

**營收結構方面**，德勝科技以 [[PoE]] 乙太網路交換器為最大收入來源，工規與商規合計逾八成，已延伸至 L3 Host Stacking 100G 高速交換器；其次為工業交換器與光纖設備（[[GEPON]] OLT/ONU、光纖媒體轉換器），佔約一成五；衛星 Server Switch 及邊緣運算設備等新興業務佔比仍小但成長快速。地理上歐美市場佔約八成，以美國、歐洲品牌代工客戶（Tier-1 及 Tier-2/3 網通品牌）為主；亞洲市場約佔兩成，含日本及東南亞系統整合商。2025 年 Q3 毛利率達 38.75%（法說會揭示），Q4 單季 EPS 達 1.0 元，全年 EPS 2.67 元。

**核心技術與競爭優勢方面**，德勝科技核心優勢在於軟硬體高度客製化能力，可依國際品牌客戶需求提供深度定製方案，支援 L2/L3 管理功能自主開發，與僅提供白牌硬體之競爭者形成明顯區隔。公司全系列產品已完成 NDAA（美國國防授權法案）及 TAA（貿易協定法案）合規設計，強化在美國政府採購及企業敏感網路市場之競爭力，受惠於美中貿易戰帶動之合規轉單效應。上游晶片採用 [[瑞昱]]（Realtek）、[[Broadcom]] 主流方案，確保供應穩定；公司已取得 ISO 9001、ISO 14001、ISO 27001（2022 最新版）資訊安全管理系統及 ISO 27034 軟體資安開發認證，為進入高安全要求之政府及企業敏感網路市場之重要憑證。衛星 Server Switch 產品已成功切入船舶、無人機等高可靠度場域，形成差異化競爭點。

**成長動能方面**，[[AI 伺服器]] 及資料中心建設浪潮帶動高速乙太網路交換器（25G/100G）需求激增，德勝 L3 100G 產品線精確卡位此趨勢；NDAA 合規要求迫使品牌客戶向台灣合規 ODM 廠轉單，德勝因 NDAA/TAA 雙認證而受惠明顯；衛星數據服務市場崛起，Server Switch 整合衛星數據機、防火牆與路由器功能，在船舶、無人機、邊緣計算等場域已實際部署；歐美客戶因應供應鏈分散化加速佈局台灣合規製造商；[[5G]] 基礎建設及邊緣運算設備部署持續帶動企業級網路設備採購，公司已規劃 5G/6G 基礎建設設備為中長期成長主軸。

主要風險：客戶高度集中於少數歐美 Tier-1 品牌，主要客戶訂單削減將直接衝擊營收，2023 年至 2025 年營收從 17.9 億元降至 10.1 億元，顯示大客戶庫存調整影響深遠；[[PoE]] 交換器產品同質化競爭激烈，中國廠商持續以低價搶市；[[瑞昱]]、[[Broadcom]] 晶片供貨週期長（4-6 個月），備料失誤將影響交期與庫存；美中貿易政策若出現大幅轉向，NDAA 轉單紅利可能縮減；衛星 Server Switch 及邊緣運算等新業務規模仍小，能否順利放量尚待驗證。

## 供應鏈位置
**上游 (網通晶片與電子元件):**
- **乙太網路交換晶片:** [[瑞昱]]（Realtek）、[[Broadcom]] — [[PoE]] 交換器及 [[GEPON]] 晶片（核心供應，供貨週期 4-6 個月）
- **光收發模組:** SFP/SFP+ [[光收發模組]] 供應商 — 光纖媒體轉換器及 100G 交換器光接口
- **PoE 電源元件:** [[PoE]] 供電控制器及高效率電源供應器廠
- **PCB 與被動元件:** 印刷電路板製造商及電子被動元件廠

**中游 (網路設備 OEM/ODM 製造):**
- **PoE 交換器:** **德勝科技**（管理型／非管理型 [[PoE]] 乙太網路交換器，1G 至 100G 全速率，逾 230 型號）
- **工業交換器:** **德勝科技**（車規、工業級、戶外運營商規格交換器）
- **光纖設備:** **德勝科技**（[[GEPON]] OLT/ONU、光纖媒體轉換器）
- **高速交換器:** **德勝科技**（L3 Host Stacking 100G 高速交換器）
- **衛星 Server Switch:** **德勝科技**（整合衛星數據機、防火牆、路由器之複合設備，部署於船舶及無人機）

**下游 (系統整合商、品牌客戶與新興應用):**
- **國際品牌:** 歐美 Tier-1/Tier-2/3 網通品牌 — OEM/ODM 代工（佔約八成，NDAA 轉單受惠）
- **美國政府市場:** NDAA/TAA 合規採購 — 企業及政府敏感網路設備
- **系統整合商:** 歐美及亞洲 SI 與寬頻佈建工程商
- **衛星與邊緣應用:** 船舶、無人機、邊緣運算設備部署客戶

## 主要客戶及供應商
### 主要客戶
- **歐美 Tier-1 品牌:** 美國、歐洲國際網通品牌 — [[PoE]] 交換器 OEM/ODM（外銷佔八成，NDAA/TAA 合規轉單受惠）
- **美國政府市場:** NDAA/TAA 合規採購 — 企業敏感網路及政府設備採購
- **系統整合商:** 歐美及亞洲區域型網路 SI — 寬頻佈建工程設備採購
- **衛星應用客戶:** 船舶及無人機業者 — Rubytech Server Switch 衛星數據整合設備
- **有線電視業者:** MSO 及電信商 — [[GEPON]] ONU/OLT 光纖接取設備

### 主要供應商
- **交換器晶片:** [[瑞昱]]（Realtek）、[[Broadcom]] — 乙太網路交換器及 [[GEPON]] 晶片（主要供應，供貨週期 4-6 個月）
- **光收發模組:** SFP/SFP+ [[光收發模組]] 廠商 — 100G 及光纖媒體轉換器接口
- **電源元件:** [[PoE]] 供電控制器及電源供應器廠
