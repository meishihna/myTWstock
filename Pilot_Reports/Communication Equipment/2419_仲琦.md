# 2419 - 仲琦

## 業務簡介
**板塊:** Technology
**產業:** Communication Equipment
**市值:** 7,776 百萬台幣
**企業價值:** 7,350 百萬台幣

仲琦科技 (2419，[[Hitron Technologies]]) 為 [[明泰]] (Alpha Networks，3380) 旗下子公司，隸屬 [[明基友達集團]]，專注有線電視寬頻接取設備，為北美 [[DOCSIS]] 纜線數據機市場重要供應商，具備深厚 CableLabs 認證技術根基。核心產品涵蓋 [[DOCSIS]] 3.1/4.0 纜線數據機與閘道器、[[Wi-Fi 7]] 無線路由器與 Mesh 延伸器、[[PON]] 光纖接取 ONT/ONU、[[5G]] CPE 固定無線接取設備及 HitronCloud 雲端家庭網路管理平台。2025 年全年營收 88.8 億元，年減 2.3%，毛利率 18.8%，稅後虧損 1.17 億元。公司已獲北美第五大有線電視多系統營運商採用 [[DOCSIS]] 4.0 設備，並與美系低軌衛星大廠簽訂 [[Wi-Fi]] 路由器五年長單。

**營收結構方面**，[[DOCSIS]] 纜線數據機與閘道器長期佔整體營收逾八成，為絕對核心；[[Wi-Fi 7]] 路由器與 Mesh 設備、[[5G]] FWA 為成長性板塊；[[PON]] 光纖設備為歐洲及亞太市場補充。地理上以北美有線電視 MSO 市場為主力，歐洲 DOCSIS 4.0 及 Wi-Fi 7 新客戶陸續開發中。2026 年核心成長動能來自 DOCSIS 4.0 北美量產、Wi-Fi 7 整合應用及 5G FWA 出貨。

**核心技術與競爭優勢方面**，仲琦具備 CableLabs 認證 [[DOCSIS]] 4.0 完整技術開發能力，係業界最早完成 DOCSIS 4.0 商用部署之廠商之一，已由 [[Mediacom]] 選為首波商用合作夥伴，並助力北美第五大 MSO 網路升級。公司主晶片仰賴 [[Broadcom]] DOCSIS 規格核心供應，搭配 [[Qualcomm]]、[[聯發科]] Wi-Fi 7 晶片組合，形成完整寬頻產品矩陣。HitronCloud 雲端管理平台強化 B2B 服務黏著度，加速向 B2C 零售與企業市場轉型。

**成長動能方面**，北美寬頻升級至 DOCSIS 4.0 的大型換代浪潮正式啟動，MSO 客戶資本支出重啟；[[Wi-Fi 7]] 在消費及企業端的換代需求帶動高單價設備出貨；低軌衛星 [[Wi-Fi]] 路由器五年長單提供穩定基礎；歐洲 DOCSIS 4.0 及 Wi-Fi 7 新客戶擴展增添成長彈性。

主要風險：DOCSIS 市場高度集中於北美 MSO 客戶，採購週期不確定性大；[[Broadcom]] DOCSIS 晶片供應寡占導致議價空間受限；B2C 零售市場競爭激烈，品牌知名度低於主要競爭對手；匯率波動 (主要以美元計價) 對台幣報表獲利形成壓力。

## 供應鏈位置
**上游 (寬頻通訊晶片):**
- **DOCSIS 晶片:** [[Broadcom]] — DOCSIS 纜線數據機主晶片 (高度寡占)
- **Wi-Fi 晶片:** [[Qualcomm]]、[[聯發科]] — Wi-Fi 6/7 無線模組
- **光通訊元件:** [[PON]] 光纖接取晶片及光模組

**中游 (寬頻設備設計製造):**
- **纜線數據機:** 仲琦 ([[DOCSIS]] 3.1/4.0 數據機/閘道器)
- **無線路由器:** 仲琦 ([[Wi-Fi 7]] Mesh 路由器/延伸器)
- **光纖設備:** 仲琦 ([[PON]] ONT/ONU 光纖接取)
- **5G CPE:** 仲琦 ([[5G]] FWA 固定無線接取設備)

**下游 (有線電視與電信營運商):**
- **北美 MSO:** [[Mediacom]] (DOCSIS 4.0 首波)、北美第五大 MSO — 多系統有線電視營運商
- **低軌衛星:** 美系低軌衛星大廠 Wi-Fi 路由器五年長單
- **歐洲電信:** 歐洲有線寬頻營運商 (DOCSIS 4.0/Wi-Fi 7 新客戶)
