# 6561_是方

## 業務簡介
**板塊:** Communication Services
**產業:** Telecom Services
**市值:** 25,512 百萬台幣
**企業價值:** 27,571 百萬台幣

是方電訊股份有限公司（6561，[[Chief Telecom]]）隸屬於[[中華電信]]集團（持股約46%），為全台規模最大、最具中立性的電信級網際網路[[資料中心]]（IDC）營運商，1991年創立、2018年上市。是方電訊同時是全台最大海纜交換中心（TPCX），串接逾10條國際海底光纜，並為台灣唯一同時直連[[AWS]]（Direct Connect）、[[Microsoft Azure]]（ExpressRoute）、[[Google Cloud]]（Cloud Interconnect）、[[Oracle Cloud]]（FastConnect）及IBM Cloud等五大公有雲的中立IDC，戰略地位極為稀缺。隨[[AI 伺服器]]算力需求爆發，2024年6月啟用的第三棟IDC（LY2，聯雲智能資料中心）以支援每機架150kW高密度液冷機房為核心，成功轉型為AI算力「包租公」；第四棟位於台中科學園區的AIDC（中科）投資逾新台幣30億元，2028年預計商轉。

**營收結構方面**，依2024年全年營收約新台幣37.9億元（年增17%）分析：IDC機架租用（Colocation）佔約39%；資料網路服務（含TPIX網際網路交換、三環光纖骨幹、雲端直連CCX）佔約39%；雲端應用服務（CCX多雲交換、代管、DR備援）佔約16%；語音服務（持續下滑）佔約6%。2025年全年營收升至新台幣39.4億元（年增4%），毛利率突破52%，EPS達15.75元（歷史新高）。

**核心技術與競爭優勢方面**，是方電訊擁有台灣密度最高的國際海底光纜直連能力，TPCX（海纜交換中心）接入SJC2、Apricot等主要線纜；TPIX（網際網路交換中心）擁有264+會員，全球排名前50，節點延伸至日本、新加坡、香港、美西及歐洲；LY2採全液冷設計（台灣第一），單機架電力密度10-150kW，可容納[[NVIDIA]] H100/H200/GB200 GPU叢集；與[[緯創]]（NVIDIA GPU伺服器供應）及AI效能軟體商Zettabyte形成「鐵三角」AI算力方案。

**成長動能方面**，AI需求推動機架電力密度提升3-5倍，同面積帶來更高租金收入；LY2 2025 H1填充率達74%，目標2028年全滿；中科AIDC已有國際CSP、製造業及金融機構簽署意向書，2028年商轉後可貢獻年收入逾新台幣10億元；[[AWS]]、[[Microsoft Azure]]、[[Google Cloud]]持續擴大台灣投資帶動雲端直連需求；台灣IDC市場2020-2027年CAGR達23.6%，遠高於全球15.9%；[[GMI Cloud]]等AI算力服務商合作擴大服務生態。

主要風險：IDC資本支出高（2024年CAPEX逾新台幣15.6億元），中科AIDC逾30億投資若填充延遲將拖累ROE；LY2一次性建設收入高基期導致2026年營收年比承壓；[[中華電信]]同時為股東及競爭者，關聯方集中風險顯著；[[台灣大哥大]]積極建設AIDC形成競爭；台灣地震與電力供應約束為潛在運營風險。

## 供應鏈位置
**上游 (基礎建設與頻寬):**
- **光纖頻寬:** [[中華電信]]、[[台灣大哥大]]、[[遠傳電信]] — 第一類電信商光纖頻寬承租
- **伺服器設備:** [[Dell]]、[[HPE]]、[[Super Micro]] — 機房伺服器與儲存設備
- **國際海纜:** [[Meta]]、[[KDDI]]、Singtel — SJC2、Apricot等國際海底光纜共建方
- **綠電供應:** 台灣綠電供應商 — IDC機房再生能源電力
- **AI加速器:** [[NVIDIA]] — GPU伺服器（LY2高密度機架租戶使用）

**中游 (IDC營運與雲端服務):**
- **IDC機房:** **[[是方電訊]]** — 電信級高密度機架租用（Colocation）
- **雲端直連:** **[[是方電訊]]** — 多雲直連交換（AWS Direct Connect/Azure ExpressRoute/GCP Cloud Interconnect）
- **加值服務:** **[[是方電訊]]** — 私有雲建置、DR備援、代管服務

**下游 (終端客戶):**
- **國際公有雲:** [[AWS]]、[[Microsoft Azure]]、[[Google Cloud]]、[[Oracle Cloud]] — 台灣區直連節點
- **跨國科技企業:** [[Meta]]、[[Amazon]]、Shopee — IDC機架租用
- **金融機構:** 台灣主要銀行 — DR備援與合規機房
- **遊戲娛樂業:** 國內外遊戲公司 — CDN與伺服器託管

## 主要客戶及供應商
### 主要客戶
- **國際公有雲:** [[AWS]]、[[Microsoft Azure]]、[[Google Cloud]]、[[Oracle Cloud]] — 台灣唯一同時直連五大雲（含IBM Cloud）的中立IDC，雲端直連最大客戶群
- **跨國科技企業:** [[Meta]]、[[Apple]]、[[Netflix]]、Shopee — IDC機架租用
- **AI算力服務商:** [[GMI Cloud]] — LY2 AI算力雲服務合作夥伴
- **金融機構:** 台灣主要商業銀行及保險公司 — DR備援機房與合規託管
- **電信業（TPIX成員）:** [[中華電信]]、[[遠傳電信]]、[[台灣大哥大]] — 網際網路交換節點租戶

### 主要供應商
- **光纖頻寬:** [[中華電信]]、[[台灣大哥大]]、[[遠傳電信]] — 主要頻寬承租來源
- **伺服器設備:** [[Dell]]、[[HPE]]、[[Super Micro]] — 機房伺服器與儲存設備
- **海纜共建夥伴:** [[Meta]]、[[KDDI]] — SJC2/Apricot國際海底光纜共建
- **AI伺服器供應:** [[緯創]] — NVIDIA H100/H200/GB200 GPU伺服器（LY2鐵三角合作方）
- **AI加速器:** [[NVIDIA]] — GPU伺服器核心晶片（LY2高密度機架需求基礎）
