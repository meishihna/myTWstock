# 7828 - 創新服務

## 業務簡介
**板塊:** Industrials
**產業:** Specialty Industrial Machinery
**市值:** 74,306 百萬台幣
**企業價值:** 74,215 百萬台幣

創新服務 (7828，Innostar Service) 成立於2013年，發跡自 MEMS[[探針卡]]自動植針設備（Auto Probe Insertion，API），為全球少數具備高精度雙臂植針機台的設備廠。2025年獲全球探針卡市占第二大廠[[Technoprobe]]入股（持股近一成），取得台灣及中國探針卡代理與維修服務授權。三大業務：(1) API 植針設備及自動化裝置；(2) [[探針卡]]銷售、維修與材料包；(3) 先進封裝模組（銅柱及[[TGV]]玻璃通孔中介層）。2026年4月正式轉上櫃，毛利率長期維持75%至80%。

**營收結構方面**，2026年植針設備及自動化裝置（裝置業務）佔營收約八成，探針卡銷售與材料包各佔約一成。2025全年營收7.16億元、年增76%，毛利率76.25%；2026年Q1毛利率突破80%，年增51.8%。公司已引進雷射清潔、自動掃針、雷射縮針等新型自動化裝置，平均售價更高，2027至2028年三大業務佔比將趨向均衡。

**核心技術與競爭優勢方面**，創新服務研發的「雙臂直升機」植針機每台每日可植入一萬根探針，效率遠超傳統競品；與[[台積電]]長期合作驗證植針設備，為其唯一自動化植針設備供應商之一。攜手晶呈科共同開發[[TGV]]玻璃通孔中介層，已開發千瓦級散熱方案，可服務下一代GPU封裝；台中新廠2026年Q2投產後組裝產能擴大1.5倍。

**成長動能方面**，[[AI 伺服器]]帶動[[CoWoS]]、[[HBM]]及高速運算測試需求全面爆發，[[探針卡]]自動化製造需求水漲船高；訂單能見度已直達2028年，急單持續湧入。[[TGV]][[玻璃基板]]中介層最快2026年底完成封裝驗證、2027年在高速儲存晶片率先量產，2028年後切入GPU與CPU領域。

主要風險：高度依賴[[Technoprobe]]策略夥伴關係，若合作生變將衝擊代理業務；[[TGV]]量產化時程延後風險；台中新廠大幅擴產帶來折舊壓力；客戶集中於少數晶圓代工及封測廠；新型自動化裝置推出時程若延後，2026年下半年收入節奏將受影響。

## 供應鏈位置
**上游 (零組件):**
- **光學與視覺:** 精密視覺鏡頭、相機模組廠商
- **雷射光源:** 工業雷射光源供應商
- **奈米滑軌與機械手臂:** 高精密運動控制元件廠商

**中游:**
- **創新服務** (MEMS[[探針卡]]自動植針設備; 自動化裝置; 銅柱模組; [[TGV]]玻璃通孔中介層)
- **[[Technoprobe]]:** 策略股東兼代理夥伴，提供探針卡供創新服務銷售

**下游 (終端應用):**
- **晶圓代工:** [[台積電]]（植針設備長期合作客戶）
- **封測廠:** 使用[[探針卡]]的先進測試廠
- **先進封裝:** [[玻璃基板]]TGV中介層（目標[[AI 伺服器]]及[[HBM]]應用）

## 主要客戶及供應商
### 主要客戶
- **[[台積電]]:** 主要植針設備合作客戶，AI晶片測試推動探針卡需求
- **[[Technoprobe]]:** 策略股東；創新服務為其台灣及中國代理，提供探針卡銷售與維修
- **晶圓代工與封測廠:** [[探針卡]]植針設備及自動化裝置客戶
- **先進封裝模組:** [[TGV]]玻璃基板中介層，目標 GPU/CPU 廠商

### 主要供應商
- **[[Technoprobe]]:** 探針卡來源（代理銷售）
- **精密零件:** 光學鏡頭、雷射光源、奈米精密滑軌廠商
