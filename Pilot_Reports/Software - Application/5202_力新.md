# 5202 - 力新

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 1,060 百萬台幣
**企業價值:** 618 百萬台幣

力新國際科技（5202，NewSoft）成立於1984年，隸屬[[台灣鋼鐵集團]]，是台灣歷史最悠久的軟體公司之一，早年以「丹青」中文文書處理與「非常好色」影像處理軟體奠定品牌。目前轉型為企業數位轉型軟體服務商，主力產品包括：AI-OCR 智慧文件辨識擷取（丹青文件辨識系統）、Pro OA 雲端辦公室協同管理平台、BPM 企業流程管理、碳盤查系統，以及日本 OEM Bundle 軟體授權業務。服務客群橫跨金融、製造、政府及醫療等垂直產業。

**營收結構方面**，力新的收入來自四大類：AI-OCR 與文件辨識系統（含授權與 SaaS 訂閱，估佔三至四成）、OA 雲端協同平台（含系統建置與維護，約二成）、日本市場 Bundle 軟體授權（OEM 捆綁，約二成）、以及碳盤查與其他系統整合服務（新興業務，逾一成）。2024年合併營收1.64億元，年增20.9%，但營業虧損3,759萬元，顯示高毛利軟體業務仍需規模化才可轉盈。

**核心技術與競爭優勢方面**，力新的 AI-OCR 技術源自逾四十年的文字辨識研發積累，具備繁體中文手寫辨識的深厚優勢，較國際競品（[[Google]] Cloud Vision、[[Microsoft]] Azure OCR）更貼近台灣在地文件格式（統一發票、身份證、匯票）。丹青文件辨識系統歷經多年客戶端部署，建立穩定的企業客戶基礎。Pro OA 系統深度整合台灣電子簽核法規合規需求，形成本土化壁壘。日本 Bundle 軟體授權業務雖非主流，但為公司提供穩定外匯收入，有效平衡台灣市場的景氣波動。

**成長動能方面**，企業文件數位化與無紙化趨勢加速，AI-OCR 應用場景從傳統報帳單據延伸至合約比對、保單核保、醫療掛號等高附加價值領域，市場仍快速擴大。碳排放管理法規趨嚴（台灣氣候變遷因應法、ISO 14064），驅動製造業採購碳盤查系統。Pro OA 雲端版切換率提升，有助於拉高經常性訂閱收入佔比。母集團[[台灣鋼鐵集團]]的關係企業是天然的內部客戶來源，可作為新產品試行平台。

主要風險：公司長期處於虧損狀態（2025年營業虧損4,867萬元），費用結構偏重，現金流為負，財務壓力顯著；若母集團[[台灣鋼鐵集團]]支援縮減，獨立經營能力受考驗。AI-OCR 市場競爭日趨激烈，[[Microsoft]]、[[Google]]等國際科技巨頭不斷強化雲端文件智能服務，恐持續壓縮力新的定價空間。日本 Bundle 業務依賴單一合作模式，若 OEM 夥伴更換供應商將造成收入斷崖。

## 供應鏈位置
**上游 (雲端平台與掃描設備):**
- **雲端基礎設施:** [[Microsoft]] Azure、[[AWS]]（AI-OCR SaaS 部署基礎）
- **硬體搭售:** 掃描器與事務機廠商（OEM 軟體捆綁）

**中游 (軟體開發):**
- **AI 文件辨識:** **力新** — 丹青 AI-OCR、IDR SDK、智能合約比對機器人
- **協同辦公:** **力新** — Pro OA 雲端辦公室、BPM 流程管理、碳盤查系統

**下游 (終端客戶):**
- **金融業:** [[第一金]]、[[富邦金]]等金融機構（文件智能辨識與電子申辦）
- **製造業:** [[台灣鋼鐵集團]]成員企業（內部資訊系統）、[[Gogoro]]（智慧聯網與數位流程）
- **政府/醫療:** 各級政府機關、醫療院所（掛號系統、行政數位化）
- **日本市場:** 日本 OEM 合作夥伴（Bundle 軟體授權）

## 主要客戶及供應商
### 主要客戶
- **金融業:** [[第一金]]、[[富邦金]]等金融機構（AI-OCR 文件辨識、電子申辦加速）
- **製造業:** [[台灣鋼鐵集團]]集團關係企業（Pro OA/BPM 資訊化）、[[Gogoro]]（智慧聯網服務）
- **政府/公部門:** 各級政府機關（電子簽核、行政流程數位化）
- **醫療院所:** 醫院掛號系統（IDR SDK 身份證辨識）
- **日本 OEM 夥伴:** 日本軟體廠商（Bundle 軟體授權，穩定外匯收入）

### 主要供應商
- **雲端平台:** [[Microsoft]] Azure、[[AWS]]
- **硬體搭售:** 掃描器與複合事務機廠商（OEM 捆綁銷售）
