# 5205 - 中茂

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 293 百萬台幣
**企業價值:** 264 百萬台幣

中茂能資系統整合科技股份有限公司成立於1989年，上櫃掛牌逾三十年，專注於環境服務與資源整合，主要業務涵蓋水資源營運管理、廢棄物處理與再生利用服務、電子零組件代理，以及民生商品經銷代理。公司定位為中小型環保工程服務商，承接工業客戶廢水處理委外業務，並提供廢棄物清除、再生利用整體解決方案。資本額約1.35億元，屬台灣綠能環保產業類別。

**營收結構方面**，業務服務收入占總營收約85.7%，為最主要的收益來源，包括廢水處理工程委外服務費與水資源運營管理費；商品銷售（電子零組件與民生商品代理）約占5.4%；運費及其他約占8.9%。整體年營收規模偏小，2024年全年合併營收約0.31億元，顯示公司規模仍處小型水平，盈利穩定性受景氣波動影響。

**核心技術與競爭優勢方面**，公司積累數十年廢水及廢棄物處理工程實務經驗，具備工業廢水水質分析、處理流程設計與現場操作管理能力。水資源營運業務倚重長期契約型態，與工業園區廠商建立穩定委外合作關係，轉換成本較高，提供一定程度的客戶黏著度。電子零組件代理業務則依賴既有通路網絡，具區域性市場覆蓋優勢。

**成長動能方面**，台灣環保法規持續趨嚴，工業廢水排放標準升級帶動企業外包處理需求，有利於公司水資源運營業務量能提升。廢棄物再生利用政策亦為循環經濟趨勢推升提供助力。然而公司規模小，承接大型案件能力有限，需依賴穩定的小型工業客戶訂單基礎維持營運。

主要風險：公司規模偏小，2024年EPS為-0.99元，連年虧損壓力不容忽視；水資源處理業務依賴少數重要委外客戶，客戶集中風險高；廢棄物業務受廢棄物處理法規及許可證管制，合規成本上升；電子零組件代理受整體電子產業景氣波動影響；公司人力與資本資源有限，擴大市場份額能力受制。

## 供應鏈位置
**上游 (原料與設備):**
- **廢水處理藥劑:** [[BASF]]、[[Dow Chemical]] 等國際化工廠提供混凝劑、氧化劑等工業廢水處理藥劑
- **泵浦設備:** [[Grundfos]]、[[Xylem]] 等環保設備廠提供污水處理泵浦及自動化儀器
- **電子零組件:** 代理品牌如 [[Molex]]、[[TE Connectivity]] 等連接器原廠

**中游:**
- **水資源運營:** 中茂本身提供工業廢水委外處理運營服務
- **廢棄物處理:** 提供廢棄物清除、分類、再生利用服務

**下游 (終端應用):**
- **工業客戶:** 台灣工業區中小型製造廠商廢水外包需求
- **民生商品:** 透過通路商銷售電子零組件及民生商品

## 主要客戶及供應商
**主要服務客戶:**
- **工業廢水客戶:** 台灣各地工業區製造業者，涵蓋機械、化工等行業廠商（委外廢水處理合約）
- **廢棄物清運:** 中小型企業及工廠委外廢棄物清除業務客戶

**主要供應商:**
- **藥劑與材料:** 國內環保藥劑供應商
- **代理品牌:** 電子零組件國際原廠授權代理（[[Molex]]、[[TE Connectivity]]）
