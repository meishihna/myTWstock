# 5201 - 凱衛

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 1,064 百萬台幣
**企業價值:** 780 百萬台幣

凱衛資訊（5201，KWAY）成立於1990年代，為台灣深耕金融資訊系統的老牌軟體廠商，業務聚焦於證券期貨交易中後台核心系統開發、金融軟體系統整合，以及 MultiCharts 程式交易軟體在台灣的獨家代理銷售。公司在外資券商在台據點的市佔率高達約七成，是台灣外資金融機構不可或缺的 IT 合作夥伴。旗下亦推出「籌碼大股東」、「高股息存股」等零售理財 App，拓展 B2C 金融科技通路。

**營收結構方面**，凱衛的收入來自三大業務：金融核心系統授權與維護（證券/期貨帳務、結算系統，為最大宗，估佔總營收五至六成）、系統整合硬軟體代理（代理 Fix Engine、UNIX 伺服器等金融級設備，約二至三成）、以及 MultiCharts 程式交易軟體代理與 FinTech App 訂閱收入（個位數至一成）。2024年合併營收2.70億元，年增18.9%，顯示金融市場活絡帶動系統投資需求。

**核心技術與競爭優勢方面**，凱衛的護城河建立在兩個關鍵資產上：一是深度嵌入外資券商在台營運的金融核心系統，替換成本極高，客戶黏著度強；二是 MultiCharts 在台灣程式交易社群的獨占代理地位，擁有廣大且忠實的專業投資人用戶群。公司長年服務[[Goldman Sachs]]、[[Morgan Stanley]]、[[UBS]]、[[JP Morgan]]等外資機構在台分公司，積累的金融法規合規與資安認證技術壁壘難以短期複製。[[台灣證券交易所]]數據接介的深度整合，進一步強化與客戶的技術綁定關係。

**成長動能方面**，台灣資本市場交易量回升帶動券商 IT 投資意願提升，利於系統升級訂單落地。政府推動金融科技創新，促使傳統券商加速數位轉型，對後台系統現代化需求增加。MultiCharts 在量化投資普及化趨勢下用戶基數擴大，訂閱制轉型帶動經常性收入提升。FinTech App（籌碼大股東等）用戶持續累積，未來具廣告及增值服務變現潛力。2025年公司因收購相關資本支出大幅增加，顯示積極佈局業務擴張。

主要風險：核心客群集中於外資券商與本土大型券商，客戶數量有限，大型客戶流失對收入衝擊顯著；金融市場低迷期券商削減 IT 預算時，公司訂單能見度下降。MultiCharts 原廠若調整代理政策或直接進入台灣市場，將侵蝕該業務線。2024年淨利高達6,888萬元係受業外收益拉抬，本業獲利能力仍待改善（2024年營業淨損430萬元）。

## 供應鏈位置
**上游 (軟體原廠與硬體廠):**
- **程式交易軟體:** MultiCharts 原廠（獨家代理授權）
- **金融基礎設施:** Broadridge（Fix Engine 交易中介）
- **主機設備:** UNIX 伺服器廠商（金融級硬體代理）
- **交易所數據:** [[台灣證券交易所]]、[[臺灣期貨交易所]]（市場數據接介）

**中游 (系統開發與整合):**
- **金融軟體開發:** **凱衛** — 證券/期貨核心帳務與結算系統、FinTech App

**下游 (終端金融機構):**
- **外資券商:** [[Goldman Sachs]]、[[Morgan Stanley]]、[[UBS]]、[[JP Morgan]] 台灣分公司
- **本土券商:** [[元大金]]、[[凱基證券]]、[[富邦金]]等
- **散戶投資人:** MultiCharts 程式交易用戶、理財 App 用戶

## 主要客戶及供應商
### 主要客戶
- **外資券商 (台灣分公司):** [[Goldman Sachs]]、[[Morgan Stanley]]、[[UBS]]、[[JP Morgan]]（金融核心系統主力客群，市佔率約七成）
- **本土券商/期貨商:** [[元大金]]、[[凱基證券]]、[[富邦金]]（結算系統與系統整合）
- **程式交易用戶:** MultiCharts 台灣訂閱用戶（量化交易個人與機構）

### 主要供應商
- **程式交易軟體:** MultiCharts 原廠（獨家代理合約）
- **Fix Engine:** Broadridge（金融交易中介軟體）
- **伺服器設備:** UNIX 主機廠商（金融級硬體代理）
