# 6486_互動

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 3,868 百萬台幣
**企業價值:** 3,660 百萬台幣

互動國際數位股份有限公司成立於2001年，是台灣少數橫跨電信暨寬頻網路、無線傳輸、數位媒體、雲端資訊及地理資訊系統等領域的專業技術系統整合商，總部設於台北。公司核心業務涵蓋電信系統建置與維運、微波通訊傳輸、GIS 空間資訊解決方案及雲端平台整合服務，主要服務國內各大電信業者、固網業者、有線電視業者、媒體集團、政府機關及學術機構。2024年合併營收達新臺幣25.31億元，年增10.4%；合併稅後淨利2.86億元，年增9.2%。

**營收結構方面**，2024年電信暨寬頻網路系統服務約佔45.6%，無線傳輸服務約佔29%，雲端資訊系統服務約佔12.6%，數位媒體系統服務及地理資訊系統服務合計約佔12.8%。近年來傳輸系統設備銷售與行動通訊網路工程建設服務貢獻顯著，隨著[[5G]]專網建設加速，電信工程業務持續成長。

**核心技術與競爭優勢方面**，公司在台灣高端 GIS 市場推估市佔率超過70%，掌握 GIS＋AI 空間分析技術與微波通訊關鍵技術，非單純硬體代理商，享有較高毛利。公司積極結合 IoT、大數據、GeoAI 及 BIM 等技術，推動數位孿生及智慧城市解決方案，並開發無人機影像分析、智慧防災平台及國土測繪應用，與[[中華電信]]、[[台灣大哥大]]、[[遠傳電信]]等電信龍頭維持長期合作關係。

**成長動能方面**，國家韌性網路政策推動微波傳輸及衛星終端建設需求，帶動偏遠山區與離島備援通訊工程訂單；[[低軌衛星]]地面設備整合為新興業務方向；GIS 與 AI 融合應用持續擴展政府與民間客戶；雲端資訊服務業務隨企業數位轉型需求穩步成長，為公司提供多元成長引擎。

主要風險：公司高度依賴國內電信業者資本支出動向，若主要客戶削減5G建設預算將直接衝擊工程收入；政府計畫標案具不確定性，拿單週期長且競爭激烈；地理資訊業務受主管機關政策影響大；GIS 業務若遭國際大廠低價搶市，市佔率可能面臨壓力。

## 供應鏈位置
**上游 (設備與技術供應):**
- **微波通訊設備:** 國際微波設備廠商
- **網路傳輸設備:** 國際網通設備廠商
- **GIS 軟體平台:** [[Esri]]（ArcGIS 授權）
- **雲端基礎設施:** [[Microsoft Azure]]、[[AWS]]

**中游:**
- **系統整合:** **互動**（電信工程建置、GIS 空間資訊、雲端平台整合、微波傳輸系統整合）

**下游 (終端客戶):**
- **電信業者:** [[中華電信]]、[[台灣大哥大]]、[[遠傳電信]]、[[台灣之星]]
- **有線電視與媒體:** 國內主要有線電視系統業者、媒體集團
- **政府機關:** 國土測繪中心、各縣市政府智慧城市計畫、防災應變單位
- **企業與學術機構:** 上市櫃集團及研究機構

## 主要客戶及供應商
**主要客戶:**
- **電信業者:** [[中華電信]]（最大客戶，5G核心網路、光纖與微波工程）、[[台灣大哥大]]、[[遠傳電信]]（行動通訊網路工程）
- **有線電視與固網:** 國內主要有線電視系統業者（寬頻網路設備建置）
- **政府及學術:** 國土測繪中心（GIS空間資訊）、各縣市政府（智慧城市、防災平台）
- **媒體與企業:** 國內知名媒體集團（數位媒體系統服務）

**主要供應商:**
- **GIS 軟體:** [[Esri]]（ArcGIS平台授權與技術支援）
- **微波設備:** 國際微波通訊設備廠商
- **雲端平台:** [[Microsoft]]（Azure雲端基礎設施）
