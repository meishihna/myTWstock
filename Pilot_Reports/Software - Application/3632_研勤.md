# 3632 - 研勤

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 189 百萬台幣
**企業價值:** 459 百萬台幣

研勤科技（3632，PAPAGO!）成立於2001年，早年以衛星導航品牌「PAPAGO!」在台灣與東南亞打下消費性電子市場，目前已全面轉型為 AI 人臉辨識與車載電子雙軸並進的科技廠商。旗艦產品 FACE8 臺灣臉霸為公司自主研發之人臉辨識引擎，通過美國國家標準技術研究院（NIST）FRVT 評測認證，辨識準確率達99.8%，累計超過一萬家企業與機構採用、每日辨識量逾百萬次，在台灣人臉辨識市場佔有率居第一位。車載電子業務維持 PAPAGO! 品牌行車記錄器、胎壓偵測系統與電子後視鏡產品線，整合 AI 影像演算法提升附加價值。

**營收結構方面**，研勤的收入主要來自三大來源：AI 人臉辨識軟硬體（FACE8 引擎授權、考勤機、門禁主機及雲端訂閱服務，近年比重持續攀升，估佔總營收三至四成）、車載電子產品（PAPAGO! 行車記錄器等，佔比最大但逐年下降，估佔五成左右）、以及其他（AI Guard 智慧工安平台、FarBar 廣告機等新事業，佔比尚小）。2024年合併營收3.72億元，因車載業務萎縮而年減5.5%，但人臉辨識業務維持成長動能。

**核心技術與競爭優勢方面**，FACE8 的核心優勢在於完全台灣自主研發，不使用中國零組件，符合政府資安採購規範，這在2025年中小企業輔導採購及移民署等政府標案中已形成差異化壁壘。NIST FRVT 認證排名（排除中俄廠商後全球前五）提供國際可信度背書。FACE8 另通過 ISO/IEC 30107-3（iBeta）防偽攻擊認證及 ISO/IEC 27001 資安認證，競爭對手如[[訊連科技]] FaceMe 雖技術相當，但在政府採購資安要求的合規性上研勤更具優勢。

**成長動能方面**，台灣政府機關資安採購法規趨嚴，要求排除中國零組件，驅動政府端換機需求（移民署2024年採購新台幣600萬元設備案為代表性案例）。企業勞動管理數位化持續推動出缺勤系統更新，健身房、長照機構及學校等垂直市場仍有大量未滲透空間。車載產品線整合 AI 行車輔助（ADAS 功能）有望提升單價。日本市場廣告機 FarBar 業務若放量，可為公司開拓新的獲利來源。

主要風險：車載電子業務面臨中國低價競爭持續侵蝕，且消費者對獨立導航機需求長期衰退；公司近年連年虧損（2024年淨損1,198萬元），費用率居高不下，轉盈時間表具不確定性。FACE8 硬體供應鏈若核心零組件（影像感測IC）遭中斷，將影響交貨能力。2025年底爆發主機板採用中國零組件爭議，雖公司否認關鍵零件來源，但仍引發政府客戶信任風險。

## 供應鏈位置
**上游 (零組件與平台):**
- **影像感測晶片:** 台灣影像感測 IC 廠商（人臉辨識鏡頭模組）
- **GPS/AI 模組:** [[聯發科]]導航處理器、AI 邊緣運算晶片
- **雲端基礎設施:** [[Microsoft]] Azure、[[AWS]]（FACE8 雲端考勤平台）

**中游 (軟體開發與硬體整合):**
- **AI 人臉辨識:** **研勤** — FACE8 臺灣臉霸引擎（自主研發、軟硬體一體）
- **車載電子:** **研勤** — PAPAGO! 行車記錄器、胎壓偵測、電子後視鏡

**下游 (終端應用):**
- **企業管理:** [[柏文]]（健身工廠會員識別）、金融機構、長照中心、健身房連鎖
- **政府機關:** 移民署、各縣市政府（差勤打卡系統）、學校校園安全
- **零售通路:** 汽車百貨、電商平台（PAPAGO! 消費性車載產品）

## 主要客戶及供應商
### 主要客戶
- **政府機關:** 移民署（2024年600萬元差勤打卡系統採購案）、各縣市政府考勤系統、校園安全系統
- **企業端:** [[柏文]]（健身工廠）——會員人臉辨識識別；大型金融機構——身份驗證
- **長照/醫療:** 長照中心、安養機構（人員識別與門禁管理）
- **零售通路:** 汽車百貨、PChome、Yahoo 購物中心（PAPAGO! 行車記錄器）

### 主要供應商
- **雲端平台:** [[Microsoft]] Azure、[[AWS]]
- **晶片模組:** [[聯發科]] GPS 處理器、台灣影像感測 IC 廠商
- **電子代工:** 國內電子代工廠（車載硬體 ODM 生產）
