# 6902_GOGOLOOK

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 4,814 百萬台幣
**企業價值:** 4,903 百萬台幣

走著瞧股份有限公司 (Gogolook，6902) 成立於 2012 年，為台灣上市的「信任科技 (TrustTech)」AI 軟體服務公司，以全球知名來電辨識應用程式 [[Whoscall]] 為核心起家。公司定位為亞洲最大電話號碼與防詐騙資料庫擁有者，並以 Risk Management as a Service (RMaaS) 模式向消費者、企業及政府提供多元信任科技解決方案。2025 年 4 月正式從創新板改列台灣證券交易所一般板，是台灣軟體新創中具代表性的里程碑。主要股東包含 [[NAVER]]（[[LINE]] 母公司）。

**營收結構方面**，公司分三大業務線：一、消費端防詐服務，以 [[Whoscall]] 訂閱制為主，2024 年訂閱佔比已升至約 46%，為最大單一收入來源；二、企業端防詐服務，包含 2024 年收購的 [[ScamAdviser]]（全球假網址與商譽風險偵測平台），企業端營收 2024 年大幅成長；三、金融科技服務，旗下 JUJI 借貸媒合平台（前稱袋鼠金融 Roo.Cash）2025 年 Q3 已佔總營收約 30%。地理佈局以台灣為大本營，泰國用戶數已超越台灣成為最大市場，並持續擴展東南亞 7 億人口市場。

**核心技術與競爭優勢方面**，Gogolook 建立了東亞與東南亞最大的電話號碼識別及詐騙資料庫，結合 AI 機器學習模型持續強化詐騙識別準確率。公司是全球反詐騙聯盟 (GASA) 創始成員，並與台灣警政署、韓國金融監督院、泰國警方及馬來西亞各州政府建立正式執法合作。[[ScamAdviser]] 收購後補強了企業端 B2B SaaS 產品線，使公司同時具備 B2C 訂閱模式與 B2B 授權模式的雙引擎。電信夥伴 [[Globe Telecom]]（菲律賓）與 [[StarHub]]（新加坡）的合作，提供通路觸及當地用戶群。

**成長動能方面**，泰國市場 MAU 已超越台灣且持續高速成長，以台北與曼谷雙總部運營的策略性佈局鎖定東南亞 7 億人口市場。企業端防詐 SaaS 服務導入多國電信商及金融機構，年均成長速度遠高於消費端，有望在總收入中持續提升占比。JUJI 金融科技媒合平台聚焦台灣貸款需求撮合，受惠於流量持續放大與轉換率提升。公司 2025 年全年達成獲利目標，2025 年全年營收達 10.48 億新台幣，同比大幅成長，並首次全年轉盈，為後續資本運用提供更大彈性。

主要風險：來電辨識與防詐服務依賴持續更新的資料庫與用戶回報生態，若用戶增長放緩或詐騙手法大規模升級可能影響服務有效性；企業端 [[ScamAdviser]] 整合與海外市場拓展需承擔較高的人事與行銷費用，短期壓制獲利能力；金融科技媒合受台灣主管機關監管政策變動及信用環境波動影響；匯率變動對海外（泰國、日本、韓國）收入的換算存在一定風險。

## 供應鏈位置
**上游 (雲端基礎設施與資料來源):**
- **雲端平台:** [[AWS]]、[[Google Cloud]] (運算、儲存、AI 推論基礎設施)
- **電信 API:** 各國電信業者 API 串接 (來電線路辨識)
- **策略股東:** [[NAVER]] ([[LINE]] 母公司，早期最大外部控股)
- **收購資產:** [[ScamAdviser]] (2024 年收購，全球假網址資料庫)

**中游 (TrustTech 平台):**
- **消費端防詐:** **Gogolook** ([[Whoscall]] 來電辨識與詐騙過濾、美玉姨訊息查核)
- **企業端防詐:** **Gogolook** ([[ScamAdviser]] 商譽風險偵測 SaaS、企業 API 授權)
- **金融科技媒合:** **Gogolook** (JUJI / 袋鼠金融 Roo.Cash 借貸媒合平台)

**下游 (終端客戶):**
- **消費者:** 全球 [[Whoscall]] App 訂閱付費用戶 (台灣、泰國、日本、韓國等)
- **企業客戶:** [[凱基證券]]、[[中信金]] 等大型金融機構 (防詐合作)
- **電信夥伴:** [[Globe Telecom]] (菲律賓)、[[StarHub]] (新加坡)
- **政府機關:** 台灣警政署、韓國金融監督院、泰國警方、馬來西亞各州政府

## 主要客戶及供應商
### 主要客戶
- **消費端訂閱:** 全球 [[Whoscall]] App 付費訂閱用戶 (泰國為最大市場，其次為台灣、日本、韓國)
- **企業防詐 SaaS:** 各國金融機構、電信商、電商平台 (透過 [[ScamAdviser]] 商譽風險偵測 API)
- **金融機構合作:** [[凱基證券]]、[[中信金]] 等 (防詐技術整合)
- **電信渠道夥伴:** [[Globe Telecom]] (菲律賓)、[[StarHub]] (新加坡)
- **政府機關:** 台灣警政署、韓國金融監督院、泰國警方

### 主要供應商
- **雲端基礎設施:** [[AWS]]、[[Google Cloud]]
- **策略股東暨技術夥伴:** [[NAVER]] ([[LINE]] 母公司)
- **數據來源:** 用戶回報生態系統與各國電信 API
