# 6874_倍力

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 1,658 百萬台幣
**企業價值:** 2,097 百萬台幣

倍力資訊股份有限公司（M-Power Information）創立於1999年8月，是台灣財務金融報表軟體解決方案的領導廠商，同時提供企業資源規劃、資訊安全及 ESG 永續揭露等多元資訊服務，總部設於台北。公司以三階層（N-tiers）架構為核心技術，代理並自研國內外先進軟體解決方案，服務超過400家上市櫃公司，在財務報告書解決方案領域擁有約14%的上市櫃公司市佔率。2024年合併營收17.73億元；2025年受大型專案收入遞延影響，上半年營收較同期下降約29%。

**營收結構方面**，倍力營收主要來自金融業（約46%）與製造業（約33%），其餘為電信、政府機關及教育等領域；業務性質以專案型系統導入及年度維護服務為主，高附加價值自有產品（如碳管家、IFRS財務揭露解決方案）比重逐步上升。公司代理[[SAP]]、[[Oracle]]及[[以柔資訊]]等國際及本土軟體廠商產品，並積極發展自主品牌解決方案以提升毛利率。

**核心技術與競爭優勢方面**，公司深耕財務報告整合系統逾25年，擁有橫跨金融、製造、電信等產業的豐富導入經驗與客戶關係；ACE 成長藍圖三大支柱包括 AI 代理人（AI Agent 虛擬員工執行跨應用任務）、資安特遣隊（網路防禦至韌性恢復全方位資安服務）及 ESG 永續解決方案（碳管家、IFRS 永續財務揭露）。碳管家系統以 AI 賦能，將碳盤查作業時間從91天壓縮至15.5天，競爭優勢顯著。

**成長動能方面**，2026年起主管機關強制要求全體上市櫃公司進行碳盤查及接軌[[IFRS S1/S2]]永續準則，帶動碳管家及永續財務揭露解決方案市場需求大幅擴張；[[AI]]代理人服務切入企業端自動化流程；資安意識提升驅動整合資安服務成長；自有產品佔比提升可望優化毛利結構。

主要風險：大型專案收入認列集中於特定季度，導致季度間營收波動劇烈；代理軟體業務依賴主要原廠（[[SAP]]、[[Oracle]]）的授權政策，若原廠調整代理條件將直接衝擊收入；ESG 監管時程延遲或主管機關放寬強制要求，將顯著壓縮碳管家業務成長空間；新興 AI 代理人與資安業務短期投入成本較高，獲利貢獻時間表具不確定性。

## 供應鏈位置
**上游 (軟體授權與技術):**
- **國際 ERP 原廠:** [[SAP]]、[[Oracle]]（企業應用軟體代理授權）
- **以柔資訊:** 營業秘密保護方案授權商
- **雲端基礎設施:** [[Microsoft Azure]]、[[AWS]]

**中游:**
- **系統整合與軟體服務:** **倍力**（財務報表解決方案、AI 代理人、資安服務、ESG 碳管家平台）

**下游 (終端客戶):**
- **金融業:** [[富邦金控]]、[[國泰金控]]等大型金控及銀行（財務報告整合系統）
- **製造業:** 上市櫃製造業集團（ERP 系統整合、ESG 碳盤查）
- **電信業:** 電信業者（財務資訊系統）
- **政府及學校:** 政府機關（資訊服務）

## 主要客戶及供應商
**主要客戶:**
- **金融業 (46%):** [[富邦金控]]、[[國泰金控]]、[[中信金控]]等大型金融機構（財務報表暨合規系統）
- **製造業 (33%):** 上市櫃製造業集團（ERP 整合、碳盤查 ESG 方案）
- **電信與其他:** 電信業者、政府機關及教育單位（佔約21%）
- **整體:** 超過400家上市櫃公司，涵蓋14%的台灣上市櫃企業

**主要供應商:**
- **ERP 軟體:** [[SAP]]（企業資源規劃軟體代理授權）
- **資料庫與雲端:** [[Oracle]]（資料庫及雲端應用代理）
- **資安解決方案:** [[以柔資訊]]（營業秘密保護方案）
