# 6738 - 鼎恒

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 2,879 百萬台幣
**企業價值:** 2,621 百萬台幣

鼎恒數位科技股份有限公司（品牌名 MAYO Human Capital，簡稱 MAYOHR）成立於2013年7月，是台灣雲端人力資源管理軟體的代表性業者，總部設於新竹竹北，在台灣及越南設有據點。公司聚焦於以 [[Microsoft Azure]] 公有雲平台為基礎架構，開發並銷售雲端人資 SaaS 解決方案，產品涵蓋人事組織管理、出勤排班、薪資結算、招募聘僱及員工福利平台等功能模組，已協助超過2,500家跨產業企業進行人資數位轉型。2024年全年營收約2.22億元。

**營收結構方面**，公司收入主要分為雲端人資解決方案服務（Apollo 平台訂閱及導入服務）與雲端員工福利整合服務（STAYFUN 平台）兩大支柱，SaaS 訂閱型收入比重持續提升，業務涵蓋餐飲、零售、製造、金融、資訊科技、外商等多元產業，惟整體規模仍屬中小型，2025年前三季受訂單週期影響，累計營收呈衰退態勢。

**核心技術與競爭優勢方面**，Apollo 全方位人資解決方案整合招募聘僱、行動出勤、智慧薪資、員工自助服務等模組於單一雲端平台，以靈活的組態設定降低導入門檻；STAYFUN 員工福利整合平台提供差異化的非薪資員工體驗服務，形成產品組合黏著度。公司率先在台灣以 SaaS 模式服務中大型企業，合作夥伴包含[[遠雄集團]]、[[路易莎咖啡]]、[[Merck]]（德國默克藥廠）、[[桂盟國際]]等知名企業。

**成長動能方面**，台灣勞動法規持續修訂（工時、加班費計算、健保費率調整等）推動企業持續升級人資系統；企業導入[[AI]]輔助薪資計算與排班優化成為新需求；東南亞跨國企業擴編推動越南在地服務佈局；ESG 人才管理揭露要求可望促進人資系統升級需求，[[Microsoft Azure]] OpenAI 整合功能亦逐步導入 Apollo 平台，強化產品智能化。

主要風險：台灣 SaaS 人資市場競爭日趨激烈，面臨[[SAP SuccessFactors]]、[[Workday]] 等國際大廠及本土競爭者夾擊；公司規模偏小、客戶開發成本高，大型企業導入週期長；越南業務拓展面臨在地化成本與競爭壓力；SaaS 訂閱收入成長速度若低於市場預期，將壓縮獲利空間。

## 供應鏈位置
**上游 (雲端基礎設施與技術):**
- **雲端平台:** [[Microsoft Azure]]（IaaS/PaaS 基礎架構）
- **AI 技術:** [[Microsoft Azure OpenAI Service]]（智能化功能模組）

**中游:**
- **HR SaaS 開發商:** **MAYOHR**（Apollo 人資平台、STAYFUN 福利平台自研開發與維運）

**下游 (終端客戶):**
- **製造業:** [[桂盟國際]]、[[通力電梯]]等製造業集團
- **餐飲零售:** [[路易莎咖啡]]、連鎖零售業者
- **外商企業:** [[Merck]]（德國默克藥廠）等跨國外商在台子公司
- **多元產業:** 金融、建設、資訊科技等跨產業中大型企業（超過2,500家）
