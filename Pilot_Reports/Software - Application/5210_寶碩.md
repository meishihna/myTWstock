# 5210 - 寶碩

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 2,424 百萬台幣
**企業價值:** 2,043 百萬台幣

寶碩財務科技股份有限公司成立於1990年代，深耕金融資訊服務逾三十年，英文名稱APEX Group，總部設於台北，並於新竹及上海設有研發中心。公司主要業務涵蓋財務系統軟體開發、金融機構系統整合服務，以及太陽能發電設備工程承攬，服務對象以金控、銀行、證券、保險、政府機構及學術單位為主。資本額8.2億元，員工約150人。

**營收結構方面**，應用軟體設計開發及系統整合服務為最主要收益來源，涵蓋衍生性金融商品風險管理系統、債券管理系統、財富管理平台等金融核心軟體；其次為維護服務收入（年度維護合約），提供穩定的經常性收益基礎；太陽能發電設備工程為第三收益來源，貢獻度相對較低。2024年全年合併營收約2.53億元，第4季單季營收7,880萬元，稅後淨利3,639萬元。

**核心技術與競爭優勢方面**，寶碩融合財工（Financial Engineering）知識與先進AI技術，研發高端財務系統，在衍生性金融商品評價、風險管理與結算等複雜運算領域具深厚技術積累。公司以專業、創新、卓越為核心理念，深耕金融行業三十年，擁有豐富的銀行及金融機構客製化開發經驗，客戶轉換成本高，維護合約黏著性強。已獲各大金控及保險公司長期合作背書，業界口碑穩固。

**成長動能方面**，台灣金融機構持續推動數位轉型，對風險管理系統、財富管理平台與合規系統需求持續升溫；[[金融監理科技]]（RegTech）趨勢加速金融機構汰換老舊系統；AI技術導入金融模型建構有助提升系統附加價值；太陽能裝置工程受政府[[再生能源]]政策帶動，形成多元成長動能。

主要風險：規模小、客戶集中度高，重要金融機構合約若流失將影響營收；金融軟體市場競爭者包括精誠資訊、[[IBM]]、[[Oracle]]等大型業者；太陽能工程業務受補貼政策變動影響；AI金融科技新創切入可能壓縮系統整合商利潤空間；上海研發中心存在地緣政治風險。

## 供應鏈位置
**上游 (原料與設備):**
- **資料庫與中介軟體:** [[Oracle]]、[[Microsoft]] 等基礎軟體授權
- **雲端平台:** [[AWS]]、[[Microsoft Azure]] 等雲端基礎架構
- **太陽能設備:** 太陽能板模組供應商

**中游:**
- **軟體開發:** 寶碩自行研發金融核心系統與財務工程解決方案
- **系統整合:** 整合硬體、軟體及網路，交付完整金融系統

**下游 (終端應用):**
- **銀行金控:** 國內各大金控旗下銀行財富管理及風險管理需求
- **證券業:** 前後台交易系統及風險管理
- **保險業:** 資產負債管理及精算系統
- **政府與學術:** 財務資訊系統建置與維護

## 主要客戶及供應商
**主要客戶（金融機構）:**
- **金控與銀行:** [[富邦金控]]、[[國泰金控]]、[[中信金控]]等大型金控旗下銀行（衍生性金融商品管理系統）
- **保險公司:** 國內壽險及財險公司（資產負債管理系統）
- **證券商:** 國內主要券商（風險管理與結算系統）
- **政府與學術:** 政府機關財務系統及大學財務管理系統

**主要供應商:**
- **基礎軟體:** [[Oracle]]（資料庫）、[[Microsoft]]（中介軟體）
- **雲端服務:** [[AWS]]、[[Microsoft Azure]]
