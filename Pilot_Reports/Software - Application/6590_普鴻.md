# 6590_普鴻

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 1,655 百萬台幣
**企業價值:** 1,603 百萬台幣

普鴻資訊股份有限公司成立於2000年7月，是台灣金融支付與資訊安全領域的專業軟體服務商，深耕銀行及金融機構的核心支付系統建置與維運，並在硬體安全模組（HSM）、行動支付及金融監理科技等領域佔據領先地位，總部設於台北。公司採模組化金融融合機（Appliance Box）作為核心交付模式，提供標準化、軟硬體一體的金融支付解決方案，客戶群約9成為金融業，市占率超過五成，被業界譽為台灣金融血脈的關鍵基礎設施供應商。

**營收結構方面**，普鴻以提供勞務收入為絕對主體（約佔94.6%），商品銷售佔約5.4%。業務分為支付應用系統、金融應用系統、資訊安全及委外服務四大類別，主要客戶為[[財金資訊]]、[[LINE Bank]]、[[富邦金控]]及國內主要商業銀行。2023年合併營收達新臺幣6.75億元，年增29.55%；稅後純益1.29億元，年增四成；2024年全年EPS約4.37元。

**核心技術與競爭優勢方面**，普鴻在金融支付及資安市場市占率超過50%，為台灣最大金融支付系統軟體商。技術壁壘來自長年累積的金融業客製化能力與全天候在地服務，以及專利HSM加密硬體（ProHSM™）技術；公司率先採用微服務架構重構支付系統，確保系統彈性與高可用性，並透過雙活（AA）架構提升金融機構災備能力。子公司捷智商訊專注金融監理科技，進一步擴展監理申報與法遵系統市場。

**成長動能方面**，金融監管機構持續推動開放銀行、數位支付及電子發票等政策，帶動金融機構系統升級需求；[[行動支付]]市場擴張及第三方支付普及化催生新一輪基礎設施投資；HSM設備汰舊換新週期及資安意識提升，推動相關硬體及服務合約更新；子公司金融監理科技業務可望隨監管法規日益複雜而持續放量。

主要風險：客戶高度集中於台灣金融業，若主要銀行客戶預算凍結或採購延遲將直接衝擊當期營收；金融業系統招標競爭激烈，來自國際大廠的壓力不容忽視；監管環境變動可能導致客戶提前或延後系統採購週期；公司規模相對較小，人才招募與技術研發能量有限。

## 供應鏈位置
**上游 (硬體與技術):**
- **HSM 加密硬體元件:** 國際半導體元件廠商
- **伺服器基礎設施:** 國際伺服器廠商
- **資安技術:** 自研 ProHSM™ 技術為核心

**中游:**
- **金融軟體服務:** **普鴻**（支付應用、金融應用、資訊安全、委外服務）
- **子公司:** 捷智商訊（金融監理申報系統）

**下游 (終端客戶):**
- **金融基礎設施:** [[財金資訊]]（ATM 跨行交換系統）
- **數位銀行:** [[LINE Bank]]（行動支付後台）
- **商業銀行:** [[富邦金控]]、[[國泰金控]]及國內主要銀行
- **電子支付機構:** 國內主要[[行動支付]]業者

## 主要客戶及供應商
**主要客戶:**
- **金融基礎設施:** [[財金資訊]]（跨行支付清算核心系統）
- **數位銀行與純網銀:** [[LINE Bank]]（行動支付解決方案）
- **金控銀行:** [[富邦金控]]（新一代 ProHSM™ 加密系統、eACH雙活系統）
- **其他商業銀行:** 國內主要商業銀行（支付系統、HSM設備、委外維運）
- **監理申報:** 金融監管機構相關系統（透過子公司捷智商訊）

**主要供應商:**
- **硬體安全模組原料:** 國際電子元件廠商（HSM 加密晶片及相關零組件）
