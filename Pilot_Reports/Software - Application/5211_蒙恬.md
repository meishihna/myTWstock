# 5211 - 蒙恬

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 632 百萬台幣
**企業價值:** 467 百萬台幣

蒙恬科技股份有限公司（PenPower Technology）成立於1991年9月，英文品牌名稱Penpower，以智慧型人機介面核心技術研發為主軸，深耕手寫辨識、光學字符辨識（OCR）、語音辨識、文字轉語音（TTS）及影像辨識五大AI識別技術。公司產品線涵蓋消費性掃譯筆、手寫輸入板、企業AI識別解決方案，以及各類AI識別技術授權，客戶橫跨一般消費者、企業與政府機關。

**營收結構方面**，消費性硬體產品（以掃譯筆系列為代表）為最主要收益來源，全能掃譯筆結合OCR掃描、即時翻譯、AI學習輔助等功能，在台灣、香港及海外華語市場熱銷；技術授權（軟體授權及SDK授權）為第二收益來源，授權對象為智慧型手機廠商、電子書業者、金融業電子簽名系統等B2B客戶；企業系統整合服務（文件數位化、資料庫建置）提供穩定的經常性收益。2025年5月單月營收年增33.18%，顯示消費性掃譯筆需求回升。

**核心技術與競爭優勢方面**，蒙恬科技擁有逾三十年手寫辨識與[[OCR]]技術積累，繁體中文、簡體中文、粵語等多語系辨識能力居業界領先地位，尤其在繁中手寫辨識領域具強大競爭壁壘。AI掃譯筆整合自研OCR引擎、機器學習優化翻譯品質，並支援60+語言即時翻譯，在學生及商務旅行者市場具品牌黏著度。企業授權業務為客戶系統量身訂製，累積深度整合關係。

**成長動能方面**，[[AI]]技術快速發展為手寫辨識、[[語音辨識]]及翻譯功能帶來產品升級契機；AI掃譯筆整合大型語言模型輔助英文學習功能，切入教育科技（EdTech）市場；政府機關文件數位化需求帶動OCR企業解決方案採購；海外市場特別是東南亞及日本市場之繁、簡中文辨識授權需求持續擴大。

主要風險：消費性硬體市場競爭激烈，[[Google翻譯]]及[[DeepL]]等免費翻譯服務對硬體翻譯筆形成替代壓力；AI識別技術開源化（如[[Tesseract OCR]]）可能壓縮授權收入；智慧型手機語音助理功能持續強化，衝擊手寫輸入板需求；消費性產品毛利率受硬體成本上升壓縮；市場規模較小，研發資源有限，難以與大型科技巨頭競爭。

## 供應鏈位置
**上游 (原料與設備):**
- **晶片與感測器:** 掃描感測器、[[Arm]] 處理器晶片
- **電子零組件:** 記憶體、連接器等標準電子元件
- **AI雲端服務:** [[Google Cloud]]、[[Microsoft Azure]] 等雲端翻譯API

**中游:**
- **研發設計:** 蒙恬自行研發[[OCR]]引擎、手寫辨識演算法
- **硬體製造:** 委外代工生產掃譯筆、手寫板等硬體產品
- **軟體授權:** SDK及API授權給B2B客戶

**下游 (終端應用):**
- **消費市場:** 一般消費者、學生（翻譯筆、手寫輸入板）
- **企業市場:** 金融業電子簽名、政府文件數位化、圖書館典藏數位化
- **授權市場:** 智慧型手機廠商、電子書設備、[[GPS]]導航系統廠商

## 主要客戶及供應商
**主要客戶:**
- **消費通路:** [[PChome]]、[[momo購物網]]、[[Yahoo奇摩購物]] 等電商平台（掃譯筆零售）
- **企業客戶:** 國內金融機構（電子簽名系統OCR）、政府機關及圖書館（文件數位化）
- **B2B授權:** 智慧型手機廠商及電子設備業者（手寫辨識SDK授權）
- **海外市場:** 香港及東南亞消費通路（掃譯筆出口）

**主要供應商:**
- **晶片:** [[Qualcomm]]、[[聯發科]] 處理器晶片
- **代工製造:** 台灣及中國EMS廠商
