# 6231_系微

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 9,861 百萬台幣
**企業價值:** 8,979 百萬台幣

系微股份有限公司（Insyde Software Corp.）成立於1998年，總部位於台北，以系統韌體研發為核心業務，深耕[[UEFI]] BIOS領域逾二十五年，奠定全球筆記型電腦BIOS市場領導地位。旗艦產品InsydeH2O® UEFI BIOS廣泛授權給全球主要筆電品牌廠，另以Supervyse® OpenBMC韌體切入伺服器及資料中心市場，形成PC端與伺服器端雙輪驅動格局。2024年合併營收16.15億元創歷史新高，毛利率近80%，為高毛利純軟體授權商業模式。

**營收結構方面**，授權金（Royalty Fee）約占總營收60%，客戶每出貨一台筆電或伺服器均需支付授權費，形成「設計一次、持續收費」之高度可預期經常性收益；NRE設計服務費（客製化韌體開發費）約占30%，2024年佔比較2023年的25%提升；伺服器OpenBMC業務收入比重從2024年Q1的10%上升至Q2的15%，呈加速成長趨勢。2025年Q1營收4.07億元，年增9.73%，EPS 1.70元。

**核心技術與競爭優勢方面**，系微在Arm架構[[AI PC]]市場佔有率高達70至80%，成為搭載高通Snapdragon X Elite及第一代、第二代[[Snapdragon]] 8cx平台筆電不可或缺的韌體夥伴。2024年12月，InsydeH2O及Supervyse OpenBMC通過[[NVIDIA]] MGX模組化平台認證，支援GH200 Grace Hopper超級晶片及Grace CPU，成為首家獲此認證的BIOS獨立供應商，強化AI伺服器市場競爭地位。2025年3月取得ISO/IEC 27001:2022資安認證，提升企業客戶信任。

**成長動能方面**，[[AI筆電]]換機潮帶動授權單價提升，AI筆電BIOS授權金較傳統筆電高出一倍以上；高通及Arm架構AI PC滲透率提升直接拉動系微市佔規模；伺服器端Supervyse OpenBMC受惠於[[AI伺服器]]及[[資料中心]]建設熱潮，OpenBMC業務比重持續攀升；資安訂閱服務（aiBIOS資安模組）為新型態經常性收益來源；此外系微正發展針對[[Arm伺服器]]的BIOS解決方案，成為首家通過Arm SBMR 2.0規範的獨立BIOS供應商。

主要風險：PC市場景氣波動直接影響授權金規模；AI PC換機速度若低於預期將拖累成長；客戶集中度風險，少數大型筆電品牌廠貢獻大部分授權收入；Intel重新佈局韌體策略可能影響x86授權需求；AMI等競爭對手在伺服器BIOS市場具成熟地位，OpenBMC市場競爭加劇；開源BIOS（如[[coreboot]]）發展可能衝擊長期授權模式。

## 供應鏈位置
**上游 (原料與設備):**
- **晶片架構授權:** [[Arm]] Holdings（架構授權）、[[Intel]] x86平台
- **處理器合作:** [[Qualcomm]]（Snapdragon X Elite等AI PC晶片）
- **NVIDIA合作:** [[NVIDIA]] MGX平台認證合作（Grace Hopper、GH200）

**中游:**
- **韌體研發:** 系微自行研發InsydeH2O® [[UEFI]] BIOS及Supervyse® OpenBMC
- **NRE客製化:** 為品牌廠提供客製化韌體開發服務
- **認證與資安:** ISO/IEC 27001、Arm SBMR 2.0等認證維護

**下游 (終端應用):**
- **筆電品牌廠:** [[宏碁]]、[[華碩]]、[[Lenovo]]、[[HP]]、[[Dell]]、[[Microsoft]] Surface（InsydeH2O授權）
- **AI伺服器ODM:** [[廣達]]、[[緯創]]、[[英業達]]等伺服器ODM廠（OpenBMC授權）
- **資料中心:** [[NVIDIA]] MGX平台AI伺服器客戶

## 主要客戶及供應商
**主要客戶（品牌廠）:**
- **筆電品牌:** [[宏碁]]（Swift Go系列）、[[HP]]（Spectre x360）、[[Lenovo]]（IdeaPad Pro系列）、[[華碩]]、[[Microsoft]]（Arm架構Surface）
- **AI伺服器廠:** [[廣達]]、[[緯創]]、[[英業達]] 等ODM廠商採用Supervyse OpenBMC
- **晶片平台夥伴:** [[Qualcomm]]（Snapdragon生態系合作）、[[NVIDIA]]（MGX平台認證夥伴）

**主要供應商（技術授權）:**
- **架構授權:** [[Arm]] Holdings（Arm SBMR規範制訂者）
- **規範機構:** UEFI Forum（UEFI規範標準維護）
