# 5403 - 中菲

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 7,191 百萬台幣
**企業價值:** 5,974 百萬台幣

中菲電腦股份有限公司（DDSC）成立於1981年，為台灣金融科技軟體領域龍頭業者，深耕金融業系統逾四十年，核心業務為銀行信託系統、證券前後台系統、財富管理系統等金融應用軟體開發與系統整合。公司在台灣銀行信託解決方案市場佔有率高達約80%，近乎寡占；證券業前後台系統市佔率約30%，合計服務超過30家國內外大型金融機構。2024年全年營收31.56億元，EPS 8.44元，財務體質穩健。

**營收結構方面**，金融產業業務（銀行、金控、壽險）約占整體收入70%，包括信託系統、財富管理系統、保管銀行系統等；證券產業業務（複委託交易系統、前後台帳務系統）約占20%；其他包括硬體維護與系統升級服務約占10%。毛利率維持在40%高水準，顯示軟體授權與維護費用具高附加價值。2025年前三季累計營收達24億元，年增11%，累計EPS 5.8元。

**核心技術與競爭優勢方面**，中菲在特定金錢信託、保管銀行、員工福利信託、不動產信託等應用系統領域累積逾四十年深厚業務知識，深度嵌入客戶核心作業流程。信託系統整合帳務、客戶管理、法遵合規於一體，客戶轉換成本極高，形成強大的客戶黏著。公司率先對應金融監理機關推行的「信託2.0」政策、TISA個人帳戶新制及安養信託需求，具備先發優勢，搶佔監理創新帶動的系統升級商機。

**成長動能方面**，台灣政府推動「信託2.0」普惠金融政策持續帶動銀行新型信託產品上線需求；[[TISA]]（台灣個人帳戶制度）法規實施後，銀行需建置對應帳務及交易系統；安養信託及退休金融需求隨人口老齡化趨勢擴大；複委託交易系統隨國人境外投資增溫而需求持增；此外，金融監理合規（如AML、KYC數位化）帶動系統更新採購。

主要風險：業務高度集中於台灣金融業，景氣波動或金融業資本支出縮減直接影響營收；信託系統高市佔帶來競爭對手模仿風險；開源金融科技工具及雲端原生金融平台（[[AWS]]、[[Microsoft Azure]]）可能衝擊傳統軟體整合商；中國及外資金融科技業者進入台灣市場競爭；關鍵人才流失風險。

## 供應鏈位置
**上游 (原料與設備):**
- **基礎軟體:** [[Oracle]] 資料庫、[[IBM]] 中介軟體
- **雲端基礎架構:** [[AWS]]、[[Microsoft Azure]] 雲端服務
- **資安解決方案:** 資安廠商加密及認證技術

**中游:**
- **軟體開發:** 中菲自行研發信託系統、財富管理平台、複委託系統
- **系統整合:** 整合銀行既有核心系統（Core Banking）與前台應用

**下游 (終端應用):**
- **商業銀行信託部:** 特定金錢信託、保管銀行、員工福利信託系統
- **證券商:** 複委託交易系統、前後台帳務系統
- **壽險及金控:** 財富管理系統、債券管理系統

## 主要客戶及供應商
**主要客戶（金融機構）:**
- **官股銀行:** [[台灣銀行]]、[[兆豐銀行]]、[[彰化銀行]]（信託及財富管理系統）
- **民營銀行:** [[玉山銀行]]、[[中信銀行]]、[[富邦銀行]]（信託系統）
- **外商銀行:** 在台外資銀行（保管銀行系統）
- **壽險公司:** [[全球人壽]]等壽險業者（資產管理系統）
- **證券商:** 國內主要券商（複委託系統及前後台系統）

**主要供應商:**
- **資料庫:** [[Oracle]]（核心資料庫平台）
- **雲端:** [[AWS]]（雲端佈建）
