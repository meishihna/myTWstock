# 4764 - 雙鍵

## 業務簡介
**板塊:** Basic Materials
**產業:** Specialty Chemicals
**市值:** 29,384 百萬台幣
**企業價值:** 27,439 百萬台幣

雙鍵化工 (Double Bond Chemical) 為台灣特用化學品廠，專精塑膠添加劑與 UV 光固化材料，現為全球第三大光固化起始劑生產商。主要產品線包括：塑膠添加劑 ([[紫外線吸收劑]]/HALS 光穩定劑/抗氧化劑)、[[UV固化]]材料 (光引發劑/單體/寡聚物)、電子化學品 ([[CCL]]用樹脂添加劑/環氧硬化劑/[[LED]]封裝材料)、及數位紡織印花墨水。生產基地以台灣中和總部暨研發中心為核心，宜蘭利澤工業園區設有新廠，中國江蘇鹽城大豐港華豐工業園設有生產基地，客戶逾 3,000 家遍及全球。

**營收結構方面**，2024 年塑膠添加劑佔整體營收約 48%，[[UV固化]]材料佔約 44%，電子化學品及其他佔約 8%。宜蘭廠已投產，光起始劑年產能達 6,000 噸，擴充整體產能支撐成長。地理布局以外銷為主，客戶遍及歐洲、亞洲及北美，外銷佔比估計超過七成。

**核心技術與競爭優勢方面**，雙鍵在光固化化學品擁有深厚技術積累，全球第三大光引發劑供應商的市場地位使其具備規模競爭力，並持續研發符合環保法規的無溶劑光固化配方。電子化學品方面，已確認切入高速高頻[[CCL]]供應鏈，為[[台光電]]、[[聯茂]]、[[台燿]]等 [[CCL]] 廠供應[[5G]]/AI 基板用樹脂添加劑及硬化劑，受惠高速通訊基板需求擴增。塑膠添加劑客戶涵蓋[[台塑]]、[[南亞]]等大型石化廠，具長期穩定供應關係。

**成長動能方面**，高階 [[CCL]] 用電子化學品為最重要的成長引擎：[[5G]]、6G 及 [[AI 伺服器]] 基板對低損耗、高頻特性 CCL 材料需求大幅攀升，驅動台光電、聯茂等客戶持續擴充特殊樹脂配方採購；宜蘭新廠產能爬升提供收入增量；HALS 光穩定劑宜蘭生產計畫落地，擴大高毛利產品比重；[[3D列印]]材料與環保 UV 塗料應用拓展多元市場。2025 年起毛利率從低谷回升，達約 18-23%。

主要風險：全球塑膠添加劑市場受景氣週期影響，化工原料價格波動直接壓縮毛利；中國鹽城廠地緣政治風險及兩岸政策不確定性；UV 光固化材料市場競爭激烈，歐洲大廠[[IGM Resins]]、[[Allnex]] 等擁有技術與品牌優勢；電子化學品客戶驗證週期長；大幅資本支出 (宜蘭廠約 20 億元) 形成折舊壓力，短期影響獲利能力。

## 供應鏈位置
**上游 (原料與設備):**
- **化工原料:** 苯酚、醇類、苯乙烯等精密有機化學品供應商
- **光固化中間體:** 丙烯酸酯類基礎原料廠

**中游 (製造):**
- **雙鍵** ([[紫外線吸收劑]]/HALS 光穩定劑/光引發劑/[[UV固化]]單體寡聚物/[[CCL]]電子化學品；台灣中和+宜蘭廠+中國鹽城廠)

**下游 (終端應用):**
- **電子基板 (CCL):** [[台光電]]、[[聯茂]]、[[台燿]] — [[5G]]/AI 高速基板樹脂添加劑
- **塑膠:** [[台塑]]、[[南亞]] — 塑膠製品光穩定/抗氧化添加劑
- **LED:** [[LED]]封裝膠材料
- **UV塗料/油墨:** 塗料廠、油墨廠 — 光引發劑
- **紡織/3D:** 數位紡織印花墨水、[[3D列印]]材料

## 主要客戶及供應商
### 主要客戶
- **CCL電子基板:** [[台光電]]、[[聯茂]]、[[台燿]] — [[5G]]/AI 基板用電子化學品
- **塑膠石化:** [[台塑]]、[[南亞]] — 塑膠添加劑 (光穩定劑/抗氧化劑)
- **UV塗料/油墨:** 全球塗料廠、油墨廠 (超過 3,000 家客戶) — 光引發劑/UV 材料

### 主要供應商
- **精密有機化學品:** 苯酚、苯甲醇、醇酯類等基礎化工廠
- **丙烯酸酯:** 丙烯酸酯單體廠 — [[UV固化]]材料中間體
