# 4765 - 磐采

## 業務簡介
**板塊:** Basic Materials
**產業:** Specialty Chemicals
**市值:** 517 百萬台幣
**企業價值:** 778 百萬台幣

磐采股份有限公司 (4765，Pancolour Ink) 成立於1998年，為台灣專業 UV 光固化材料製造商，擁有超過25年研發經驗，品牌涵蓋 PANOVA、PANCURE、PANOLEN 及 RADITHO。公司定位於特殊功能性材料，核心業務涵蓋 UV 網版印刷油墨 (應用於光碟、卡片、包裝印刷)、UV 保護塗料與接著劑，以及[[3D列印]]光固化樹脂耗材。近年積極轉型，布局[[MLCC]]用導電漿料 (銅漿、銀漿，用於內電極與端電極)，試圖從傳統印刷材料切入高附加價值電子材料領域。

**營收結構方面**，印刷油墨及漿料佔總營收約81%，保護塗料佔約11%，接著劑佔約6%。UV 油墨以網版印刷為主力，應用於光碟印刷、包裝及工業卡片；[[3D列印]]樹脂為近年重點發展品項，已於2025年開設3D列印展示店推廣應用；[[MLCC]]導電漿料目前仍處開發導入期，尚未形成顯著營收貢獻。2024年營收為3.07億元，毛利率回升至27%，但仍處輕微虧損狀態。

**核心技術與競爭優勢方面**，磐采掌握奈米分散技術、光固化化學配方設計及色彩管理系統，為台灣少數能自主研發 UV 光固化全系列材料的廠商。在[[3D列印]]樹脂領域，公司為台灣規模最大的自主品牌製造商，具備從樹脂合成到色彩調配的完整研發能力。在[[MLCC]]導電漿料方面，公司以奈米銅粉/銀粉分散技術為核心，開發能取代日系漿料的國產替代方案，潛在應用包括[[MLCC]]內電極漿料及[[太陽能]]電池電極漿料。

**成長動能方面**，磐采轉型電子材料的核心驅動力在於[[MLCC]]導電漿料國產化需求，目前[[MLCC]]漿料市場高度依賴[[村田]]、[[TDK]]等日本原廠，磐采若能通過[[國巨]]、[[華新科]]等台灣廠商認證，將取得可觀市場空間。[[3D列印]]樹脂受惠於積層製造需求持續擴大，公司積極拓展服務型通路。此外，UV 塗料有望受惠於潔淨生產趨勢，帶動傳統油性塗料轉換需求。

主要風險：[[MLCC]]導電漿料認證週期長、成功率不確定，核心 UV 油墨業務面臨中國低成本競爭及數位印刷替代壓力，公司持續虧損消耗淨值，需持續以研發投入維持競爭力。

## 供應鏈位置
**上游 (原料與設備):**
- **金屬粉末:** 奈米銅粉、銀粉 — [[MLCC]]導電漿料原料
- **光固化樹脂/單體:** 特殊丙烯酸酯樹脂、光起始劑
- **顏料/染料:** 有機顏料、UV 吸收劑

**中游 (製造):**
- **磐采** (UV 網版印刷油墨、UV 保護塗料/接著劑、[[3D列印]]光固化樹脂、[[MLCC]]導電漿料研發)

**下游 (終端應用):**
- **[[MLCC]] (導入期):** [[國巨]]、[[華新科]]、[[村田]] — 內電極/端電極導電漿料
- **[[太陽能]]:** 太陽能電池 — 電極導電漿料
- **印刷/包裝:** 光碟、工業卡片、包裝印刷 — UV 油墨
- **[[3D列印]]:** 積層製造設備廠商及服務局 — 光固化樹脂

## 主要客戶及供應商
### 主要客戶
- **[[MLCC]] (潛在):** [[國巨]]、[[華新科]]、[[村田]] — 導電漿料驗證中
- **印刷/包裝:** 光碟及包裝印刷廠 — UV 網版油墨
- **[[3D列印]]:** 積層製造應用廠商 — 光固化樹脂

### 主要供應商
- **金屬粉末:** 奈米銅粉/銀粉廠商 — 導電漿料原料
- **樹脂/單體:** 特殊丙烯酸酯樹脂供應商
- **光起始劑:** 化工原料商
