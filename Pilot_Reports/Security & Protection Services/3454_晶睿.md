# 3454 - 晶睿

## 業務簡介
**板塊:** Industrials
**產業:** Security & Protection Services
**市值:** 8,605 百萬台幣
**企業價值:** 7,660 百萬台幣

晶睿通訊股份有限公司（3454）成立於2000年，為全球知名網路攝影機（[[IP Camera]]）製造商及智慧安防解決方案供應商，持有自有品牌「VIVOTEK」（[[OBM]]）並兼營[[ODM]]代工業務。公司自2017年起成為[[台達電子]]之子公司，並於2026年3月完成私有化下市，[[台達電子]]以每股100元全額收購，VIVOTEK品牌事業群隨即與加拿大安防軟體品牌[[March Networks]]合併，整合後實體年營收規模逾2億美元，服務1,500家以上金融機構及600家以上零售商。子公司[[睿緻科技]]為晶睿分拆之自有SoC晶片設計公司，提供[[IP Camera]]、車用攝影機等專用影像處理晶片。

**營收結構方面**，2024年[[IP Camera]]約佔整體營收80%，[[NVR]]約7%，影像伺服器、無線攝影機、PTZ攝影機及影像管理軟體（VAST Security Station）合計約13%。地理分布以北美為核心，美國約佔55%，其他海外市場約25%，台灣約15%，加拿大約5%；[[OBM]]與[[ODM]]雙軌並行，[[ODM]]客戶以國際電信及網路設備大廠為主（受[[NDA]]保護未公開）。2024年毛利率31.8%，較2023年25.7%顯著回升。

**核心技術與競爭優勢方面**，VIVOTEK連續12年躋身全球安防50大，2024年排名全球第14（整體）及第一（台灣），連續五年獲台灣國際品牌肯定。自主雲端平台[[VORTEX]]（2022年推出）以SaaS訂閱模式提供邊緣至雲端AI影像分析，整合攝影機、[[NVR]]、VMS、門禁及行動端管理；在鏡AI技術涵蓋RealSight Engine、Chroma24 AI真彩夜視、Smart VCA影像內容分析、Vision Object Analytics等，實現行人計數、車輛偵測、異常行為偵測等功能；[[睿緻科技]]（Vatics）自製SoC晶片差異化競爭，取得[[CEVA]]影像DSP核心授權；[[NDAA]]合規全系列產品，有效對抗[[Hikvision]]、[[Dahua]]等中國品牌。

**成長動能方面**，[[台達電子]]母公司協同效應持續深化：VIVOTEK攝影機嵌入Delta樓宇自動化生態系，推動智慧建築交叉銷售；[[VORTEX]]訂閱平台轉型若達規模將帶動高毛利率的經常性收入結構性改善；車用監控市場（[[行車記錄器]]、公車/火車車廂監控）結合[[AI]]駕駛疲勞偵測與乘客計數成為新興成長點；與[[March Networks]]合併擴大企業軟體能力，強化金融及零售垂直市場；東南亞電信商合作夥伴關係拓展新興市場。

主要風險：2025年因產品組合調整及整合成本拖累，全年出現營業虧損（營業利益率-0.37%）；營收自2022年高峰995億元降至2025年746億元，跌幅達25%，客戶庫存去化週期延長；[[ODM]]業務對少數大型電信/網路客戶集中度高，具訂單波動風險；55%美國市場集中帶來匯率及政策風險；下市後公開資訊揭露停止，獨立財務能見度降低；[[Hikvision]]、[[Dahua]]在非[[NDAA]]管制市場仍以低價主導全球份額。

## 供應鏈位置
**上游 (關鍵元件):**
- **自製SoC晶片:** [[睿緻科技]]（晶睿子公司）— [[IP Camera]]、車用攝影機及門鈴攝影機專用影像處理SoC（取得[[CEVA]] DSP核心授權）
- **影像SoC補充:** [[安霸]]（Ambarella）（業界主流[[AI]]視覺SoC，補充供應）
- **感光元件:** [[Sony]] [[CIS]]影像感測器（主要供應商）
- **光學鏡頭:** 鏡頭模組供應商

**中游 (製造與開發):**
- **晶睿通訊** — [[IP Camera]]、[[NVR]]製造（新北中和廠及桃園廠）、VIVOTEK品牌OBM銷售、[[VORTEX]]雲端SaaS開發、VAST Security Station VMS研發
- **母公司整合:** [[台達電子]]（樓宇自動化事業群，全額持股，2026年私有化）

**下游 (終端市場):**
- **北美金融及零售:** 逾1,500家金融機構、逾600家零售商（透過[[March Networks]]合併後通路）
- **智慧城市及政府:** 政府公共安全及[[智慧城市]]安防專案（[[NDAA]]合規）
- **全球系統整合商:** 100+國家200+授權經銷商及系統整合商（VIVOTEK品牌通路）
- **[[ODM]]客戶:** 國際電信及網路設備大廠（[[ODM]]代工，受[[NDA]]保護）
