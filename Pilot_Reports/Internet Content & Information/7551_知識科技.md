# 7551 - 知識科技

## 業務簡介
**板塊:** Communication Services
**產業:** Internet Content & Information
**市值:** 162 百萬台幣
**企業價值:** 102 百萬台幣

知識科技 (7551，Flashaim Technology) 為深耕逾二十年之數位行銷整合服務商，總部設於台南，於台北、台中、高雄設有分公司，主要協助台灣中小型實體店家進行數位轉型與網路行銷。公司擁有 [[Google]] 認證合作夥伴 (Google Certified Collaborative Partner) 資格及 [[LINE]] Diamond 級銷售夥伴認證，同時代理 [[Meta]]（Facebook/Instagram）與 [[Yahoo]] 等平台之數位廣告。核心自主產品包含 Mapsbooking（整合 [[Google]] 地圖之線上預訂系統）與 FANSbee（[[LINE]] 官方帳號聊天機器人與智能導購平台），服務客戶逾萬家台灣中小企業。

**營收結構方面**，公司實際收入高度集中於數位廣告代理業務，2024 年廣告代理服務（代理 [[Google]] Ads、[[LINE]] LAP、[[Meta]] 廣告、[[Yahoo]] 原生廣告）佔總營收約 93%；Mapsbooking 商家管理服務約佔 5%；網站設計與電商建置約佔 1%。此結構係毛利率長期壓縮的根本原因——廣告平台費用幾乎直接轉嫁，毛利率自 2020 年 34% 急速跌至 2024 年 7.8%。2025 年合併營收 1.95 億台幣，連續三年虧損，EPS 為 -1.24 元；惟 2026 年 Q1-Q2 月營收年增率回升至 35-54%，顯示業務逐步回暖。

**核心技術與競爭優勢方面**，Mapsbooking 為具專利技術之 [[Google]] 地圖預訂整合系統，消費者於 [[Google]] 地圖點選「預訂」後 10 秒內完成訂位，自動同步 [[Google]] Calendar 並整合 [[LINE Pay]] 付款，可協助商家將 [[Google]] 地圖流量直接轉化為實際訂單與營收；FANSbee 則以 [[LINE]] Diamond 級銷售夥伴資格開發官方帳號 API 模組，整合 POS、會員卡、電商與推播功能，訂閱定價 12,600 元起（年費）。案例中，[[LG Electronics]] 台灣導入 FANSbee 後，LINE 官方帳號好友數在一年內自 25,778 成長至 50,581 人（年增 96%）。公司在台灣尤具 Google 商家優化 (GMB) 與地圖廣告差異化優勢。

**成長動能方面**，2026 年月營收回升主因係廣告業務回溫及新客戶帶入，公司正推動業務結構優化——提升 Mapsbooking 與 FANSbee 等自主 SaaS 產品佔比，以改善長期毛利率。餐飲業是最大目標市場，Mapsbooking 以「每筆訂位費 1 元、零設定費」低門檻切入，藉此建立商家黏著度後再轉化訂閱收費。LINE Points 商家給點服務則協助商家引流至 [[Google]] 地圖五星好評、[[Facebook]]、[[Instagram]]，構建完整 OMO（線上融合線下）閉環。同時，四地辦公室（台北、台中、台南、高雄）提供在地業務人員服務，強化中小企業客戶深度綁定。

主要風險：93% 收入來自廣告代理業務，業務結構型毛利率偏低（7.8-10%），難以覆蓋固定費用，導致連續虧損；SaaS 自主產品 Mapsbooking 與 FANSbee 貨幣化進展緩慢，規模化路徑尚不清晰；台灣數位廣告市場成長趨緩且競爭激烈，[[91APP]]、LeRanking 等競品持續搶奪中小企業客戶；70 人以上員工、四地辦公室之固定費用結構相對 1.95 億元年營收而言費用率偏重，改善需仰賴業務規模快速擴張或產品結構轉型成功。

## 供應鏈位置
**上游 (網路平台與技術原廠):**
- **搜尋/地圖:** [[Google]] — [[Google]] Ads 廣告平台、[[Google]] Maps API、GMB 商家後台系統
- **即時通訊:** [[LINE]] — LINE 官方帳號 API、LAP 廣告平台（Diamond 級合作夥伴）
- **社群廣告:** [[Meta]] — Facebook/Instagram 廣告系統
- **搜尋廣告:** [[Yahoo]] — Yahoo 原生廣告平台
- **支付服務:** [[LINE Pay]] — Mapsbooking 線上預訂整合付款

**中游 (數位行銷整合服務):**
- **知識科技 (Flashaim)** (Mapsbooking 地圖預訂系統、FANSbee LINE 機器人、廣告代操、電商網站建置)

**下游 (終端店家客戶):**
- **連鎖餐飲:** 台灣中小型連鎖餐飲品牌 — Mapsbooking 地圖預訂與 FANSbee LINE 導購
- **零售通路:** 實體零售店家 — 廣告代操與電商轉型
- **消費電器品牌:** [[LG Electronics]] — FANSbee LINE 官方帳號導購
- **非營利組織:** 舊鞋救命協會 (Step30) — LINE Pay 捐款整合

## 主要客戶及供應商
### 主要客戶
- **連鎖餐飲業者:** 台灣中小型連鎖餐飲品牌（餐廳為 Mapsbooking 最大目標市場）— 地圖預訂系統與 [[LINE]] 導購整合
- **消費電器品牌:** [[LG Electronics]] 台灣 — FANSbee LINE 官方帳號智能導購，好友數一年內成長 96%
- **零售通路:** 實體零售品牌 — [[Google]] 廣告代操與電商建置
- **醫療診所:** 診所與醫療機構 — 線上預約系統與廣告代操
- **非營利組織:** 舊鞋救命協會 (Step30) 等公益團體 — [[LINE Pay]] 捐款整合與數位行銷

### 主要合作夥伴
- **搜尋/地圖:** [[Google]] — 認證合作夥伴，[[Google]] Maps API 與 Ads 廣告整合
- **即時通訊:** [[LINE]] — Diamond 級銷售夥伴認證，LINE 官方帳號 API 開發
- **社群廣告:** [[Meta]] — Facebook/Instagram 廣告代理
- **搜尋廣告:** [[Yahoo]] — Yahoo 廣告平台代理
