# 6272_驊陞

## 業務簡介
**板塊:** Technology
**產業:** Electronic Components
**市值:** 2,073 百萬台幣
**企業價值:** 2,913 百萬台幣

驊陞科技股份有限公司（6272）為專精於高頻高速電子連接器與車用電子線束的研發製造商，於 2025 年 12 月正式在台灣證交所掛牌上市。公司分為「智能電子」與「車用電子」兩大事業體；智能電子聚焦 [[DisplayPort]] 2.1（DP 2.1）連接器、[[Type-C]] 線材及高頻傳輸配件，切入 [[NVIDIA]] RTX 50 系列顯卡供應鏈；車用電子則為 [[比亞迪]] 等新能源車廠提供車載天線、各類線束及車用充電座。

**營收結構方面**，車用電子事業部（車載天線、線束、新能源車充電座）占集團營收逾 50%，智能電子（DP 2.1 連接器、AI GPU 傳輸線材、網通配件）占約 40%，其他（工控、醫療）占約 10%。地理上，中國大陸市場（含車用與智能電子）占比超過六成，亞太其他地區及北美合計約四成。

**核心技術與競爭優勢方面**，驊陞為全球 DP 2.1 規格制定參與廠商之一，在 [[NVIDIA]] RTX 50 系列 Enh DP 2.1 連接器認證中成為首選供應商，掌握高頻傳輸 SI（訊號完整性）設計能力。車用事業已取得 [[比亞迪]] Tier 1 供應商資格，並切入多家中國大陸造車新勢力，通過 IATF 16949 車用品質認證。新開發的雙頻窄波束寬陣列天線整合 [[5G]] NR 與 Ku-band [[低軌衛星]] 接收技術，開拓新藍海。

**成長動能方面**，[[AI PC]] 及 [[AI 伺服器]] 普及帶動 DP 2.1 連接器需求倍增；新能源車滲透率持續提升推動車載天線與線束出貨量；低軌衛星地面接收站導入雙頻天線產品；2025 年前三季營收 30.6 億元，年增 41%，毛利率維持 26% 以上高水準。

主要風險：中美貿易戰關稅風險衝擊中國大陸製造基地競爭力；驊陞對 [[NVIDIA]] GPU 供應鏈高度集中，顯卡換代週期易造成出貨不穩定；車用電子中國大陸車廠競爭激烈，價格壓力持續；新能源車滲透放緩可能影響車用電子成長預期。

## 供應鏈位置
**上游（原料與關鍵元件）：**
- **高頻銅線:** 無氧銅線及隔離材料供應商
- **精密塑膠:** 高頻傳輸用 LCP、PPS 工程塑膠原料商
- **金屬沖壓件:** 精密端子與屏蔽殼沖壓廠

**中游（公司定位）：**
- **智能電子:** **驊陞** — DP 2.1 連接器、[[Type-C]] 線材、高頻傳輸線束
- **車用電子:** **驊陞** — 車載天線、電動車充電座、各類車用線束

**下游（終端應用）：**
- **AI GPU 顯卡:** [[NVIDIA]] RTX 50 系列 — Enh DP 2.1 連接器
- **AI 伺服器:** 伺服器 ODM 廠 — 高速傳輸線材
- **新能源車:** [[比亞迪]] 及中國大陸造車新勢力 — 車載天線與線束

## 主要客戶及供應商
### 主要客戶
- **AI GPU 顯卡:** [[NVIDIA]] — RTX 50 系列 Enh DP 2.1 連接器首選供應商
- **新能源車:** [[比亞迪]] — 車載天線、線束（Tier 1 直供）
- **造車新勢力:** 中國大陸其他新能源車廠 — 車用電子零組件
- **PC 品牌:** 全球 PC/AI PC 品牌 — DP 2.1 及 [[Type-C]] 線材

### 主要供應商
- **無氧銅線:** 國內外高導電率銅線冶煉廠
- **工程塑料:** LCP、PPS 高頻用工程塑膠原料商
- **端子沖壓:** 精密金屬端子沖壓廠
