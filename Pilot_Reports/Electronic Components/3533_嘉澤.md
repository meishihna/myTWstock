# 3533 - 嘉澤

## 業務簡介
**板塊:** Technology
**產業:** Electronic Components
**市值:** 219,956 百萬台幣
**企業價值:** 211,798 百萬台幣

嘉澤端子工業股份有限公司（Lotes），成立於1986年，總部位於基隆，2007年上市，是全球前三大 CPU Socket（中央處理器插槽）製造商，與[[鴻騰精密]]（富士康子公司）合計掌握全球 CPU Socket 市場約70至80%份額。公司同時持有 [[Intel]] 與 [[AMD]] 雙認證，能跨平台供應最新世代 CPU Socket（Intel LGA 系列、AMD SP5/SP6 等），並涵蓋 [[DDR5]] 記憶體插槽、[[PCIe Gen 5/Gen 6]] 連接器、[[SOCAMM]] 記憶體模組接口等先進產品。子公司嘉基（[[嘉基]]，股票代號6715），專注於[[Thunderbolt]]、[[光纖]]高速傳輸線材，協同拓展[[資料中心]]光通訊市場。2024年合併營收達300.88億元台幣（歷史新高），2025年 EPS 為70.17元。

**營收結構方面**，嘉澤端子的營收以伺服器市場為最大來源，2026年第一季伺服器業務首次突破50%（年增60%），與此前的30至40%相比顯著躍升；個人電腦/筆記型電腦主機板 CPU Socket 及 DDR 記憶體插槽佔約30至35%；高速傳輸線材（子公司[[嘉基]]）佔約12%；汽車及工業應用佔約7至9%。產品組合以高毛利 CPU Socket 及 DDR5 插槽為核心，毛利率長期維持50%以上，居台灣連接器產業最高水準之一。

**核心技術與競爭優勢方面**，嘉澤端子的核心護城河在於與 [[Intel]] 及 [[AMD]] 深度共同開發 CPU 腳位規格，作為新一代 CPU 平台規格制定的直接參與方，在新腳位量產前即可完成設計優化，形成極高技術壁壘。近年推出的液冷快速接頭（UQD/MQD）已通過 [[NVIDIA]] 認證，正式切入 [[AI伺服器]] 液冷散熱基礎設施市場；[[SOCAMM]] 新規格記憶體接口亦有望進入 NVIDIA VR200 次世代平台。子公司[[嘉基]]在[[Thunderbolt]]及光纖傳輸線領域取得美系網通業者數據中心認證，形成高速傳輸線材與連接器的協同效益。

**成長動能方面**，嘉澤端子的未來成長來自三大主軸：一是 [[Intel]] 及 [[AMD]] 新世代伺服器 CPU 平台升級（腳位數從5,000升至6,096乃至7,000以上 Pins），顯著拉高 CPU Socket ASP（單價提升15%以上）；二是液冷 QD 快接頭（UQD/MQD）於2026年下半年貢獻實質獲利（4款均獲 [[NVIDIA]] 認證），隨[[AI伺服器]]液冷滲透率從15%提升至40%，市場空間巨大；三是子公司[[嘉基]]高速線材（[[Thunderbolt]]、光纖傳輸線）隨[[資料中心]]建設加速持續放量。法人估算2026年 EPS 有望挑戰95元歷史新高。

主要風險：CPU Socket 業務高度依賴 [[Intel]]/[[AMD]] 平台升級時程（延遲則影響換機週期與新品訂單）；[[鴻騰精密]]（富士康子公司）持續在 CPU Socket 市場形成價格競爭壓力；液冷 QD 快接頭毛利率低於公司平均，短期稀釋整體獲利；PC/NB 端市場景氣週期性需求波動（仍佔30至35%）；高股價基期（千金股）造成流動性限制，散戶參與度低；台海地緣政治風險對高集中度台灣供應商形成潛在威脅。

## 供應鏈位置
**上游 (原料與設備):**
- **銅合金端子材料:** 高強度銅合金帶材（端子沖壓用）
- **貴金屬電鍍材料:** 金、鈀電鍍材料（高接觸可靠性所需）
- **工程塑膠:** 高溫耐熱 LCP 等連接器殼體材料
- **技術規格合作:** [[Intel]]、[[AMD]]（CPU Socket 腳位規格共同研發）

**中游:**
- **嘉澤端子（3533）:** CPU Socket 及高速連接器設計製造
- **子公司[[嘉基]]（6715）:** 高速傳輸線材（[[Thunderbolt]]、光纖線）製造

**下游 (終端應用):**
- **伺服器主機板ODM:** [[廣達]]、[[英業達]]、[[仁寶]]、[[緯穎]]
- **主機板品牌廠:** [[華碩]]、[[技嘉]]、[[微星]]
- **AI伺服器平台:** [[NVIDIA]]（液冷 QD 快接頭、[[SOCAMM]] 接口）
- **資料中心光通訊:** 美系網通業者（子公司[[嘉基]]服務）
