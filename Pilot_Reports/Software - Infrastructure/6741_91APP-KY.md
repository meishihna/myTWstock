# 6741 - 91APP-KY

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 7,138 百萬台幣
**企業價值:** 5,103 百萬台幣

91APP-KY（6741）成立於 2013 年，是台灣首家上市的 [[SaaS]] 公司，專注於零售與餐飲品牌的全通路數位商務解決方案，定位為「D2C（Direct-to-Consumer）電商 SaaS」與「[[OMO]]（Online-Merge-Offline，虛實融合）」市場的領導者。核心平台整合電商、行銷、[[POS]]、第三方支付及物流配送，透過軟體訂閱與交易手續費的雙軌收費模式服務品牌商。2021 年 5 月掛牌上櫃後，2025 年 11 月以新台幣約 9.6 億元（3,200 萬美元）全現金收購台灣餐飲 POS 龍頭[[iCHEF]]，業務版圖正式從零售跨入餐飲科技領域，服務餐廳據點超過 15,000 個（涵蓋台灣、香港、新加坡）。

**營收結構方面**，軟體訂閱收入（平台月費）約佔整體六成，交易手續費及廣告服務約佔四成；品牌電商（B2C）與零售通路整合服務為兩大主力。2024 年全年合併營收約 16.19 億元，年增 16.56%。2025 年前三季累計營收年增 10%，全年估計達 18.07 億元；納入[[iCHEF]]後，2026 年合併基期大幅擴大。

**核心技術與競爭優勢方面**，91APP 的[[OMO]]全通路架構整合線上電商、門市 POS、會員忠誠度系統與數位廣告，形成完整消費者旅程閉環，轉換成本極高。平台已服務逾 700 個品牌商戶，涵蓋國際快時尚、奢侈品、生活用品到本土零售通路，龐大交易資料支撐廣告精準投放能力，構建「電商 SaaS + 廣告媒體 + 支付」三位一體生態。收購[[iCHEF]]後，餐飲雲端 POS、QR Code 點餐、訂位管理及餐飲會員忠誠度系統納入版圖，打通零售×餐飲跨業資料場景，強化 AI 應用深度。

**成長動能方面**，品牌商加速 D2C 轉型（降低對平台型電商如[[PChome]]、[[蝦皮購物]]的依賴）為持續增客的核心驅動力。[[iCHEF]]帶來 4 億元年收入基礎及 15,000 餐廳據點的交易流量，強化第三方支付規模與廣告客戶多樣性。AI 驅動的個人化推薦、智慧廣告優化及門市預測補貨功能，將提升客戶 ARR（年度經常性收入）並擴大每客戶服務範疇。香港、新加坡市場亦為中長期增量目標。

主要風險：SaaS 業務成長需持續拉新客戶，在國際電商大平台（[[Shopify]]、[[蝦皮購物]]）競爭下，中小型品牌客戶的取得成本上升。[[iCHEF]]整合進度及餐飲與零售的跨業協同效益兌現時程存在不確定性；整體市場高度依賴台灣內需，拓展海外需面臨各地競爭差異與文化適應問題。

## 供應鏈位置
**上游（基礎設施與技術授權）:**
- **雲端基礎設施:** [[AWS]]、[[Google Cloud]]（電商平台運算與儲存）
- **支付清算:** [[聯信財金]]、[[歐付寶]]、Visa/Mastercard 收單銀行
- **物流合作:** [[黑貓宅急便]]、[[統一速達]]等宅配廠商

**中游:**
- **電商 SaaS 平台:** 91APP（品牌官網建置、[[OMO]]全通路整合、POS 系統）
- **餐飲科技:** 子公司[[iCHEF]]（餐飲雲端 POS、QR Code 點餐、訂位管理）
- **數位廣告:** Meta Ads、Google Ads 投放整合服務

**下游（終端客戶品牌）:**
- **國際品牌:** [[LVMH]]（GUERLAIN、MAKE UP FOR EVER）、[[VF集團]]（Timberland、The North Face）、[[PUMA]]、[[Philips]]
- **本土零售通路:** [[全聯]]、[[全家便利商店]]、[[康是美]]
- **台灣品牌:** SO NICE、小三美日
