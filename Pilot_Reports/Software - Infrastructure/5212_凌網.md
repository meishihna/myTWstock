# 5212 - 凌網

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 1,652 百萬台幣
**企業價值:** 1,307 百萬台幣

凌網科技股份有限公司（Hyweb Technology）成立於1999年，為台灣資訊服務業中深耕公部門數位化與知識管理的專業廠商，旗下擁有[[HyRead]]電子書雲端服務平台與[[Hylib]]圖書館自動化系統兩大核心品牌，長期為全台逾500個政府單位提供網站建置、資訊整合系統及圖書館資訊系統服務。2024年全年營收約11.37億元，2025年前11個月累計營收10.91億元，年增16.38%，獲利能力持續提升，EPS由2024年2.86元成長至2025年Q1~Q3累計高度成長。

**營收結構方面**，凌網營收分為四大來源：政府資訊系統建置與維護專案服務佔比最高（約46%）、電子書閱讀器與[[HyRead]]平台服務（約33%）、圖書館軟體服務及設備買賣（約11%），以及金流支付平台建置服務（約9%）。政府專案具有長期合約穩定性，[[HyRead]]平台機構客戶續約率超過90%，形成高黏性重複性收入基礎。

**核心技術與競爭優勢方面**，凌網擁有台灣最大正體中文雲端電子圖書館服務平台[[HyRead]]，在台灣及港澳地區電子書市場佔有率居首。[[Hylib]]圖書館自動化系統在台灣大專院校及縣市公共圖書館市佔率超過70%，超過150所圖書館採用。公部門長期合作關係形成強固的進入障礙，機構客戶轉換成本高，年度續約率穩健。台灣[[國家圖書館]]、各縣市[[公共圖書館]]均為其核心服務對象。

**成長動能方面**，[[HyRead]]電子書平台個人使用者每年維持約30%成長，海外市場（港澳及東南亞）擴張策略持續推進。政府數位轉型政策推動下，公部門資訊系統建置預算持續增加，凌網可望承接更多[[電子政府]]建設訂單。電子紙（[[E Ink]]）載具普及與數位閱讀習慣養成，進一步擴大[[HyRead]]平台用戶基礎。此外，金流支付平台業務可望隨台灣[[數位支付]]政策普及而成長。

主要風險：政府專案業務高度依賴公部門預算，受政策轉向或預算削減影響顯著；[[HyRead]]電子書市場雖具本地優勢，但面臨[[Readmoo]]、[[Amazon Kindle]]等競爭壓力；海外擴張成效仍待驗證，港澳市場規模有限；公司整體規模偏小，在人才招募與研發投入上的資源受限。

## 供應鏈位置
**上游 (內容與技術):**
- **電子書內容授權:** 國內外出版社如 [[遠流出版]]、[[天下雜誌]] 等授權數位書目
- **電子紙硬體:** [[E Ink]] 等電子紙顯示技術供應商
- **雲端基礎架構:** [[Amazon Web Services]]、[[Microsoft Azure]] 等雲端平台

**中游:**
- **平台服務:** **凌網** 經營 [[HyRead]] 電子書雲端平台與 [[Hylib]] 圖書館自動化系統
- **系統整合:** 政府資訊系統建置與維護、金流支付平台建置

**下游 (終端應用):**
- **公共圖書館:** [[國家圖書館]]、全台縣市[[公共圖書館]]系統
- **大專院校:** 大學圖書館數位化服務
- **政府機關:** 各縣市政府網站與資訊整合系統
- **個人讀者:** 透過 [[HyRead]] App 訂閱電子書服務

## 主要客戶及供應商
**主要客戶:**
- **政府資訊系統:** 台灣各縣市政府、中央機關 — 網站建置與資訊整合系統服務
- **圖書館系統:** [[國家圖書館]]、[[國立公共資訊圖書館]]、全台逾150所大專院校及縣市公共圖書館
- **電子書機構用戶:** 全台及港澳正體中文電子書採購機構（機構續約率逾90%）
- **金流服務客戶:** 公部門金流支付平台建置需求方

**主要供應商:**
- **出版內容:** 國內外出版社授權電子書版權
- **雲端基礎架構:** [[Amazon Web Services]]、[[Microsoft Azure]] 等雲端運算資源
- **電子紙硬體:** [[E Ink]] 電子紙顯示技術
