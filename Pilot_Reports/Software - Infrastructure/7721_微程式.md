# 7721 - 微程式

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 3,389 百萬台幣
**企業價值:** 3,410 百萬台幣

微程式資訊股份有限公司成立於1995年，長期定位為ICT Design House（設計服務公司），採輕資產營運模式，專注於軟硬體系統的研發與設計，並將生產委外。公司核心業務分為兩大領域：AIoT智慧服務方案與半導體感測控制解決方案。在AIoT領域，公司在全台公車、[[台北捷運]]、[[YouBike]]公共自行車系統及停車場等交通設施部署逾數十萬台終端設備，透過全天候雲端管理平台提供電子支付與智慧設備服務。2025年7月登錄[[台灣證券交易所]]，資本額約4億元。

**營收結構方面**，電子支付服務與智慧設備服務合計佔總營收約九成，其中電子支付（公車、捷運、YouBike等設備及雲端管理）與智慧設備（E-Bike系統、停車場控制器）各占大宗。訂閱制暨維運服務收入佔整體約四成，穩定支撐全部管銷費用，為高毛利的重複性收入基礎。半導體感測控制為新興業務，尚處拓展期，目標佔比提升至30%。2024年全年營收約7.94億元，毛利率56%，EPS 3.33元。

**核心技術與競爭優勢方面**，微程式深耕IoT感測技術整合，擁有振動感測、氣體與溫濕度監測、磁場監控及[[RFID]]模組等自主技術，並已切入半導體晶圓廠光罩、曝光、清洗、封裝等數百道製程的感測控制應用。公司透過與德鑫控股的在地半導體聯盟合作，成功進入部分晶圓代工供應鏈，並開發出低頻RFID解決方案導入迅得機械的軌道式無人搬運車（RGV）及Stoker系統。在智慧交通領域，長達近三十年的系統整合累積使其具有極高的轉換成本壁壘。

**成長動能方面**，半導體感測控制業務2025年起顯著加速，受惠於台灣[[晶圓代工]]廠追求製程良率提升而導入客製化感測方案的需求。[[AI 伺服器]]建設熱潮帶動[[台積電]]等晶圓廠持續擴產，間接拉升感測控制設備需求。E-Bike及智慧停車場等低碳運具的國內外需求亦持續擴增，公司並積極探索海外市場。2026年前三月累計營收年增逾20%，顯示成長動能延續。

主要風險：半導體感測控制業務仍處開發驗證期，客戶導入時程具不確定性；交通電子支付業務高度依賴政府採購政策及大眾運輸主管機關；競爭者可能以更低價格切入，壓縮訂閱制維運毛利；匯率波動對海外業務造成潛在衝擊。

## 供應鏈位置
**上游 (原料與設備):**
- **感測元件:** 外採振動感測器、溫濕度感測器、磁場感測器等精密元件
- **RFID 模組:** 採購低頻[[RFID]]讀寫晶片及天線模組
- **嵌入式運算:** 採用ARM架構微控制器及工業級SoC
- **代工製造:** 委外PCB板卡製造及機構件組裝（輕資產模式）

**中游:**
- **AIoT 系統整合:** **微程式** 自行研發軟硬體，整合電子支付終端、雲端管理平台及智慧感測控制系統
- **軟體訂閱服務:** 提供終端設備雲端管理、數據分析及維運支援
- **ASIC/模組設計:** 自主開發感測控制模組，導入半導體製程監控

**下游 (終端應用):**
- **公共交通支付:** [[台北捷運]]、縣市公車、[[YouBike]]公共自行車
- **智慧停車:** 全台停車場管理系統業者
- **半導體製程:** [[台積電]]等晶圓代工廠（光罩、曝光、清洗、封裝製程感測）
- **智慧製造物流:** 迅得機械（RGV/Stoker自動搬運系統）

## 主要客戶及供應商
**主要客戶（AIoT 智慧服務）:**
- **公共交通:** [[台北捷運]]（公共運輸電子支付終端）、全台縣市公車主管機關、[[YouBike]]營運商
- **停車場系統:** 全台各大停車場管理業者（政府及民間）
- **智慧物流:** 迅得機械（導入RFID無人搬運車方案）

**主要客戶（半導體感測控制）:**
- **晶圓代工:** [[台積電]]及其他晶圓代工廠（感測控制模組驗證導入中）
- **半導體聯盟:** 透過德鑫控股在地半導體聯盟進入供應鏈

**主要供應商:**
- **感測元件:** 日本、歐洲感測器原廠（振動、溫濕度、磁場感測元件）
- **RFID 晶片:** 國際RFID晶片廠商
- **代工製造:** 台灣電子代工廠（PCB組裝、機構件）
