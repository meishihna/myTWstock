# 6752 - 叡揚

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 3,584 百萬台幣
**企業價值:** 3,622 百萬台幣

叡揚資訊（6752）成立於 1987 年，英文名 Galaxy Software Services（GSS），是台灣歷史最悠久的企業應用軟體暨 [[SaaS]] 服務商之一，核心產品涵蓋人資管理（Vital HCM）、公文電子化、客戶關係管理（Vital CRM）、知識管理、財務會計，以及金融業徵授信與風險管理解決方案。2009 年起推出 Vital 雲端服務系列，以月租制 [[SaaS]] 模式服務中大型企業及政府機關，累積超過三十年的台灣本土化行政流程與法規遵循深度，形成難以快速複製的競爭優勢。

**營收結構方面**，公司分為軟體授權、維護服務及雲端訂閱三大收入來源：傳統軟體授權與系統整合服務約佔整體五成，雲端 SaaS 訂閱服務（以 Vital 系列為主）佔比持續提升，估計已達三至四成，維護服務約一至二成。客戶結構以政府機關（含中央及地方政府）及金融業（銀行、金控）為主力，佔合計約六至七成，其餘為製造、電子及服務業。全年營收規模約 5–6 億元台幣，為中型軟體服務商。

**核心技術與競爭優勢方面**，叡揚在台灣[[公文電子化]]領域具有市場主導地位，公文管理系統長期為政府機關標準配備，轉換成本極高。Vital HCM 人資系統針對台灣勞動法規（勞基法、外籍勞工管理）高度客製化，與各大銀行薪轉帳戶整合，成為大型企業人資部門首選。金融業徵授信解決方案導入[[IFRS 9]]信用減損模型與壓力測試框架，切入銀行風控系統的高壁壘利基市場。Vital 雲端服務以金融級資安規範（[[ISO 27001]]、[[CSA STAR]]認證）為訴求，強化企業客戶對雲端遷移的信任。

**成長動能方面**，台灣政府持續推動行政數位轉型，各機關升級公文管理、智能表單及電子簽核系統的預算穩定。企業永續（ESG）趨勢帶動碳排查管理模組（Vital Carbon）的新增訂閱需求。雲端 SaaS 轉換率提升（傳統套裝軟體客戶轉至 Vital 月租制）能提高收入能見度並改善現金流結構。AI 智能對話（Chatbot）服務整合至 Vital CRM 與公文系統，有助於提升客戶服務效率。

主要風險：政府標案高度依賴預算週期，若公部門資訊化預算遭刪減或政策轉向（如轉用開源方案），將直接衝擊訂單。公司規模偏小，在面對國際 ERP 大廠（[[SAP]]、[[Oracle]]）攻入中大型企業市場或本土新創競爭時，研發資源有限。雲端 SaaS 化轉型期間，授權收入可能出現結構性下滑，須依賴訂閱收入的增速抵補。

## 供應鏈位置
**上游（基礎設施與技術）:**
- **雲端基礎設施:** [[Microsoft Azure]]、[[AWS]]（Vital 雲端服務底層運算）
- **資安認證:** [[ISO 27001]]、[[CSA STAR]]標準認證機構
- **AI 技術:** [[Microsoft Azure OpenAI]]（Chatbot 智能對話整合）

**中游:**
- **企業 SaaS 平台:** 叡揚資訊（Vital HCM、Vital CRM、公文管理、碳排查管理）
- **系統整合服務:** 客製化導入、教育訓練、維護支援

**下游（終端客戶）:**
- **政府機關:** 中央政府各部會、地方政府機關（公文電子化主要用戶）
- **金融業:** 本土銀行、金控（徵授信風控系統、[[IFRS 9]]模型）
- **製造與服務業:** 大型製造企業人資系統、碳排查管理

## 主要客戶及供應商
**主要客戶（依產業）:**
- **政府機關:** 中央政府部會、地方政府；公文電子化系統及智能表單為主要需求，採購透過政府共同供應契約
- **金融業:** 本土銀行及金控（徵授信風控、[[IFRS 9]]信用減損模型、人資管理）
- **製造業:** 遠通電收、金泰工業等大型企業（Vital HCM 人資系統）
- **服務業:** 多元產業中大型企業（Vital CRM、知識管理平台）

**主要供應商（技術夥伴）:**
- **雲端基礎設施:** [[Microsoft Azure]]（Vital 雲端服務主要承載平台）、[[AWS]]
- **AI 應用:** [[Microsoft Azure OpenAI]]（Chatbot、智能表單 AI 功能）
- **資安認證機構:** [[ISO 27001]]、[[CSA STAR]]認證合作
