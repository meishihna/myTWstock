# 6878_歐付寶

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 1,758 百萬台幣
**企業價值:** 1,421 百萬台幣

歐付寶電子支付股份有限公司（6878）成立於2011年9月，總部設於台北市，是台灣最早獲得電子支付執照的業者之一，2015年正式取得主管機關核准的電子支付業務資格。公司提供消費者與商家電子帳戶儲值、收付款、跨境支付及電子發票等全方位第三方支付金流服務，截至2025年初用戶數約108萬，在台灣電子支付業者中規模排名第七。

**營收結構方面**，歐付寶主要營收來源為向商家收取的交易手續費（依交易類型如信用卡、ATM、超商代碼等比例收費），以及跨境支付匯兌差額。公司支援多元收款方式，包括信用卡、ATM 轉帳、網路 ATM、四大超商代碼繳費、條碼繳費及海外金流；跨境業務方面，歐付寶取得主管機關核准，可接受境外人士持境外機構發行之支付帳戶或儲值卡在台消費，並代辦外幣兌換及海外匯款。公司亦支援 [[微信支付]] 跨境收款，協助台灣商家接受中國大陸旅客付款。

**核心技術與競爭優勢方面**，歐付寶通過國際支付安全認證 [[PCI-DSS]]，確保交易資料安全合規，是台灣電子支付業者中少數具備完整跨境收付款能力的開放平台。公司採開放平台策略，提供 API 文件供電商、APP 開發商串接，降低商家技術整合門檻；累積的商家網絡與消費者帳戶儲值基礎構成一定程度的轉換障礙。公司亦具備電子發票整合功能，協助電商平台完成消費到開票的一站式流程。

**成長動能方面**，台灣電子支付滲透率持續提升，主管機關放寬跨境交易與境外人士使用電子支付的限制，有助歐付寶拓展跨境業務；來台旅遊消費復甦帶動 [[微信支付]] 等跨境收款需求；電商生態系整合（API 串接）擴大商家覆蓋；政府推動無現金社會政策，長期有利電子支付整體市場成長。

主要風險：台灣電子支付市場高度競爭，面臨 [[街口支付]]、[[LINE Pay]]、[[悠遊付]]、各大銀行 Pay 服務等強勁競爭者，市場份額偏小（排名第七）；獲利能力偏弱，近年 EPS 為負值；商家手續費率受競爭壓縮空間有限；監管要求趨嚴，資安及資本適足率要求持續增加合規成本。

## 供應鏈位置
**上游 (金融基礎設施):**
- **國際卡組織:** [[Visa]]、[[Mastercard]]、[[JCB]]（信用卡收款清算網路）
- **本土銀行:** 合作銀行提供 ATM 清算、資金保管及外幣兌換服務
- **超商通路:** [[統一超商 7-ELEVEN]]、[[全家便利商店]]、[[萊爾富]]、[[OK 超商]]（代碼繳費通路）
- **跨境支付:** [[微信支付]]（騰訊）跨境收款合作
- **技術認證:** [[PCI-DSS]] 認證（國際支付安全標準）

**中游:**
- **歐付寶** 作為電子支付平台，提供商家端收款整合、消費者端電子帳戶，以及清算、退款、跨境匯兌等後台服務

**下游 (商家與消費者):**
- **電商平台:** 中小型電商網站、APP 應用程式開發商（API 串接）
- **實體商店:** 餐飲、零售等實體消費場域
- **政府與公用事業:** 繳費代收服務
- **海外入境旅客:** 使用境外支付帳戶在台消費

## 主要客戶及供應商
**主要客戶（商家端）:**

**電商與數位平台:**
- 中小型電商、APP 服務商（透過 [[API]] 串接歐付寶金流）
- 遊戲及數位內容平台（點數儲值繳費）

**實體商家:**
- 餐飲業者、零售店（行動支付收款）
- 觀光景點及旅宿業者（接受 [[微信支付]] 跨境旅客）

**主要上游合作夥伴:**
- [[Visa]]、[[Mastercard]]（卡組織清算）
- [[統一超商 7-ELEVEN]]、[[全家便利商店]]（超商代碼繳費通路）
- 合作銀行（資金保管、ATM 清算）
- [[微信支付]]（跨境收款合作）
