# 6689_伊雲谷

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 4,231 百萬台幣
**企業價值:** 2,501 百萬台幣

伊雲谷數位科技（6689）成立於2013年，是台灣最大的[[AWS]]雲端代理商暨受管服務供應商（MSP），亦為大中華區首位取得「AWS 核心級服務合作夥伴」認證的公司。公司定位為多雲整合服務商，旗下集合[[AWS]]、[[Microsoft Azure]]、[[Google Cloud]]（GCP）與[[Oracle Cloud]]四大公有雲平台，並透過子公司「雲馥數位」（台灣首家 Azure MSP）、「雲動力資訊」（GCP Premier Partner）提供一站式企業雲端遷移、雲端優化、資安與 AI 解決方案。全球員工超過 800 人，據點橫跨台灣、菲律賓、新加坡、馬來西亞、泰國、印尼、越南及澳洲等 14 處，為台灣雲端服務業中海外佈局最廣泛的業者之一。

**營收結構方面**，雲端服務為公司絕對核心，佔整體營收近 99%，已完全取代早期硬體銷售業務。地區結構上，台灣市場約佔 46%，東南亞市場約佔 26%，其餘為香港、中國及其他亞太地區；遊戲、公部門及金融業為三大高成長垂直市場。2024 年全年合併營收約 126 億元台幣，2025 年 H1 雲端營收年增約 3%，達 64 億元，因東南亞擴張初期費用拉高，整體營業利益率略受壓縮至約 0.1%。

**核心技術與競爭優勢方面**，伊雲谷以「Land and Expand」策略深化客戶滲透，憑藉[[AWS]]最高合作夥伴等級，以及 2024 年榮獲「AWS 全球年度 MSP 合作夥伴獎（MSP Partner of the Year – Global）」，建立難以複製的雲端服務認證護城河。子公司雲動力資訊推出「Argon 企業 AI 夥伴」，整合[[Amazon Bedrock]]、[[Google Gemini]]、[[OpenAI]] GPT 等大型語言模型，提供企業 AI Agent 應用。在資安領域，公司取得[[Cloud Security Alliance]]（CSA）Trusted Cloud Provider 認證及[[AWS]] MSSP 資安能力認證，同步切入 MDR（受管偵測與應變）市場，強化資安服務收益。

**成長動能方面**，東南亞市場（尤其新加坡、馬來西亞、泰國、印尼）仍是最重要的擴張引擎，配合各國政府推動數位轉型政策，預期為雲端遷移帶來持續訂單。AI 應用服務（[[Generative AI]]工作坊、[[Amazon SageMaker]]建模、[[Azure OpenAI]]企業部署）已成為高毛利差異化服務，有助於改善整體毛利結構。隨台灣政府資安政策趨嚴，結合 MSSP 資安服務的複合型雲端方案亦具備顯著增長空間。

主要風險：高度依賴[[AWS]]單一超大型雲端平台，若亞馬遜調整代理商分潤政策或直接競爭，將對毛利率造成壓力。此外，東南亞各市場競爭激烈，本地資安法規差異大，拓展成本不低；整體毛利率長期偏低（約 6–8%），遇到景氣下行時抗壓能力有限。

## 供應鏈位置
**上游（技術授權與雲端基礎設施）:**
- **公有雲平台:** [[AWS]]（Amazon Web Services）、[[Microsoft Azure]]、[[Google Cloud]]、[[Oracle Cloud]]
- **AI 模型授權:** [[OpenAI]]、[[Google Gemini]]、[[Amazon Bedrock]]
- **資安技術:** [[CrowdStrike]]、[[Palo Alto Networks]]等端點及網路安全廠商

**中游:**
- **雲端代理與整合:** 伊雲谷（多雲 MSP、雲端遷移、DevOps 顧問）
- **AI 應用開發:** 子公司雲動力資訊（GCP Premier Partner、Argon AI 夥伴平台）
- **Azure 受管服務:** 子公司雲馥數位（台灣首家 Azure MSP）

**下游（終端客戶）:**
- **遊戲業:** 遊戲公司雲端基礎設施與 CDN 優化
- **金融業:** 銀行、金控雲端遷移與合規架構
- **公部門:** 政府機關雲端化及資安監控
- **製造業:** [[台積電]]等半導體與製造企業數位轉型

## 主要客戶及供應商
**主要客戶（依產業）:**
- **遊戲與娛樂:** 台灣及東南亞遊戲公司，以 AWS 高彈性運算為主要需求
- **金融機構:** 本土銀行、金控，需求集中於合規雲端架構與資安監控（MSSP）
- **政府機關:** 台灣及東南亞公部門，受惠於各國數位轉型政策
- **科技製造:** 半導體及電子製造業者，大型資料中心遷移與 AI 應用建置

**主要供應商（技術合作夥伴）:**
- **核心雲端平台:** [[AWS]]（最高合作夥伴等級）、[[Microsoft Azure]]（透過子公司雲馥數位）、[[Google Cloud]]（透過子公司雲動力資訊）、[[Oracle Cloud]]
- **AI 應用:** [[OpenAI]]、[[Amazon Bedrock]]、[[Google Gemini]]
- **資安技術夥伴:** [[Cloud Security Alliance]]（CSA）認證合作、[[SecurityScorecard]]
