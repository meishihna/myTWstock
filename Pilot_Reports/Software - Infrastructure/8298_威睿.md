# 8298 - 威睿

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 970 百萬台幣
**企業價值:** 642 百萬台幣

威睿科技股份有限公司（Genie Networks Limited，股票代號8298）成立於1989年，總部設於台北，是台灣老牌網路流量分析及DDoS防護解決方案專業廠商，以自有品牌產品GenieATM系列及GenieAnalytics系列在全球電信商及大型網路營運商市場深耕逾三十年。公司採軟體驅動的電信級網路設備商業模式，主要服務客戶為網路服務業者（ISP）、政府組織、學術機構及大型企業，業務遍及全球逾40個國家。2025年全年度營收及訂單較前年成長逾50%，為公司多年來最強勁的業績表現。

**營收結構方面**，軟體授權及維護訂閱收入為主要來源，包含GenieATM網路流量分析平台授權及年度維護合約；DDoS防護解決方案（含流量清洗服務及設備授權）為第二大業務；此外有專業服務、系統整合及訓練等服務收入。以地域分布，海外市場佔比逾七成，涵蓋亞太、歐洲、中東、非洲及俄羅斯等地區，台灣本土佔約三成。2025年成功取得[[Airtel Africa]]等非洲最大電信集團訂單，顯示地理版圖持續擴張。

**核心技術與競爭優勢方面**，威睿科技的GenieATM平台以[[IP Flow]]（[[NetFlow]]/[[sFlow]]）技術為核心，具備全網流量行為自動學習、大規模異常流量偵測及攻擊緩解自動化能力，可應對每秒數百Gbps的電信級流量清洗需求。公司與[[Radware]]（那斯達克上市資安廠商）深化策略結盟，整合Radware的DDoS緩解設備，形成流量偵測加攻擊清洗的完整防禦解決方案。中國移動等全球一線電信商的導入案例，為其在電信級市場提供強力背書。

**成長動能方面**，[[5G]]網路大規模商用後，電信商面臨更複雜的流量管理及更大規模的DDoS攻擊威脅，推升對電信級網路流量智能分析與防護解決方案的需求。[[AI 資料中心]]及[[雲端運算]]基礎設施的快速擴張，亦帶動大型網路營運商對流量可視化及安全監控工具的採購。[[Airtel Africa]]訂單的取得顯示新興市場電信商的需求正在加速，公司2025年起積極進軍非洲及中東市場，開拓全新成長曲線。

主要風險：公司規模偏小，單一大型訂單的取得或流失對年度營收影響顯著；電信商資本支出週期性波動影響採購時程；[[Cisco]]、[[Nokia]]等網路設備大廠亦提供流量分析模組，形成競爭壓力；俄羅斯等地緣政治敏感市場的業務面臨出口管制風險；開源流量分析工具普及化對中小型ISP客群造成替代威脅。

## 供應鏈位置
**上游 (技術夥伴與元件):**
- **DDoS 緩解設備:** [[Radware]]（那斯達克上市，策略結盟DDoS清洗設備）
- **伺服器硬體:** [[Dell]]、[[HP]]等工業伺服器（GenieATM軟體運行平台）
- **網路元件:** Cisco相容網路設備元件（流量採樣探針）
- **雲端基礎設施:** 公有雲（GenieATM雲端版部署）

**中游:**
- **網路流量分析:** **威睿科技** 自行研發GenieATM及GenieAnalytics平台，提供流量視覺化、異常偵測及DDoS防護
- **系統整合服務:** 提供客製化安裝、調校及訓練服務
- **維護訂閱:** 年度軟體維護及技術支援合約

**下游 (終端應用):**
- **電信商:** 亞太、歐洲、中東、非洲及俄羅斯ISP（網路流量管理及DDoS防護）
- **政府及學術:** 政府網路中心及大學網路（流量監控及安全）
- **大型企業:** 金融、能源等關鍵基礎設施企業（企業網路安全監控）
