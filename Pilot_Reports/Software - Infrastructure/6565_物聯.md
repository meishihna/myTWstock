# 6565_物聯

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 475 百萬台幣
**企業價值:** 323 百萬台幣

物聯智慧股份有限公司（6565）成立於2008年，是台灣深耕[[物聯網]]雲端平台的軟體服務廠商，以自主研發的[[Kalay]]雲端連線平台為核心，提供影像監控裝置、智慧家庭聯網設備之P2P點對點連線、雲端影像儲存、遠端存取及AI分析等端到端IoT解決方案。目前[[Kalay]]平台已連接全球逾13億台物聯網設備，服務涵蓋超過190個國家，2024年全年累計營收（前11個月）約2.42億元，年增81%，為近年業績最佳表現。

**營收結構方面**，物聯智慧的收入分為四類：雲端服務收入（Kalay雲端連線平台訂閱與使用量計費，逐年提升）、軟體授權收入（SDK/韌體授權）、設計服務收入（客製化整合方案）及硬體相關收入。雲端服務收入占比持續成長，反映SaaS化商業模式轉型成效；2025年北美市場因感恩節與聖誕節節慶備貨需求年增32%，東北亞市場連續兩年為成長最快區域。

**核心技術與競爭優勢方面**，物聯智慧的核心競爭力在於[[Kalay]] P2P連線技術，能在複雜的網路防火牆環境下建立穩定低延遲的點對點通道，是IP攝影機、嬰兒監視器、寵物攝影機、智慧門鈴等設備廠商嵌入雲端功能的首選平台。[[Kalay]]平台功能模組涵蓋P2P/IoT連線、影像監控與儲存、訊息推播、線上更新及智慧語音助理整合，形成高度完整的一站式IoT軟體基礎架構，客戶導入後轉換成本高。公司已與中國移動旗下[[中移物聯]]建立戰略合作。

**成長動能方面**，[[AI]]邊緣運算普及推動IP攝影機升級至[[AIoT]]智慧安防設備，物聯智慧的[[Kalay]]平台可整合[[AI]]影像分析功能（如人臉辨識、行為偵測），帶動每台設備雲端服務費用提升。[[智慧家庭]]市場持續擴大，[[Amazon Alexa]]、[[Google Home]]等語音助理生態系整合需求增加[[Kalay]]平台附加價值。東北亞（日韓）市場快速成長，加上北美[[安防]]市場持續需求，為物聯智慧提供地理多元化成長動能。公司2025年法說會在宏遠證券舉行，顯示主動強化投資人關係。

主要風險：物聯智慧平台安全性是核心弱點，歷史上曾有研究機構（美國CISA）提示[[Kalay]]協議存在安全漏洞，雖已修補，但安全疑慮影響品牌形象；中國大陸為重要市場，地緣政治風險與中國本土廠商競爭（[[海康威視]]、[[大華]]等）壓縮成長空間；雲端平台訂閱模式轉型期間，每設備平均收費偏低，需要龐大設備量才能支撐顯著營收；主要客戶為中小規模攝影機品牌廠商，客戶集中風險相對分散但議價能力不高。

## 供應鏈位置
**上游 (基礎架構):**
- **雲端基礎架構:** [[Amazon Web Services]]、[[Microsoft Azure]]、[[Google Cloud]] — 雲端運算與儲存資源
- **通訊模組:** [[Qualcomm]]、[[聯發科]] 等晶片廠提供 IoT 裝置運算平台
- **網路安全技術:** 加密協議與資安技術授權

**中游:**
- **IoT 雲端平台:** **物聯智慧** 提供 [[Kalay]] P2P 連線平台、SDK、韌體及雲端影像服務
- **客製化整合:** 針對品牌廠商提供設計服務與系統整合

**下游 (終端應用):**
- **智慧安防:** IP 攝影機、門鈴攝影機廠商嵌入 [[Kalay]] 雲端連線能力
- **智慧家庭:** 寵物攝影機、嬰兒監視器、智慧機器人等消費型 IoT 設備品牌廠
- **企業物聯網:** 中移物聯（[[中移物聯]]）等電信業者 OneLink 平台整合
- **車聯網:** 汽車智慧後視鏡與行車記錄器 IoT 連線應用

## 主要客戶及供應商
**主要客戶:**
- **中國電信業者:** [[中移物聯]]（中國移動旗下）— 戰略合作，OneLink 平台整合 [[Kalay]] 雲端服務
- **全球 IP 攝影機品牌廠:** 全球逾190個國家攝影機、智慧家庭裝置設備廠商嵌入 [[Kalay]] SDK
- **北美智慧家庭市場:** 智慧門鈴、寵物攝影機、嬰兒監視器品牌廠
- **東北亞市場:** 日本、韓國智慧安防與 [[AIoT]] 設備品牌廠

**主要供應商:**
- **雲端基礎設施:** [[Amazon Web Services]]、[[Microsoft Azure]]、[[Google Cloud]]
- **IoT 晶片平台:** [[Qualcomm]]、[[聯發科]] — 裝置端運算平台
