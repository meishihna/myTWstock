# 6462_神盾

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 9,308 百萬台幣
**企業價值:** 13,922 百萬台幣

神盾股份有限公司（Egis Technology）成立於2007年，為台灣指紋辨識IC設計專業廠商，透過併購整合祥群（滑刷式與按壓式指紋辨識晶片）、京琥科技（指紋辨識演算法）及網際威信軟體部門（資料加密及安全防護）三家公司而建立，是全球少數能同時提供指紋辨識晶片與演算法一體化解決方案的IC設計廠。2024年全年營收約47.9億元，較2023年成長24.47%，2025年因中國手機品牌競爭加劇而出現虧損壓力。

**營收結構方面**，神盾營收以指紋辨識IC為核心，電容式、光學式（螢幕下）指紋辨識IC合計佔營收約75%以上；2024年完成斥資約47億元併購乾瞻科技後，半導體IP授權業務（含UCIe、DDR、LPDDR Combo PHY等foundation IP）成為新興收入貢獻來源，乾瞻科技IP業務年營收4至5億元、淨利率高達50%。車用指紋辨識IC（供[[現代汽車]]Genesis車款與[[起亞]]K9旗艦車款）為高毛利利基應用。

**核心技術與競爭優勢方面**，神盾是全球率先將光學式螢幕下指紋辨識（under-display fingerprint）商業化的少數廠商之一，與[[友達]]合作推出全球首款支援[[OLED]]面板的大面積超薄光學指紋感測模組，支援雙手指辨識。神盾與[[力旺電子]]（eMemory）聯合發表全球首款類比AI晶片，結合非揮發性記憶體（[[NVM]]）與光學指紋辨識，應用於螢幕下大面積辨識系統。FIDO國際標準組織董事會成員（台灣唯一），確保技術規格話語權。

**成長動能方面**，車用指紋辨識IC已成功打入[[現代汽車]]（含Genesis品牌）與[[起亞]]兩大韓國車廠供應鏈，成為韓國車廠獨家供應商；隨電動車智慧安全功能需求擴大，車用市場成為重要的成長引擎。乾瞻科技IP授權業務（UCIe互連標準IP等先進製程IP）受惠[[AI 伺服器]]與[[HBM]]等先進封裝技術普及而受益。此外，TOF（飛時測距）IC與P-Sensor（近接感應器）等多元感測器產品線，有助分散手機指紋單一應用依賴。

主要風險：中國IC設計廠商（[[匯頂科技]]等）在手機指紋辨識晶片市場大幅侵蝕神盾市占率，導致公司連虧；[[三星電子]]為最大單一手機客戶，集中度偏高，訂單波動直接衝擊業績；乾瞻科技IP業務並購整合成效及後續IP授權市場景氣，左右公司獲利前景；車用市場訂單雖具長期性，但導入周期漫長，量產規模難以快速放大。

## 供應鏈位置
**上游 (IP 與製造):**
- **晶圓代工:** [[台積電]]、[[聯華電子]] — 指紋辨識IC製造
- **矽智財 (IP):** [[力旺電子]] (eMemory) — NVM 類比 AI 晶片技術合作；乾瞻科技（已併購）提供 UCIe、DDR/LPDDR PHY 等 foundation IP
- **OLED 面板:** [[友達]] — 螢幕下光學指紋辨識模組合作

**中游:**
- **IC 設計與演算法:** **神盾** 自主開發電容式/光學式指紋辨識 IC、P-Sensor、TOF IC 及資料加密晶片
- **IP 授權:** 乾瞻科技（子公司）提供先進製程 foundation IP 授權給 IC 設計與系統廠

**下游 (終端應用):**
- **智慧型手機:** [[三星電子]]、[[小米]]、[[OPPO]]、[[vivo]]、[[華為]] — 手機螢幕下指紋辨識
- **汽車:** [[現代汽車]] Genesis、[[起亞]] K9 — 車用生物辨識啟動／解鎖
- **穿戴裝置:** [[三星電子]] — 藍牙耳機及穿戴式裝置感測應用

## 主要客戶及供應商
**主要客戶:**
- **韓國手機與消費電子:** [[三星電子]] — 手機螢幕下光學指紋辨識IC（曾佔三星訂單50%以上，P-Sensor 亦通過三星認證）
- **中國手機四大品牌:** [[小米]]、[[OPPO]]、[[vivo]]、[[華為]]（含榮耀）— 屏下光學指紋辨識IC
- **韓國車廠:** [[現代汽車]] (Genesis)、[[起亞]] (K9) — 車用指紋辨識IC，為兩大車廠獨家供應商
- **IP 授權客戶:** 採用乾瞻科技 foundation IP 之 IC 設計廠與系統廠

**主要供應商:**
- **晶圓代工:** [[台積電]]、[[聯華電子]]
- **EDA 與 IP:** [[力旺電子]] (eMemory)、[[新思科技]] (Synopsys) 等
