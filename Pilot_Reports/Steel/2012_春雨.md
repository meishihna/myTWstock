# 2012 - 春雨

## 業務簡介
**板塊:** Basic Materials
**產業:** Steel
**市值:** 4,125 百萬台幣
**企業價值:** 8,108 百萬台幣

春雨工廠股份有限公司（2012）創立於1949年，為台灣歷史最悠久的[[扣件]]製造商，隸屬台鋼集團，總部位於台中，製造基地遍及台灣、印尼（雄獅公司）、中國東莞及美國。公司具備從盤元線材拉拔、球化退火、冷間鍛造成型、熱處理到表面處理的完整垂直整合製程，為台灣[[TC螺栓]]（扭矩控制高強度結構螺栓）及[[軌道扣件]]的最大供應商，並在印尼鑽尾螺絲市場取得領導地位。2024年合併營收約92億元新台幣，集團由台灣春雨本體、印尼雄獅、中國東莞春雨、春日機械及美國春雨五大單元構成。

**營收結構方面**，產品組合以球化線材（約32%）、機械螺絲（約27%）、一般螺絲（約24%）、螺帽（約10%）及盤元（約7%）為主。地理分布呈現高度多元化：台灣本島佔37%，香港及中國大陸22%，東南亞（以印尼為核心）22%，歐洲9%，美國6%。子公司貢獻結構：台灣春雨47%、印尼雄獅19%、春日機械14%、東莞春雨9%、美國春雨5%。

**核心技術與競爭優勢方面**，春雨在台灣建築鋼構[[TC螺栓]]市場占有率居首，[[台北101]]、[[高鐵]]、捷運等重大工程均採用春雨產品；印尼鑽尾螺絲市場占有率第一，受惠於東南亞建築業持續成長。公司具備自主模具開發能力，可快速回應客戶特殊規格需求；身為台鋼集團成員，優先取得[[中鋼]]盤元線材配額，在原料供應與定價上具備相對優勢。2025年法說會揭露在手訂單能見度達1至1.5年，以台積電廠房擴建及國內基礎設施工程為主要驅動力。

**成長動能方面**，台積電廠房擴建（中科五期、六期）及AI資料中心新建帶動結構性螺栓需求；2026年海外客戶（北美）補庫存循環預期啟動，將改善外銷佔比偏低現況；低碳[[扣件]]（以電爐廢鋼為原料）符合歐盟CBAM要求，可搶攻歐洲高端市場；電動車高強度精密扣件單價是傳統汽車扣件的十倍以上，長期替換效益顯著。

主要風險：美國關稅不確定性使北美訂單在2025年受壓，復甦時程取決於關稅政策明朗化；中國扣件低價傾銷持續壓縮歐洲市場售價，儘管歐盟反傾銷措施提供部分保護；原料成本與中鋼盤元報價連動，鋼價上漲時若售價無法同步，毛利率承壓；2025年營收呈現年減趨勢，顯示歐洲需求持續疲軟；EU碳邊境調整機制若全面實施，短期增加合規成本。

## 供應鏈位置
**上游 (原料):**
- **盤元線材 (Wire Rod):** 主要向母集團[[中鋼]] (CSC) 採購碳鋼、合金鋼盤元，為最大單一採購來源；亦向日韓鋼廠補充採購特殊鋼種盤元。
- **球化退火線材:** 春雨集團內部自行進行球化退火（春日機械提供設備）。

**中游 (自身製程):**
- **春雨本體:** 酸洗 → 伸線（拉拔） → 球化退火 → 冷間鍛造成型 → 熱處理 → 電鍍/達克羅表面處理 → 成品包裝。
- **雄獅 (印尼):** 鑽尾螺絲、自攻螺絲製造，主攻東南亞建築市場。
- **東莞春雨:** 供應中國大陸市場標準件。

**下游 (終端應用):**
- **建築鋼構:** [[TC螺栓]]、高強度結構螺栓 — 台積電廠房、[[台北101]]、[[高鐵]]、[[捷運]]等大型工程。
- **軌道交通:** [[軌道扣件]] — 台灣高鐵、捷運軌道系統。
- **工業通路:** 一般機械螺絲 — 北美工業通路商[[Fastenal]]、[[Grainger]]。
- **電動車:** 高強度精密[[扣件]] — 新興市場，目標 EV 底盤及動力系統用途。

## 主要客戶及供應商
### 主要客戶
- **台灣工程市場:** 國內大型鋼構廠及營造商（採購[[TC螺栓]]用於台積電廠房、高科技廠辦、基礎設施工程）。
- **北美工業通路:** [[Fastenal]]、[[Grainger]] (W.W. Grainger) — 標準件及工業用螺絲螺帽。
- **東南亞建築市場:** 印尼子公司雄獅直接供應當地建築業（鑽尾螺絲市場占有率第一）。

### 主要供應商
- **盤元主料:** [[中鋼]] (2002) — 台鋼集團關係人，盤元線材主要來源，具優先採購配額。
- **特殊鋼盤元:** 日本及南韓鋼廠（特殊合金鋼鋼種補充）。
