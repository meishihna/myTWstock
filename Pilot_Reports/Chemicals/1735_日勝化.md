# 1735 - 日勝化

## 業務簡介
**板塊:** Basic Materials
**產業:** Chemicals
**市值:** 2,003 百萬台幣
**企業價值:** 2,668 百萬台幣

日勝化工股份有限公司成立於 1989 年，總部位於南投南崗，為日本[[AICA Kogyo]]（愛家工業，持股 50.1%）之台灣控股子公司，專精[[PU樹脂]]（聚氨酯樹脂）、[[TPU]]（熱塑性聚氨酯）、接著劑及 UV 硬化塗料之製造與銷售。公司擁有逾 30 年聚氨酯相關化學品研發與製造經驗，生產基地分布台灣南投、中國及越南，為鞋材及合成皮製造業的重要材料供應商，同時切入綠建材環保塗料及光電抗反射塗料等高附加值應用。

**營收結構方面**，[[PU樹脂]]及接著劑系列為最大收入來源，估計佔整體營收約 55%，主要供應鞋材合成皮用途；[[TPU]] 粒料佔約 25%，應用涵蓋鞋底、合成皮、運動器材及醫療管材；UV 硬化塗料（含抗反射、抗眩及綠建材塗料）佔約 15%；其他（接著劑等）佔約 5%。銷售地理上，台灣市場約佔 60%，中國及東南亞（越南廠）合計約 40%。

**核心技術與競爭優勢方面**，日勝化憑藉母公司[[AICA Kogyo]]的技術授權與長期合作開發，在綠建材環保無甲醛系 UV 塗料及高耐候 PU 樹脂領域具備差異化競爭力。[[PU樹脂]]產品獲[[寶成]]、[[豐泰]]等大型鞋廠認可，穩定切入[[Nike]]、[[Adidas]]代工產業鏈。[[TPU]] 配方多元，可依鞋材、合成皮、醫療等不同規格客製化，[[三芳]]等合成皮客戶長期穩定合作。UV 硬化塗料的研發則受惠於母公司豐富的建材化學品技術積累。

**成長動能方面**，越南廠的設立使公司受惠於東南亞鞋材製造業轉移，貼近[[豐泰]]、[[寶成]]的越南生產基地布局，增強供應鏈黏性。綠建材 UV 塗料配合台灣及日本環保建材法規需求擴大，具備中期成長潛力。[[TPU]] 應用拓展至醫療管材及運動器材，有助提升產品組合毛利率。隨著聚氨酯原料（[[MDI]]/[[TDI]]）供應趨穩，原料成本壓力有望緩解。

主要風險：鞋材客戶集中，[[寶成]]、[[豐泰]]議價能力強，轉嫁漲價能力受限；原料[[MDI]]/[[TDI]]採購自[[BASF]]、[[Covestro]]、[[萬華化學]]等，全球供需及油價波動影響成本；中國廉價 PU 及[[TPU]] 競爭持續；越南廠若遇當地政策或匯率風險，將影響當地業務獲利；母公司[[AICA Kogyo]]策略方向若調整，可能影響技術授權及持股穩定性。

## 供應鏈位置
**上游 (原料與技術):**
- **異氰酸酯 (MDI/TDI):** [[BASF]]、[[Covestro]]、[[萬華化學]] — [[PU樹脂]]及[[TPU]]核心原料
- **技術母公司:** [[AICA Kogyo]]（日本，持股 50.1%）— 技術授權與共同開發

**中游 (PU 化學品製造):**
- **日勝化 (1735)** — [[PU樹脂]]、[[TPU]] 粒料、接著劑、UV 硬化塗料，台灣南投廠 + 中國廠 + 越南廠

**下游 (終端應用):**
- **鞋材:** [[寶成]]、[[豐泰]] — 供 [[Nike]]、[[Adidas]] 代工鞋廠用 PU 樹脂
- **合成皮革:** [[三芳]] — 合成皮加工用 PU 樹脂
- **綠建材塗料:** 台灣及日本建築市場 — 環保 UV 硬化塗料
- **光電:** 面板模組廠 — 抗反射/抗眩 UV 塗料

## 主要客戶及供應商
### 主要客戶
- **鞋材代工廠:** [[寶成]]、[[豐泰]] — 供應 [[Nike]]、[[Adidas]] 代工廠所需 PU 樹脂
- **合成皮革:** [[三芳]] — 合成皮加工用 [[PU樹脂]]
- **綠建材塗料:** 台灣及日本建築市場 — 環保 UV 塗料（與母公司[[AICA Kogyo]]共同開發）
- **光電模組:** 面板模組廠 — 抗反射/抗眩 UV 硬化塗料

### 主要供應商
- **異氰酸酯:** [[BASF]]、[[Covestro]]、[[萬華化學]] — MDI/TDI，為 PU/TPU 最重要原料
- **技術授權:** [[AICA Kogyo]]（日本）— 綠建材塗料及 UV 系列技術
