# AMD 供應鏈 — 投資面敘事

## 投資邏輯
AMD 是全球第二大 AI 加速器與 x86 CPU 供應商，旗下 MI300/MI350 系列 AI GPU、EPYC 伺服器 CPU 與 Ryzen PC CPU 高度倚賴台灣供應鏈完成生產與組裝。AI GPU 全程採用台積電先進製程與 CoWoS 2.5D 封裝整合 HBM，封裝產能吃緊時外溢至日月光投控等封測廠。AMD MI300X/MI300A 的 OEM 與解決方案夥伴中，過半為台廠（緯創、緯穎、英業達、廣達、技嘉、華碩等），使台灣同時是 AMD 的製造基地與系統整合中心。在 NVIDIA 之外，雲端業者為分散採購與議價而扶植 AMD 平台，形成台廠「雙軌受惠」格局，並帶動載板、CPU 插槽、均熱片與電源等高階零組件規格升級。

## 驅動因素
- MI300/MI350 系列 AI GPU 在資料中心放量，雲端業者為分散供應而擴大採用 AMD 平台。
- AI GPU 採台積電先進製程與 CoWoS 封裝，先進封裝產能緊俏外溢至台系封測廠。
- ABF 載板為 AI GPU 必用高階基板，高速互連架構推升主機板層數與材料規格。
- AMD MI300A 維持 Socket 設計、針腳數高，CPU 插槽單價提升，連接器龍頭受惠。
- 液冷轉為標配，AMD 平台 CPU/GPU 用高階均熱片與冷板需求成長，散熱廠取得認證出貨。
- EPYC 伺服器 CPU 與 Ryzen AI PC 換機潮，擴大主機板與 ODM 出貨基期。

## 風險
- AMD AI GPU 市占仍落後 NVIDIA，出貨量能與軟體生態系成熟度存不確定性。
- CoWoS 與 HBM 產能受 NVIDIA 排擠，AMD 取得先進封裝產能的優先序偏低。
- 「股票換訂單」等綁定模式若雲端客戶投資縮手，實際拉貨恐不如預期。
- AI 散熱、載板族群評價偏高，題材修正時波動劇烈易遭錯殺。
- 美中科技管制與高階晶片出口限制衝擊終端市場與出貨節奏。
- 客戶集中於少數雲端與品牌業者，訂單能見度與議價受其資本支出循環左右。
