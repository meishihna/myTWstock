# Tesla 特斯拉供應鏈 — 投資面敘事

## 投資邏輯
Tesla 特斯拉台灣供應鏈聚焦於為其電動車、儲能與自駕系統提供零組件、機構件與電源解決方案的台廠,投資主軸在於台灣供應商而非品牌本身。台廠在傳動結構件、精密機構、車用線束連接器、被動元件與電源/充電模組等環節深度參與,並隨 Tesla 銷量規模化與全球化布局而擴張出貨。隨著 FSD 自動駕駛、Dojo 算力與人形機器人 Optimus 等新題材推進,具備車用攝影機、感測模組與精密金屬加工能力的台廠有望切入下一波供應鏈擴張;台灣憑藉精密製造、快速量產與成本優勢,成為 Tesla 在零組件與三電供應上的關鍵夥伴。

## 驅動因素
- Tesla 全球銷量與產能規模化,直接帶動傳動結構件、機構件與連接器線束的出貨成長。
- FSD 與自動駕駛功能滲透,推升車用攝影機、感測模組與影像運算相關需求。
- 儲能(Powerwall / Megapack)業務快速擴張,延伸電池材料與電源模組商機。
- 人形機器人 Optimus 量產題材,為精密馬達、傳動與機構件廠商開啟新成長曲線。
- 一體化壓鑄與輕量化設計趨勢,有利具備大型結構件與精密加工能力的台廠。
- 在地化與供應鏈分散布局,促使 Tesla 拉抬非中系零組件供應商的採購比重。

## 風險
- 單一客戶集中度高,Tesla 銷量波動或調整供應商策略時,對台廠營收衝擊顯著。
- Tesla 持續降價與成本下殺政策,壓縮供應鏈報價與毛利空間。
- FSD 商業化與人形機器人量產時程不確定,新題材貢獻營收的時點難以掌握。
- 車廠垂直整合與一體壓鑄擴大自製,恐減少外部機構件與零組件採購。
- 全球電動車補貼退場與終端需求放緩,影響整體拉貨動能。
- 地緣政治與關稅變化,牽動供應鏈在地化布局與台廠接單競爭力。
