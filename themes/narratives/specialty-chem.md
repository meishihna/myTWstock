# 特用化學 Specialty Chemicals — 投資面敘事

## 投資邏輯
特用化學是半導體與顯示製造「去瓶頸」最被低估的一環：晶圓每往先進節點推進一步，所需的電子級溶劑、特殊氣體、CMP 研磨液與封裝高分子材料的純度規格與單位用量同步跳升，而這些材料長期由日、美原廠寡占。台積電在台、美、日大舉擴產並推動供應鏈在地化，給了台廠特化業者一次世代級的卡位機會——勝一(1773)、三福化(4755)、台特化(4772)等已通過 2nm/3nm 認證並取得「卓越供應商」地位，達興材料(5234)更以自研 CMP 研磨液與感光性介電材料打入先進封裝。這類材料一旦完成晶圓廠認證即享有極高替換成本與長約能見度，毛利率普遍優於傳統石化。投資角度上，本題材兼具「先進製程放量」的量增與「在地替代進口」的滲透率提升雙重動能，且涵蓋從原料、特化品到通路代理(崇越 5434、華立 3010)的完整價值鏈。相較僅鎖定光阻的「光阻液」題材，特用化學提供更廣的電子材料投資切面。

## 驅動因素
- 先進製程放量：台積電 2nm/A16 量產帶動高純度溶劑、特殊氣體(乙矽烷、C4F6)與 CMP 研磨液單位用量倍增。
- 先進封裝爆發：CoWoS / InFO / 3D 封裝拉升剝離液、底部填充膠、PID 感光介電材料與電鍍添加劑需求。
- 供應鏈在地化：地緣風險與客戶「分散採購」政策，推動台廠加速替代日、美進口材料並取得認證。
- AI 伺服器與高頻 PCB：高速 CCL 對 Low Dk/Df 樹脂(國精化 4722)需求倍增，封裝高分子材料同步受惠。
- 認證壁壘形成護城河：通過晶圓廠先進製程認證後享長約、再定價週期與高客戶黏著。
- 海外擴廠跟單：台廠隨客戶布局美國亞利桑那、日本九州，開啟海外營收新增量。

## 風險
- 單一客戶集中：多數業者台積電佔比偏高(勝一約 36%、台特化約 60%)，客戶採購策略調整衝擊大。
- 半導體景氣循環：晶圓廠資本支出與稼動率下行時，耗材出貨與新產線回收期同步受壓。
- 原料供應集中：基礎醇酯、硫磺等仰賴台灣中油、長春石化等少數來源，價格波動直接侵蝕毛利。
- 匯率壓力：代理商以日圓/美元採購原廠材料，新台幣升值將壓縮本已偏薄的代理毛利(約 7–13%)。
- 代理權與原廠風險：通路商高度依賴單一原廠(崇越對信越、華立對 JSR)，授權或合資生變影響甚鉅。
- 認證爬坡不確定：新進者通過認證後取貨量爬坡緩慢，巨額資本支出回收期可能拉長。

## 關鍵受惠者
- 電子級溶劑：勝一(1773)、三福化(4755)
- 電子級酸 / 特化前驅體：中華化(1727)、國精化(4722)
- 半導體濕製程 / CMP 化學品：達興材料(5234)、永光(1711)、國化(1713)
- 電子級特殊氣體：台特化(4772)、晶呈科技(4768)
- PCB / 封裝高分子材料：長興(1717)、聚和(6509)
- 顯示光學材料：達輝光電(6434)
- 材料通路 / 特化代理：崇越(5434)、華立(3010)、崇越電(3388)
- 化學品交付設備：上品(4770)
- 應用端(晶圓廠 / 面板廠)：台積電(2330)、友達(2409)
