# 離岸風電 Offshore Wind — 投資面敘事

## 投資邏輯
離岸風電供應鏈涵蓋水下基礎與塔架鋼構、海纜、風機零組件機電、海事工程運維,以及電廠開發營運。台灣海峽風場條件優異,在政府區塊開發政策推動下進入長期建置週期,國產化要求帶動本土水下基礎、海纜與重電機電供應鏈成長,產業 CAGR 約 12–15%。台廠以世紀鋼、新光鋼等鋼構廠主導水下基礎,華新、大亞供應海纜,並由重電與機械業者切入塔架與風機零組件。產業以「裝置容量併網 × 國產化料件含量」驅動營收,並與太陽能、儲能共同構成台灣綠能版圖。

## 驅動因素
- 區塊開發政策推動離岸風電進入長期、可預期的建置週期。
- 國產化要求帶動本土水下基礎、海纜與機電供應鏈訂單。
- 台灣海峽優異風場條件支撐高容量因數與發電效益。
- 企業綠電採購與 RE100 需求,提升離岸風電售電誘因。
- 重電與鋼構廠擴產卡位,水下基礎與塔架價值量提升。
- 海事工程與運維(O&M)形成長期服務收入。

## 風險
- 開發成本上升與利率走高,影響專案財務可行性。
- 國產化進度、施工船機與供應鏈瓶頸可能延後併網。
- 颱風、海象等天候因素增加施工與運維風險。
- 躉購費率與競價機制調整影響開發商投資意願。
- 鋼材等原料價格波動,壓縮鋼構與海纜毛利。
- 環評、漁業協商與併網審查延宕專案時程。

## 關鍵受惠者
- 塔架 / 水下基礎鋼構:世紀鋼(9958)、新光鋼(2031)、潤泰材(8463)
- 海纜 / 電纜:華新(1605)、大亞(1609)
- 風機零組件 / 機電:東元(1504)、士電(1503)、華城(1519)、中興電(1513)
- 海事工程 / 運維:東方風能(7786)、森崴能源(6806)
- 電廠開發 / 營運:泓德能源(6873)、雲豹能源(6869)
