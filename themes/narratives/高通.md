# 高通 Qualcomm 供應鏈 — 投資面敘事

## 投資邏輯
高通是全球行動 SoC 與 5G 數據機龍頭，其 Snapdragon 旗艦晶片自家不設晶圓廠，先進製程主力下單台積電（N3／N4），成熟製程與電源管理 IC 則由聯電承接，台灣晶圓代工是高通最關鍵的製造後盾。近年高通因應地緣政治風險加速「去中化」，將原本集中於新加坡與中國的封測、測試產能轉單來台，並在新竹設立大樓深化在地供應鏈，預估對台採購金額年逾 3,000 億台幣，直接受惠者為日月光投控、京元電子等封測測試廠。射頻前端是高通另一核心，砷化鎵功率放大器帶動穩懋、宏捷科、全新、環宇等三五族代工廠出貨。隨 Snapdragon X 切入 Windows PC、AI 手機與智慧眼鏡放量，台廠在載板、被動元件、測試介面與組裝環節的價值含量同步提升，形成完整且持續加深的受惠鏈。

## 驅動因素
- 高通旗艦 Snapdragon 持續鎖定台積電先進製程（N3P／N4），製程升級拉抬代工價值量。
- 去中化轉單來台，封測、測試由新加坡／中國移至日月光投控、京元電子等台廠。
- Snapdragon X 系列切入 Windows on Arm 筆電，帶動仁寶、緯創、鴻海等 PC／裝置組裝訂單。
- 5G 與 WiFi 升級推升射頻前端用量，砷化鎵功率放大器需求支撐穩懋、宏捷科。
- 高通新竹大樓落成、在地化策略明確，台廠載板（欣興、景碩、南電）與被動元件含量提升。
- AI 手機與智慧眼鏡新應用擴大 SoC 出海口，延伸至光學鏡頭與系統封裝需求。

## 風險
- 高通採雙代工策略，三星 2nm 若搶單將分散台積電先進製程訂單。
- 智慧型手機為成熟市場，終端出貨成長有限，需求易受景氣與庫存循環波動。
- 高通自有射頻前端與 TDK 合資布局，可能調整砷化鎵外包比重，影響台灣三五族代工。
- 蘋果自研數據機進度推進，長線壓縮高通基頻晶片出貨與相關封測訂單。
- 被動元件與載板價格波動大，產業供需與報價循環影響台廠獲利彈性。
- 地緣政治與關稅變數，可能再次牽動高通供應鏈布局與下單分配。
