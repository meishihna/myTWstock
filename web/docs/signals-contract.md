# signals 資料契約 **v2**（給 Coverage / my-twstock 消費用）

本資料由**私有回測引擎**產生；引擎程式碼不隨資料交付。
公開產品主站 = **Coverage（my-twstock）**；本 repo 不再對外部署，只交付**輸出 JSON**。

**v2 變更摘要**（v1 → v2）
- 由單一 `signals.json` 改為**三層分檔**：`signals-index.json`（輕）+ `signals/{code}.json` + `prices/{code}.json`。
- 新增**逐筆交易明細**（含 MAE/MFE、出場原因代碼、`skipped`）與**還原 OHLC 序列**。
- **權益曲線不存**（前端由逐筆推導）、**MA 不存**（前端由收盤計算）。
- `signals.json`（舊）標 **deprecated**，僅供本 repo 內部 `/signals` 頁過渡，Coverage 切換完成後移除，**不長期維護兩份**。

## 0. 檔案總覽

| 檔案 | 內容 | 用途 | 載入時機 | **實測大小** |
|---|---|---|---|---|
| `signals-index.json` | meta + 每檔摘要（期間/交易日數/B&H/**籌碼列**）+ **每層層級摘要** | 排行清單、層比較、籌碼列 | **首屏** | **33 KB** |
| `signals/{code}.json` | 該檔**全組合統計 + 逐筆明細** | 組合詳情、逐筆表、權益曲線 | 點入個股時 lazy | 平均 282 KB／最大 351 KB |
| `prices/{code}.json` | **還原 OHLC + 量**、日期陣列 | 走勢圖（線/K 線）、標進出點 | 點入個股時 lazy | 平均 70 KB |
| `valuation.json` | BWIBBU 本益比/淨值比/殖利率 + 5 年百分位 | 籌碼列估值（已併入 index 的 `chips`） | 由 index 帶出 | 2 KB |
| ~~`signals.json`~~ | **DEPRECATED** | 內部頁過渡 | 勿用 | 3,147 KB |

**實測載入量**（25 檔 / 10,530 組 / 113,756 筆逐筆）
- **首屏僅 33 KB**（index 輕量化後）→ 點入一檔再 +352 KB（平均）／+424 KB（最壞）
- 權威檔總計 **8.63 MB**（分散在 51 個檔）；對照「單一大檔」約 **26 MB**（靜態站不可行）

> **index 為何輕量**：UI 是「選一檔 → 看它 450 組」，首屏不需要全站 10,530 組統計，故 combo 統計一律放 `signals/{code}.json`。

## 1. `signals-index.json`

```jsonc
{
  "schema": "signals-index/2",
  "updatedAt": "2026-08-01T…Z",
  "window": { "months": 61, "asof": "2026-07-31" },   // asof=回測上限日(對齊視窗用)
  "confLayers": ["無","投信","法人同買","大盤多頭","浮額清洗"],   // 全域層順序
  "entryRules": [ …10 個進場規則名 … ],   // combo 的 ei 是此陣列索引
  "exitRules":  [ …9 個出場規則名 … ],    // combo 的 xi 是此陣列索引
  "exitReasons":[ …12 個出場原因 … ],     // 逐筆的 rc 是此陣列索引
  "comboFields":[ … ], "tradeFields":[ … ],   // 見 §2；欄位定義只在此處(單一來源)
  "equityNote": "…", "maeMfeNote": "…", "indexNote": "…", "chipsNote": "…",
  "layerNote": "…",        // 450/90 與各層定義(可直接展示)
  "source": "…",           // 官方來源標註 —— **每頁必須原樣顯示**
  "disclaimer": "…",       // 免責 —— **每頁必須原樣顯示**
  "stocks": [ StockSummary… ]
}
```

### StockSummary
```jsonc
{
  "code": "2330", "name": "台積電", "market": "twse",   // "twse"=上市 | "tpex"=上櫃
  "期間": ["2021-07-01","2026-07-31"], "交易日數": 1236,
  "buyhold": { "總報酬%": 345.19, "最大回撤%": 44.8 },   // 同期買進持有(含息還原、內扣費稅)
  "confLayers": ["無","投信",…],        // 此檔實際有的層(上櫃只有 ["無"])
  "combos": 450, "trades": 4595,        // 數量(明細在 signals/{code}.json)
  "files": { "signals": "signals/2330.json", "prices": "prices/2330.json" },
  "chips": { … 見 §4 … },               // 上櫃為 null
  "layerSummary": [ { "層":"無","組合數":90,"有交易":88,"勝率中位":55.6,
                      "總報酬中位%":18.4,"正報酬組數":61,"平均交易次數":12.3 }, … ]
}
```
`layerSummary` 供「層比較」直接呈現；**中性比較，不推薦任何一層**（越嚴的層交易越少 → 需前置小樣本/過度最佳化免責）。

## 2. `signals/{code}.json` — 組合統計 + 逐筆明細

```jsonc
{
  "schema": "signals-detail/2", "code": "2330",
  "comboFields": ["ei","xi","ci","交易次數","勝率%","平均報酬%","總報酬%","最大回撤%","平均持有天數","skipped"],
  "tradeFields": ["si","ei","xi","ep","xp","rc","r","mae","mfe"],
  "combos": [
    { "s": [0,0,0,12,66.7,4.68,64.26,12.88,34.2,0],       // 統計,順序=comboFields
      "t": [ [412,413,123.5,432,131.0,3,5.821345,-2.13,8.41], … ] }   // 逐筆,順序=tradeFields
  ]
}
```

### combo 統計 `s`（順序 = `comboFields`）
| 位置 | 欄位 | 說明 |
|---|---|---|
| 0 | `ei` | 進場規則索引 → `index.entryRules[ei]` |
| 1 | `xi` | 出場規則索引 → `index.exitRules[xi]` |
| 2 | `ci` | 確認層索引 → **該檔** `StockSummary.confLayers[ci]` |
| 3 | `交易次數` | int；**0 = 該組合此層無成交（誠實呈現，勿隱藏）** |
| 4–8 | `勝率% / 平均報酬% / 總報酬% / 最大回撤% / 平均持有天數` | 0 交易時除總報酬(0.0)外皆 `null` |
| 9 | `skipped` | **訊號成立但買不到**的次數（次日開盤已達漲停 ≥ +9.95% → 跳過）。UI 建議顯示，避免高估可執行性 |

### 逐筆 `t`（順序 = `tradeFields`）
| 位置 | 欄位 | 型別 | 說明 |
|---|---|---|---|
| 0 | `si` | int | **訊號日**索引 → `prices.dates[si]` |
| 1 | `ei` | int | **進場日**索引（= `si + 1`，次日開盤成交） |
| 2 | `xi` | int | **出場日**索引 |
| 3 | `ep` | number | 進場價（= `prices.o[ei]`，還原價） |
| 4 | `xp` | number | 出場價（依出場規則可能為收盤/停損價/停利價） |
| 5 | `rc` | int | 出場原因代碼 → `index.exitReasons[rc]`（**不得 hardcode**） |
| 6 | `r` | number | **淨報酬%**（已扣手續費 0.1425%×2 + 證交稅 0.3%），存 6 位小數 |
| 7 | `mae` | number | **MAE%**（見 §3） |
| 8 | `mfe` | number | **MFE%**（見 §3） |

**日期一律存索引**（不存字串）→ 與 `prices/{code}.json` 的 `dates` 對齊；走勢圖本來就要那份日期陣列，故零額外成本。

## 3. 前端推導公式（**不存的欄位怎麼算**）

### 3.1 權益曲線（逐筆累積淨值）
```js
let eq = 1; const curve = [];
for (const t of trades) { eq *= 1 + t[R] / 100; curve.push((eq - 1) * 100); }
// curve 最後一個值 === 該 combo 的「總報酬%」(容許捨入;r 存 6dp)
```
> 引擎的 `總報酬%` 即以同一式子算出，故**前端推導與後端統計必然一致**——產出前已逐格對帳驗證。

### 3.2 均線（MA5/20/60）
不存；由 `prices.c` 以簡單移動平均計算（前 k−1 根為 null）。

### 3.3 MAE / MFE 定義
- 持有期間 = **進場日 `ei` ~ 出場日 `xi`（含頭尾）**。
- `MAE% = (min(prices.l[ei..xi]) / ep − 1) × 100` → 最壞未實現幅度（通常為負）。
- `MFE% = (max(prices.h[ei..xi]) / ep − 1) × 100` → 最好未實現幅度。
- **皆為毛值（未扣費稅）**，與淨報酬 `r` 口徑不同 → UI 勿直接相加比較。

## 4. 籌碼列 `chips`（官方，僅上市）

```jsonc
{
  "asof": "2026-07-30",        // ← 籌碼資料自身的日期(官方 T86/MI_MARGN 公布落後行情約一日)
  "priceAsof": "2026-07-31",   // ← 同檔行情最後交易日;兩者可能不同,**UI 須顯示 asof**
  "投信10日張": 1234.5, "外資10日張": -567.0,          // T86 近10日累計買超(張)
  "融資餘額張": 30664, "融資20日變化張": -678,          // MI_MARGN
  "融券餘額張": 130, "券資比%": 0.42,                   // 券資比 = 融券/融資 × 100
  "本益比": 32.6, "股價淨值比": 10.67, "殖利率%": 0.91, "估值日": "2026-07-31",   // BWIBBU
  "百分位5年": { "本益比": 88.3, "股價淨值比": 91.2, "殖利率": 12.4, "樣本日數": 1230 }
}
```
- **`asof` 取「最後有融資資料的交易日」**，並與 `priceAsof` 並列 —— 這**不是靜默 fallback**：日期明確標示，UI 必須顯示 `asof`，讓讀者知道籌碼與行情的時間差。
- **上櫃 `chips` = `null`** → UI 須標「上櫃・不適用」，勿留白讓人誤解為 0。
- `百分位5年` = 當前值在該檔 5 年分布的百分位（0–100）；本益比/淨值比越高＝相對歷史越貴，殖利率越高＝相對歷史越優。
- **不含**營收 YoY／EPS 成長（需 FinMind）→ 留待 Phase 2「使用者自帶金鑰」。

## 5. `prices/{code}.json`

```jsonc
{ "schema":"prices/2", "code":"2330", "adjusted": true,
  "dates":["2021-07-01", …],                 // 逐筆的 si/ei/xi 索引基準
  "o":[…], "h":[…], "l":[…], "c":[…], "v":[…] }   // 除權息還原 OHLC + 成交量
```
`adjusted: true` = OHLC 已除權息還原（報酬含息、總報酬口徑）；量不還原。

## 6. 上櫃（TPEx）標記
- `market:"tpex"`、`confLayers:["無"]`、combo 僅 **90** 組（全部 `ci=0`）、`chips:null`。
- 原因：確認層籌碼（T86 三大法人／MI_MARGN 融資）與 BWIBBU 估值**僅上市**。
- Coverage UI 須標「**上櫃・確認層與估值不適用（僅上市）**」。
- 目前上櫃 2 檔：`5347 世界先進`、`3324 雙鴻`。

## 7. 確認層語義（`ci` → `confLayers[ci]`）
| 層 | 定義（官方籌碼；訊號日成立才進場） | 需要資料 |
|---|---|---|
| `無` | 純規則、無籌碼過濾（= 基準 90 組） | — |
| `投信` | 投信近10日累計買超 ≥ 15 張 | T86 投信 |
| `法人同買` | 投信達標**且**外資近10日淨買超 | T86 投信+外資 |
| `大盤多頭` | 加權指數收盤 > 200日均線 | FMTQIK 加權 |
| `浮額清洗` | 融資餘額 < 20 交易日前（散戶退場中） | MI_MARGN 融資 |

## 8. 排序原則（防 cherry-pick）
`combos` **依規則順序**（進場 × 出場 × 層）輸出，**非依績效排序**。UI 可排行，但須保留「原順序」選項，且不得只呈現最佳組合。

## 9. 單位與口徑
- 所有 `%` 為百分比數值（`64.26` = +64.26%）。
- 報酬含息還原 + 手續費 0.1425%×2 + 證交稅 0.3%。
- `最大回撤%` **存正數**（幅度）；顯示建議加負號／標綠（台股綠=虧損）。

## 10. 更新頻率 / 產生方式
| 產出 | 更新方式 | 備註 |
|---|---|---|
| `chips.json` | 每日增量（官方 T86／MI_MARGN） | 列格式 `[外資股數, 投信股數, 融資張, **融券張**]`。第 4 格為 v2 新增：舊列僅 3 格仍相容（讀為 `null`）；券資比只需最新一日（**1 次呼叫**）即可，無需全量回補 |
| `valuation.json` | 每日 1 呼叫（BWIBBU 快照）／一次性回補（5 年百分位） | BWIBBU 僅上市 |

| 對帳 | 產生端自動執行 | ①逐筆數 ②權益還原 ③MAE/MFE，全過才可交付 |
